# 网络 01 - 协议基础

## 什么是协议

协议是**数据传输和解释的规则**，定义了通信双方如何建立连接、如何交换数据、如何结束通信。

## 典型协议一览

| 层 | 协议 | 作用 |
|----|------|------|
| **传输层** | TCP | 面向连接、可靠、基于字节流 |
| | UDP | 无连接、不可靠、实时性高 |
| **应用层** | HTTP | 超文本传输（Web 基础） |
| | FTP | 文件传输 |
| **网络层** | IP | 互联网互联 |
| | ICMP | 差错控制与诊断（ping） |
| | IGMP | 组播管理 |
| **链路层** | ARP | IP → MAC 地址解析 |
| | RARP | MAC → IP 反向解析 |

## 网络应用程序设计模式

### C/S 模式（Client/Server）

客户端与服务器各部署专用程序。

| 优点 | 缺点 |
|------|------|
| 协议选用灵活 | 需安装第三方软件 |
| 数据可缓存 | 开发工作量大 |
| | 对用户安全构成威胁 |

### B/S 模式（Browser/Server）

只需部署服务端，客户端使用浏览器。

| 优点 | 缺点 |
|------|------|
| 无需安装，安全性高 | 必须支持 HTTP 协议 |
| 开发工作量小 | 不能进行数据缓存 |
| 可跨平台 | |

## 分层模型

### OSI 七层模型 vs TCP/IP 四层模型

```
OSI 七层              TCP/IP 四层
┌──────────────┐
│  应用层       │
│  表示层       │──→ 应用层
│  会话层       │
├──────────────┤
│  传输层       │──→ 传输层
├──────────────┤
│  网络层       │──→ 网络层
├──────────────┤
│  数据链路层   │
│  物理层       │──→ 网络接口层
└──────────────┘
```

| 层 | 作用 |
|----|------|
| **物理层** | 传输比特流，定义网线接口、传输速率 |
| **数据链路层** | 帧传输、错误检测纠正、介质访问控制 |
| **网络层** | 路由选择、逻辑寻址（IP） |
| **传输层** | 分段传输、端口通信（TCP/UDP） |
| **会话层** | 建立/管理/终止会话 |
| **表示层** | 数据格式转换、加密/解密 |
| **应用层** | 为用户应用提供网络服务（HTTP/FTP/SMTP） |

## 通信过程

数据从应用层向下逐层封装：
```
应用数据 → TCP 头+数据 → IP 头+数据 → 帧头+数据+帧尾
```
