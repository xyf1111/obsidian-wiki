# 网络 10 - 学习路线

> 计算机网络零基础到精通的三阶段学习路线：基础学习 → 实际运用 → 备战面试。

计算机网络是指将地理位置不同的多台计算机或设备通过通信线路进行连接，从而实现信息传递和资源共享。

## 为什么要学计算机网络？

- 绝大多数程序依赖网络加载文件和数据（网站、小程序、后台程序等），网络重要性不言而喻。
- 了解数据在不同计算机之间传输的过程和细节，掌握服务器、带宽、网速、流量等实用知识。
- 有助于开发性能更高、更安全稳定的应用：用 HTTP 2.0 代替 HTTP 1.x 减少网页加载时间、用 HTTPS 提高安全性、用 UDP 而非 TCP 提升多人实时游戏传输速度、在网络模型第 4 层和第 7 层实现负载均衡和 DDoS 防护。
- 网络设计思想可迁移到项目开发和框架源码理解：分层思想、TCP 三次握手和四次挥手、滑动窗口拥塞控制等。
- 与操作系统一样，计算机网络是**考研和面试的重点**（尤其前端和服务端开发），大学期间要认真学习。
- 从事网络方向工作（网络工程师、网络运维、网络实施等），计算机网络是核心中的核心。

## 学习条件

1. 至少学过一门编程语言（网络理论知识较多，直接学容易被劝退）。
2. 急着找工作的同学可先不学，面试前直接看题目即可；从事网络方向工作则必须系统学习，不能等到面试再学。

## 整体学习建议

1. **从整体到局部**：先了解网络分层及各层作用与联系，再按序学习每层内部的协议和细节；初学不建议啃教材，可通过趣味科普书籍或视频入门。
2. **不要死记硬背**：记不住没关系，开发程序时思考数据传输过程（如网站加载过程），通过抓包等实操加深印象。
3. **重点突出**：不从事网络相关工作的话，学完重点知识即可，甚至直接通过看面试题学习。
4. **善用 AI 辅助学习**：遇到不理解的网络概念或协议，可用 AI 工具（如 ChatGPT、DeepSeek）让其用通俗语言解释或画图演示数据传输过程。
5. **考虑考证**：从事网络相关工作（如网络工程师）建议考华为认证、思科认证等。

## 知识体系

### 学习重点

- 计算机网络分层模型以及各层的作用
- 数据在两台计算机之间的整个网络传输过程（网站加载过程）
- 应用层协议：HTTP、HTTPS、DNS
- 传输层协议：TCP（重中之重）、UDP

### 知识点大全

#### 互联网基本概念

- 计算机网络分类
- 性能指标：速率、带宽、时延、利用率、往返时间、丢包率、吞吐量

#### 计算机网络分层模型【重点】

- 分层思想、协议和服务
- OSI 七层模型、TCP / IP 四层模型

#### 应用层【重点】

- 作用和原理
- 应用进程通信方式（客户 / 服务器方式、P2P 对等方式）
- 常用协议：**HTTP**【重点】、**HTTPS**【重点】、**DNS**【重点】、FTP、DHCP、NTP、邮件相关协议
- CDN

#### 传输层【重点】

- 作用和原理、复用和分用
- **TCP**【重中之重】：连接建立和断开（三次握手、四次挥手）、流量控制、拥塞控制、超时重传机制、可靠传输实现、报文首部格式
- **UDP**：报文结构
- **UDP 和 TCP 的对比及应用场景**

#### 网络层

- 路由器
- 常用协议：**IP**（地址划分、IPv4、IPv6、数据报首部格式）、ICMP、ARP / RARP、NAT、OSPF、BGP
- 路由选择算法、VPN 技术

#### 数据链路层

- 作用和原理、封装数据帧、差错控制、可靠传输
- MAC 地址、PPP 协议

#### 物理层（简单了解即可）

- 作用和原理、物理介质、数据交换方式、信道复用

#### 网络安全

- 加密、认证、防火墙、常见攻击及防范

## 学习路线

按以下 3 个阶段学习：

### 阶段 1：基础学习

学习目标：了解计算机网络基础知识，跟着一个视频或书籍过一遍，对网络分层模型和重点知识有大致的印象。

#### 学习建议

1. 急于求职的话，本阶段可跳过，直接去看面试题。
2. 先看有趣的课外书：如《图解 HTTP》，当睡前读物即可，避免自学枯燥。
3. 选择适合的视频课程：求职方向看《计算机网络微课堂》入门；考研方向看《王道计算机考研 - 计算机网络》视频，或阅读《计算机网络 - 自顶向下方法》《计算机网络 - 谢希仁》等书籍。
4. 面试前再重点背八股文。

### 阶段 2：实际运用

学习目标：根据自己的职业发展方向进行不同的实践，运用和巩固计算机网络知识。

#### 学习建议

本阶段可跳过，在开发中实践即可。按职业方向实践：

1. 后端开发：基于 Socket 开发自己的通讯应用 / 框架、实现自己的浏览器、阅读开发框架源码等。
2. 前端开发：使用 HTTPS 协议增加网站安全性、使用 HTTP 2 协议提高网站加载速度、用控制台等抓包工具分析请求 / 响应。
3. 网络工程师：使用华为 eNSP 或 Cisco Packet Tracer 模拟器搭建网络拓扑并进行配置。
4. 安全工程师：使用 Wireshark 之类的抓包工具分析数据包 / 数据帧。

### 阶段 3：备战面试

学习目标：掌握计算机网络高频面试题，顺利通过面试。

#### 学习建议

1. 优先看重点：面试主要考察网络分层模型、HTTP/HTTPS、TCP/UDP 协议、网站加载过程等。
2. 结合专业知识：不同方向的专业知识会结合计算机网络来考察，如前端网站加载过程、后端负载均衡实现等。
3. 多看真实面经，了解不同公司对计算机网络的考察重点。

#### 面试考察形式

面试时对计算机网络的考察主要有 5 种形式（主要针对前后端开发）：

1. 直接问某个具体的知识点，如：讲解 TCP 三次握手和四次挥手机制。
2. 结合不同方向的专业知识考察，如：网站的加载过程（前端）、四七层负载均衡的实现和优缺点（后端）。
3. 通过实际开发中遇到的问题考察网络基础，如：网站加载过慢，有哪些优化方式？
4. 考察框架（轮子）的核心设计和源码细节中的网络知识点运用，如 Netty 针对 UDP 协议的封装设计。
5. 系统设计类问题，如：如何实现一个浏览器？（相对较少）

#### 经典面试题

1. 计算机网络分层结构，各层有哪些常用协议？【高频】
2. TCP 和 UDP 协议的区别？如何选择应用哪个协议？【高频】
3. TCP 为什么需要三次握手和四次挥手？为什么不是两次握手、四次握手？为什么不是三次挥手？【高频】
4. TCP 滑动窗口和拥塞控制机制
5. TCP 如何保证可靠性？
6. HTTP 协议常用状态码和含义
7. HTTP 和 HTTPS 协议的区别？【高频】
8. HTTPS 的原理、请求流程？
9. HTTP 2 为什么快？
10. HTTP 的短连接和长连接，以及如何选择？
11. POST 和 GET 请求的区别【高频】
12. 浏览器中输入 URL 返回页面的过程？（包括 DNS 解析过程）【高频】
13. Cookie 和 Session 的区别？
