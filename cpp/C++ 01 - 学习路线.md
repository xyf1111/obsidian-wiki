# C++ 学习路线

> C++ 是高性能系统编程语言，支持面向对象、泛型、过程式多种编程范式，在游戏引擎、音视频处理、高频交易、操作系统、嵌入式系统等领域不可替代。

## 就业方向

| 方向 | 说明 |
|------|------|
| 服务端开发 | 高并发后端、游戏服务器、金融系统 |
| 系统开发 | 操作系统、驱动、嵌入式系统、网络协议栈 |
| 客户端开发 | 桌面应用（Qt）、跨平台 GUI |
| 游戏开发 | Unreal Engine（主语言 C++） |
| 音视频处理 | 编解码、FFmpeg、直播推流 |
| 图像处理 | 计算机视觉、OpenCV |
| 量化交易开发 | 金融高频交易系统 |
| SDK 开发 | API 设计、基础库开发 |

### C++ vs Java 选择

- **选 C++**：对底层、嵌入式、图像/音视频处理、游戏开发、高性能计算感兴趣
- **选 Java**：更喜欢开发业务系统、快速实现功能
- **时间充裕可两者都学**：先学 C/C++ 打底层基础，再学 Java 做项目找工作

## 学习路径

| 阶段 | 内容 | 建议时长 |
|------|------|---------|
| 阶段 1 | C++ 语法基础 | 30-45 天 |
| 阶段 2 | C++ 进阶 | 30-90 天 |
| 阶段 3 | 计算机基础 | 穿插学习 |
| 阶段 4 | 软件开发通用 | 穿插学习 |
| 阶段 5 | 后端开发通用 | 穿插学习 |
| 阶段 6 | 项目实战 | 视项目而定 |
| 阶段 7 | 求职备战 | 面试前 1 个月 |

### 阶段 1：C++ 语法基础

**核心知识点：**
- 变量、常量、数据类型、运算符、控制结构
- 函数（重载、默认参数）
- 数组、字符串、指针、引用
- 内存管理（动态分配/释放）
- 结构体、命名空间
- 面向对象：类/对象、封装、继承（多继承/虚继承/菱形继承）、多态（虚函数/纯虚函数/抽象类）
- 异常处理、STL（容器/迭代器/算法）

**开发工具：** Visual Studio（Win）、CLion（跨平台）、VS Code + C++ 插件

### 阶段 2：C++ 进阶

**核心知识点：**
- RAII 资源管理
- C++ 11/14/17/20 新特性：自动类型推导、lambda、智能指针、移动语义、右值引用、nullptr
- 类型转换：static_cast / reinterpret_cast / dynamic_cast / const_cast
- 编译/构建/调试工具：GCC、CMake、GDB
- 编码规范：Google C++ Style
- 编译链接原理（静态链接/动态链接）
- STL 容器实现原理（vector/string/list/map/deque）

**推荐书籍：** 《C++ Primer Plus》《Effective C++》《STL 源码剖析》

### 阶段 3：计算机基础

- 数据结构和算法
- 操作系统（进程/线程、内存管理、锁、系统调用）
- 计算机网络（TCP/IP、HTTP、Socket）

### 阶段 4：软件开发通用

- 企业项目开发流程、Git、Linux 服务器
- 设计模式、软件工程

### 阶段 5：后端开发通用

C++ 后端相比 Java 更注重性能优化和内存管理：

**核心知识点：**
- MySQL 数据库（SQL、表设计、ORM）
- 开发框架：Drogon（Web）、ODB（ORM）、gRPC（RPC）
- 包管理：Conan、vcpkg
- Redis、消息队列、Nginx
- 微服务、容器（Docker/K8s）

### 阶段 6：项目实战

**项目类型推荐：**

| 类型 | 推荐项目 |
|------|---------|
| 手写轮子 | 简易 STL、JSON 库、TCP/IP 协议栈 |
| 数据库 | SQLite、手写数据库 |
| 中间件 | LevelDB（KV 存储引擎） |
| 网络编程 | muduo 网络库、TinyWebServer |
| RPC 框架 | phxrpc（腾讯）、srpc（搜狗） |
| 分布式 | MIT 6.824 课程 |

**C++ 项目特点：** 练手项目多为"手写轮子"，对基础要求高，能锻炼编程能力。多看开源项目源码。

### 阶段 7：求职备战

**面试重点（三大方向）：**
1. **C++ 语言本身**：特性、语法细节、最佳实践
2. **计算机基础**：数据结构、算法、操作系统、计算机网络
3. **领域技能**：后端、嵌入式、游戏、客户端

**经典面试题：**
1. C++ 11 新增了哪些新特性？
2. 虚函数和纯虚函数的区别与作用？
3. 为什么不能把所有函数设成虚函数？
4. 多态的实现原理？
5. 智能指针的种类与作用？
6. 指针和引用的区别？
7. new 和 malloc 的区别？
8. 内存泄漏的原因和避免方法？
9. 如何计算类/结构体大小？
10. C++ 类型转换的方法？
