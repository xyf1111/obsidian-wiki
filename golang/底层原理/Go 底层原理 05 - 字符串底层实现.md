# Go 底层原理 05 — 字符串底层实现

## StringHeader 结构体

Go 字符串的底层由 `reflect.StringHeader` 描述：

```go
type StringHeader struct {
    Data uintptr  // 指向底层字节数组的指针
    Len  int      // 字符串长度（字节数，不是 rune 数）
}
```

> Go 1.20+ 中 `reflect.StringHeader` 已标记为弃用，推荐用 `unsafe.String`/`unsafe.StringData`。

### 内存布局

```
string 值（16 字节）
┌──────────────┐
│ Data (8字节)  │────→ [H][e][l][l][o]
│ Len  (8字节)  │      len=5
└──────────────┘
```

### 验证

```go
s := "Hello"
h := (*reflect.StringHeader)(unsafe.Pointer(&s))
fmt.Printf("Data: %x, Len: %d\n", h.Data, h.Len) // 某个地址, 5
```

## 字符串不可变性

Go 字符串是**只读的**，创建后不能修改：

```go
s := "Hello"
// s[0] = 'h'  // ❌ 编译错误：cannot assign to s[0]
```

**设计原因：**
1. **安全** — 字符串可以安全共享，不会有竞态
2. **高效** — 子串操作不需要拷贝（共享底层数组）
3. **哈希** — 字符串可作为 map key（不可变保证哈希值稳定）

```go
// 子串不拷贝底层数据
s := "Hello, World"
sub := s[7:12]    // "World"——共享 s 的底层数组，O(1)
```

> ⚠️ 虽然字符串不可变，但 `[]byte(s)` 会拷贝一份完整的字节数组。

## 字符串拼接性能

### 不同方式对比

```go
// 方式1：+ 拼接（慢）
s := ""
for i := 0; i < 1000; i++ {
    s += "a"           // 每次创建新字符串，O(n²)
}

// 方式2：strings.Builder（快）
var sb strings.Builder
sb.Grow(1000)           // 预分配
for i := 0; i < 1000; i++ {
    sb.WriteByte('a')
}
s := sb.String()

// 方式3：[]byte（快）
buf := make([]byte, 0, 1000)
for i := 0; i < 1000; i++ {
    buf = append(buf, 'a')
}
s := string(buf)        // 最后转 string 会拷贝
```

### 底层原因

`+` 每次拼接都：
1. 计算新字符串长度
2. 分配新内存
3. 拷贝旧字符串 + 新内容
4. 释放旧字符串

`strings.Builder` 通过维护 `[]byte` 缓冲区避免重复分配。

## 字符串与 []byte 转换

```go
s := "Hello, 世界"

// string → []byte（拷贝）
b := []byte(s)          // O(n) 复杂度

// []byte → string（拷贝）
s2 := string(b)         // O(n) 复杂度
```

### 零拷贝转换（unsafe）

> ⚠️ 仅用于只读场景，不要修改转换后的 []byte！

```go
// string → []byte（零拷贝，只读）
func StringToBytes(s string) []byte {
    return unsafe.Slice(unsafe.StringData(s), len(s))
}

// []byte → string（零拷贝）
func BytesToString(b []byte) string {
    return unsafe.String(unsafe.SliceData(b), len(b))
}
```

## 字符串常量池

编译期确定的字符串会被放入**只读数据区**，相同的字符串字面量共享同一份内存：

```go
s1 := "Hello"
s2 := "Hello"
// s1 和 s2 指向同一块内存
```

## 字符串比较

```go
// 直接比较 == 和 != 是 O(n) 比较内容
s1 := "Hello"
s2 := "World"
fmt.Println(s1 == s2) // 比较底层字节

// 不同字符串一定不同地址
// 相同字符串如果运行时构造则可能不同地址
s3 := "Hello"
s4 := "He" + "llo"  // 编译期折叠，与 s3 地址相同
```
