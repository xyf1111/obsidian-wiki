# Go 进阶 12 — 错误处理进阶

> 基础错误处理见 [[golang/基础/Go 基础 12 - 错误处理 defer-panic-recover]]。

## error 接口

Go 的错误是一个**接口**，而非异常：

```go
type error interface {
    Error() string
}
```

```go
// 任何实现了 Error() 方法的类型都可以作为错误
type MyError struct {
    Code    int
    Message string
}

func (e *MyError) Error() string {
    return fmt.Sprintf("code=%d: %s", e.Code, e.Message)
}
```

## 自定义错误类型

### 简单的 sentinel error

```go
var ErrNotFound = errors.New("not found")
var ErrPermission = errors.New("permission denied")

func GetUser(id int) (*User, error) {
    if id <= 0 {
        return nil, ErrNotFound
    }
    // ...
}
```

### 带上下文的错误

```go
type AppError struct {
    Code    int
    Message string
    Err     error  // 包装的原始错误
}

func (e *AppError) Error() string {
    return fmt.Sprintf("code=%d: %s (%v)", e.Code, e.Message, e.Err)
}

func (e *AppError) Unwrap() error {
    return e.Err
}
```

## errors.Is 与 errors.As

Go 1.13+ 引入了错误链的检查：

### errors.Is — 判断错误类型

```go
// 检查错误链中是否有 ErrNotFound
if errors.Is(err, ErrNotFound) {
    fmt.Println("resource not found")
}

// 自定义 Unwrap 方法的错误同样支持
if errors.Is(err, io.EOF) {
    fmt.Println("end of file")
}
```

### errors.As — 获取具体错误值

```go
// 从错误链中查找并提取 *MyError 类型的错误
var myErr *MyError
if errors.As(err, &myErr) {
    fmt.Printf("code=%d, message=%s\n", myErr.Code, myErr.Message)
}
```

## 错误包装（fmt.Errorf + %w）

```go
// 包装错误：建立错误链
func ReadConfig(path string) error {
    data, err := os.ReadFile(path)
    if err != nil {
        return fmt.Errorf("read config %s: %w", path, err)
    }
    // ...
}
```

### wrap vs 不 wrap

```go
// ✅ %w 包装（可解开）
return fmt.Errorf("read file: %w", err)
errors.Is(err, os.ErrNotExist)  // true

// ❌ %v 不包装（丢失原始错误信息）
return fmt.Errorf("read file: %v", err)
errors.Is(err, os.ErrNotExist)  // false，检查不通过
```

### 多层包装

```go
func LoadConfig(path string) (*Config, error) {
    data, err := os.ReadFile(path)
    if err != nil {
        return nil, fmt.Errorf("load config: %w", err)
    }

    var cfg Config
    if err := json.Unmarshal(data, &cfg); err != nil {
        return nil, fmt.Errorf("parse config: %w", err)
    }
    return &cfg, nil
}

// 调用方可以一直追溯到根因
err := LoadConfig("/etc/config.json")
fmt.Println(err)                            // "load config: parse config: unexpected end of JSON input"
fmt.Println(errors.Is(err, io.ErrUnexpectedEOF))  // true
```

## Sentinel Error 模式

```go
// 定义 sentinel error
var (
    ErrNotFound      = errors.New("resource not found")
    ErrAlreadyExists = errors.New("resource already exists")
    ErrForbidden     = errors.New("permission denied")
)

// 在 API 中返回
func (s *Store) Get(id int) (*Item, error) {
    item, ok := s.data[id]
    if !ok {
        return nil, fmt.Errorf("store.Get(%d): %w", id, ErrNotFound)
    }
    return &item, nil
}
```

### 使用 sentinel error 的注意事项

```go
// ❌ 避免：导出具体的 sentinel
var ErrSpecific = errors.New("specific db error")
func Get() error { return ErrSpecific }

// ✅ 推荐：提供 Is/As 方法，隐藏实现细节
type DBError struct{ Msg string }
func (e *DBError) Error() string { return e.Msg }
func (e *DBError) Is(target error) bool {
    _, ok := target.(*DBError)
    return ok
}
```

## 错误处理最佳实践

### 1. 尽早处理

```go
// ❌ 延迟处理
data, _ := ioutil.ReadFile(path)  // 忽略错误
result, _ := process(data)

// ✅ 尽早处理
data, err := os.ReadFile(path)
if err != nil {
    return fmt.Errorf("read: %w", err)
}
```

### 2. 只处理一次

```go
// ❌ 重复处理：既 log 又返回
func Get() error {
    data, err := fetch()
    if err != nil {
        log.Printf("fetch failed: %v", err)  // log
        return err                           // 又返回
    }
    // ...
}

// ✅ 要么 log 要么 return，不要两者都做
func Get() error {
    data, err := fetch()
    if err != nil {
        return fmt.Errorf("fetch: %w", err)  // 让上层决定怎么处理
    }
    // ...
}
```

### 3. 用类型表达可选值

```go
// ❌ 用 error 表达"没有找到"
user, err := findUser(id)
if errors.Is(err, ErrNotFound) { ... }

// ✅ 用 bool 或指针 nil 表达
user, found := findUser(id)
if !found { ... }

// ✅ 或返回 *User，nil 表示不存在
user, err := findUser(id)
if user == nil { ... }
```

## panic 的适用场景

```go
// panic 只用在"不可能发生"的错误
// 1. 程序初始化失败
func init() {
    if err := loadConfig(); err != nil {
        panic(err)  // 配置错误应该直接崩溃
    }
}

// 2. 接口契约被违反
func (s *Stack) Pop() interface{} {
    if s.Empty() {
        panic("stack: Pop called on empty stack")
    }
    // ...
}
```
