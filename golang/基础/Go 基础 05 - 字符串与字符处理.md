# Go 基础 05 - 字符串与字符处理

> 原文：[https://xyf1111.github.io/go-study-05/](https://xyf1111.github.io/go-study-05/)

## 字符串特性

```go
s := "Hello, 世界"
```

Go 中的 `string`：
- **不可变** — 创建后不能修改（类似 Java）
- **UTF-8 编码** — 每个字符 1-4 字节
- **底层结构** — 指向只读内存区域的指针 + 长度
- **零值** — `""`（不是 nil）

## strings 包常用函数

```go
import "strings"

s := "Hello, World!"

strings.Contains(s, "World")       // true
strings.HasPrefix(s, "Hello")      // true
strings.HasSuffix(s, "!")          // true
strings.Index(s, "o")              // 4（第一个匹配位置）
strings.LastIndex(s, "o")          // 8（最后一个匹配位置）
strings.Count(s, "l")              // 3

// 大小写转换
strings.ToUpper(s)                 // "HELLO, WORLD!"
strings.ToLower(s)                 // "hello, world!"
strings.Title("hello world")       // "Hello World"（已弃用，改用 cases.Title）

// 分割与连接
parts := strings.Split("a,b,c", ",")      // ["a", "b", "c"]
joined := strings.Join(parts, "-")        // "a-b-c"
fields := strings.Fields(" a  b   c ")    // ["a", "b", "c"]（按空白分割）

// 修剪
strings.Trim("!!Hello!!", "!")            // "Hello"
strings.TrimSpace("  Hello  ")            // "Hello"
strings.TrimPrefix("/api/v1", "/api")     // "/v1"

// 替换
strings.Replace("oink oink", "o", "e", 1) // "eink oink"（1次）
strings.ReplaceAll("oink oink", "o", "e") // "eink eink"（全部）
strings.Repeat("na", 3)                   // "nanana"

// 比较
strings.Compare("a", "b")                 // -1（字典序）
strings.EqualFold("Go", "go")              // true（忽略大小写）
```

## strings.Builder — 高效字符串拼接

避免 `+` 拼接产生大量临时对象：

```go
var sb strings.Builder
sb.Grow(100)               // 预分配内存

sb.WriteString("Hello")
sb.WriteByte(',')
sb.WriteString(" World")
sb.WriteRune('!')

result := sb.String()      // "Hello, World!"
```

> `strings.Builder` 比 `+` 或 `fmt.Sprintf` 高效得多，适合循环拼接。

## strings.Reader — 高效读取

```go
r := strings.NewReader("Hello, World!")
buf := make([]byte, 5)
r.Read(buf)                // buf = "Hello"
r.Read(buf)                // buf = ", Wo"
```

## 格式化字符串

```go
import "fmt"

// 拼接
s := fmt.Sprintf("Hello, %s! You are %d years old.", "Alice", 30)

// 数字格式化
fmt.Sprintf("%d", 255)               // "255"
fmt.Sprintf("%08b", 255)             // "11111111"（二进制）
fmt.Sprintf("%x", 255)               // "ff"（十六进制）
fmt.Sprintf("%.2f", 3.14159)         // "3.14"
```

## 算法：最长不重复子串

```go
func lengthOfNonRepeatingSubStr(s string) int {
    lastOccurred := make(map[rune]int)
    start := 0
    maxLength := 0

    for i, ch := range []rune(s) {
        if lastIdx, ok := lastOccurred[ch]; ok && lastIdx >= start {
            start = lastIdx + 1
        }
        if i-start+1 > maxLength {
            maxLength = i - start + 1
        }
        lastOccurred[ch] = i
    }
    return maxLength
}
```
