# Go 基础 01 - 变量定义与基本类型

> 原文：[https://xyf1111.github.io/go-study-01/](https://xyf1111.github.io/go-study-01/)

## 基本数据类型

| 类型 | 描述 | 零值 | 占用 |
|------|------|------|------|
| `bool` | 布尔 | `false` | 1 byte |
| `int` / `uint` | 平台相关整数（32/64 bit） | `0` | 4/8 byte |
| `int8` / `uint8` | 8 位整数 | `0` | 1 byte |
| `int16` / `uint16` | 16 位整数 | `0` | 2 byte |
| `int32` / `uint32` | 32 位整数 | `0` | 4 byte |
| `int64` / `uint64` | 64 位整数 | `0` | 8 byte |
| `float32` / `float64` | 浮点数 | `0.0` | 4/8 byte |
| `complex64` / `complex128` | 复数 | `0+0i` | 8/16 byte |
| `byte` | uint8 的别名 | `0` | 1 byte |
| `rune` | int32 的别名（Unicode 码点） | `0` | 4 byte |
| `string` | 字符串（不可变字节序列） | `""` | 16 byte（header） |
| `uintptr` | 指针整数表示 | `0` | 4/8 byte |

## 变量声明方式

Go 提供了灵活且简洁的变量声明语法：

### 1. `var` 完整声明（带类型）

```go
var name string = "Alice"
var age int = 30
var active bool
```

### 2. `var` 批量声明

```go
var (
    name   string = "Alice"
    age    int    = 30
    active bool
)
```

### 3. 类型推断（省略类型）

```go
var name = "Alice"   // string
var age = 30         // int
var pi = 3.14        // float64（浮点数默认 float64）
```

### 4. 短声明 `:=`（函数内专用）

```go
name := "Alice"    // 只能在函数内部使用
age := 30
```

> **关键区别**：`var` 可以在包级别使用，`:=` 只能在函数内部。

### 5. 多变量同时赋值

```go
a, b, c := 1, 2, 3
x, y := y, x        // 交换值（无需临时变量）
```

## 类型零值（Zero Values）

Go 的变量声明后即使不赋值也有默认零值——没有「未初始化」状态：

```go
var i int       // 0
var f float64   // 0.0
var s string    // ""
var b bool      // false
var p *int      // nil
var arr [3]int  // [0, 0, 0]
var sl []int    // nil（但 len=cap=0，append 可用）
var m map[int]string // nil
```

## 类型转换

Go **没有**隐式类型转换——必须显式转换：

```go
var a int = 10
var b int64 = int64(a)      // int → int64
var c float64 = float64(a)  // int → float64
var d int = int(c)          // float64 → int（截断小数）

// 字符串与整数互转（需 strconv）
import "strconv"
s := strconv.Itoa(100)      // int → string "100"
n, _ := strconv.Atoi("42") // string → int 42
n2, _ := strconv.ParseInt("ff", 16, 64) // 进制转换
```

> **最佳实践**：不同数值类型之间必须显式转换，哪怕都是整数类型。

## `_` 下划线（匿名占位符）

```go
// 忽略函数返回值
value, _ := strconv.Atoi("42")

// 忽略 range 索引
for _, v := range slice {
    fmt.Println(v)
}

// 导入包仅执行 init
import _ "image/png"
```

## 变量作用域

```go
// 包级别变量
var global = "outer"

func main() {
    // 局部变量覆盖包级别
    global := "inner"    // 新变量，不是赋值
    fmt.Println(global)  // "inner"
}
```
