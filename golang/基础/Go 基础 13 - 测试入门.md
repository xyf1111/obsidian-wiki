# Go 基础 13 - 测试入门

> 原文：[https://xyf1111.github.io/go-study-13/](https://xyf1111.github.io/go-study-13/)

## 测试基本规则

| 规则 | 说明 |
|------|------|
| 文件名 | `*_test.go`（如 `math_test.go`） |
| 函数名 | `TestXxx(t *testing.T)`（Xxx 大写开头） |
| 运行命令 | `go test` / `go test -v` / `go test ./...` |
| 运行单个 | `go test -v -run TestAdd` |
| 失败函数 | `t.Errorf`（非 fatal）或 `t.Fatalf`（立即退出） |

### 第一个测试

```go
// math.go
func Add(a, b int) int {
    return a + b
}

// math_test.go
func TestAdd(t *testing.T) {
    result := Add(2, 3)
    if result != 5 {
        t.Errorf("Add(2, 3) = %d; want 5", result)
    }
}
```

## Table Driven Test（表格驱动测试）

Go 推荐的测试模式——用结构体切片定义多组输入/预期：

```go
func TestAdd(t *testing.T) {
    tests := []struct {
        name string       // 用例名称
        a, b int
        want int
    }{
        {"positive", 2, 3, 5},
        {"negative", -1, -2, -3},
        {"zero", 0, 0, 0},
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            if got := Add(tt.a, tt.b); got != tt.want {
                t.Errorf("Add(%d, %d) = %d; want %d", tt.a, tt.b, got, tt.want)
            }
        })
    }
}
```

> 表格驱动测试让添加新用例变得非常容易，只需在 `tests` 切片中加一行。

## 子测试（Subtests）

- **并行测试**：`t.Parallel()` 标记子测试可并行运行
- **清理**：`t.Cleanup(func(){...})` 注册清理函数（无论测试成功还是失败都会执行）
- **跳过**：`t.Skip("reason")` 跳过测试

```go
func TestDatabase(t *testing.T) {
    // 跳过条件测试（比如 CI 环境没有数据库）
    if testing.Short() {
        t.Skip("Skipping database test in short mode")
    }

    tests := []struct{ ... }{...}
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            t.Parallel()       // 并行运行
            // ... test logic
        })
    }
}
```

## 辅助函数（Helper）

用 `t.Helper()` 标记辅助函数，出错时显示调用者的行号：

```go
// ❌ 不标记 Helper：报错指向 helper 函数内部
func assertEqual(t *testing.T, got, want int) {
    if got != want {
        t.Errorf("got %d, want %d", got, want)
    }
}

// ✅ 标记 Helper：报错指向调用 helper 的那一行
func assertEqual(t *testing.T, got, want int) {
    t.Helper()
    if got != want {
        t.Errorf("got %d, want %d", got, want)
    }
}
```

## Benchmark（基准测试）

```go
func BenchmarkAdd(b *testing.B) {
    for i := 0; i < b.N; i++ {
        Add(2, 3)
    }
}
```

```bash
# 运行基准测试
go test -bench=. -benchmem

# 输出示例：
# BenchmarkAdd-8    1000000000    0.25 ns/op    0 B/op    0 allocs/op
# 说明：CPU 8核，10亿次，每次 0.25ns，0 内存分配
```

## Example 函数

`Example` 函数的内容会与注释中的 `// Output:` 对比：

```go
func ExampleAdd() {
    result := Add(2, 3)
    fmt.Println(result)
    // Output: 5
}
```

- 也可用于生成文档示例
- 示例名称使用 `Example` / `ExampleXxx` / `Example_type` / `Example_type_method`

## 常用测试模式

### mock 外部依赖

```go
// 用接口隔离外部依赖
type UserStore interface {
    GetUser(id int) (*User, error)
}

// 测试时传入 mock
type mockStore struct{}
func (m *mockStore) GetUser(id int) (*User, error) {
    return &User{Name: "Test"}, nil
}
```

### 临时目录

```go
func TestWriteFile(t *testing.T) {
    dir := t.TempDir()        // 自动清理
    path := filepath.Join(dir, "test.txt")
    os.WriteFile(path, []byte("hello"), 0644)
    // ...
}
```

### 测试 HTTP 服务

```go
func TestHandler(t *testing.T) {
    handler := func(w http.ResponseWriter, r *http.Request) {
        fmt.Fprint(w, "hello")
    }
    req := httptest.NewRequest("GET", "/", nil)
    w := httptest.NewRecorder()
    handler(w, req)
    resp := w.Result()
    body, _ := io.ReadAll(resp.Body)
    fmt.Println(string(body)) // "hello"
}
```

## 最佳实践

1. **测试文件放在与被测代码相同的目录**
2. **测试包名用 `xxx_test`**（外部测试包，避免循环导入）
3. **优先 Table Driven Test**
4. **用 `t.Helper()` 标记辅助函数**
5. **对外部依赖使用接口 + mock**
6. **运行 `go test -race` 检测竞态条件**
