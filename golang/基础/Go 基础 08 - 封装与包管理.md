# Go 基础 08 - 封装与包管理

> 原文：[https://xyf1111.github.io/go-study-08/](https://xyf1111.github.io/go-study-08/)

## 封装（Encapsulation）

Go 通过**命名可见性**来实现封装，没有 `private`/`public` 关键字：

### 可见性规则

| 命名约定 | 可见性 | 示例 |
|---------|--------|------|
| **首字母大写** | 公共（跨包访问） | `fmt.Println`、`strings.Builder` |
| **首字母小写** | 私有（包内可见） | `json.encoder`、`http.newServer` |

```go
package mypackage

// 公共：其他包可以访问
var PublicName = "accessible"
func PublicFunc() {}

// 私有：只在 mypackage 内可见
var privateName = "hidden"
func privateFunc() {}
```

### 封装的应用场景

- **隐藏实现细节**：避免外部依赖内部实现
- **保证数据完整性**：通过 getter/setter 控制访问
- **降低耦合**：只暴露必要的 API

```go
type Counter struct {
    value int  // 私有字段
}

// 公共方法控制对私有字段的访问
func (c *Counter) Increment() { c.value++ }
func (c *Counter) Value() int { return c.value }
```

## 包（Package）

### 基本规则

- **每个目录一个包**（一个目录下所有 `.go` 文件属于同一个包）
- **包名小写**，通常与目录名一致
- **`main` 包**包含可执行入口 `func main()`
- **为结构定义的方法必须放在同一个包内**

### 目录结构

```
mymodule/
├── go.mod
├── main.go              // package main
├── handler/
│   ├── handler.go       // package handler
│   └── handler_test.go  // 测试文件，测试包允许 _test 后缀
└── model/
    └── user.go          // package model
```

### 导入方式

```go
import (
    "fmt"                               // 标准库
    "mymodule/handler"                  // 项目内部包
    "github.com/gin-gonic/gin"          // 第三方包
    mydb "mymodule/database"            // 导入别名
    _ "image/png"                       // 匿名导入（仅执行 init）
)
```

### 导入路径与包名

```go
// 导入路径是 module path + 目录路径
// 包名通常是目录名，但不是强制的

// 导入路径：github.com/user/project/handler
// 包名：通常为 handler（以目录名结尾）
import "github.com/user/project/handler"
```

## init 函数

```go
package config

var AppName string

func init() {
    // 包初始化时自动执行，每个包可以有多个 init
    // 执行顺序：依赖包 init → 当前包 init
    AppName = "MyApp"
}
```

- 每个文件可以有多个 `init()`
- 按**编译顺序**执行（同一个包内按文件名排序）
- 主要用于：注册驱动、初始化配置、设置默认值

## 内部包（Internal Package）

```
project/
├── internal/           // 只能被 project 内部（父目录）导入
│   └── auth/
│       └── jwt.go
├── api/
│   └── handler.go      // ✅ 可以导入 internal/auth
└── cmd/
    └── main.go         // ✅ 可以导入 internal/auth
```

## 循环导入

Go **禁止**循环导入。如果 `package A` 导入 `package B`，`B` 不能再导入 `A`：

```
❌ package A → package B → package A
```

**解决办法**：提取公共类型到第三个包。

## 最佳实践

1. **包名简洁** — 单数名词，小写，无下划线
2. **避免 `util`、`common`** — 语义模糊，容易变成垃圾桶
3. **文件名有含义** — `user_store.go` 比 `lib.go` 好
4. **包内文件职责清晰** — 不要把所有代码塞进一个文件
5. **测试文件** — `_test.go` 结尾，与被测文件同目录
6. **内部实现** — 不要暴露不需要暴露的符号
