## 第六阶段：工程实践

### 6.1 项目结构

```
myproject/
├── cmd/             # 入口
│   └── server/
│       └── main.go
├── internal/        # 私有代码
│   ├── handler/
│   ├── service/
│   ├── repository/
│   └── model/
├── pkg/             # 可导出的公共库
├── api/             # API 定义（proto / OpenAPI）
├── config/          # 配置
├── migrations/      # 数据库迁移
└── go.mod
```

### 6.2 依赖注入

| 工具 | 类型 | 说明 |
|------|------|------|
| **wire** | 编译时 DI | Google 出品，代码生成，推荐 |
| **fx** | 运行时 DI | Uber 出品，全功能框架 |
| **dig** | 运行时 DI | Uber 出品，轻量级 |

### 6.3 可观测性

| 观测维度 | Go 工具 | 说明 |
|---------|---------|------|
| **Log** | `log/slog` | 标准库结构化日志 |
| **Metric** | `expvar` / `prometheus` | 指标采集 |
| **Trace** | `OpenTelemetry` | 分布式追踪 |
| **Profile** | `pprof` / `trace` | 性能分析 |

1. **基础已扎实** — Go 基础 21 篇 + 并发 9 篇 + 底层 10 篇 + 进阶 14 篇 = **54 篇笔记**
