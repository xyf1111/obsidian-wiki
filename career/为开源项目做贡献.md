# 为开源项目做贡献

参与开源项目贡献（提交 PR）的完整流程：找项目 → 克隆 → 关联上游 → 新建分支开发 → 提交 PR → 等待评审。

## 1. 找项目

在 GitHub / Gitee 上寻找自己感兴趣的项目。示例：[liyupi/yuindex](https://github.com/liyupi/yuindex)（Vue 3 + Node.js 全栈项目）。

## 2. 克隆到本地

两种方式任选：

1. 命令行克隆：

```bash
git clone <仓库地址>
```

2. 用 IDE（如 IDEA）直接 clone 项目，在弹窗中填写项目地址。

## 3. 关联上游源项目

在 IDE 中打开项目，进入 Terminal 操作：

```bash
# 查看所有远程库地址
git remote -v

# 添加 upstream（源项目仓库）
git remote add upstream <源项目URL>

# 再次查看确认
git remote -v

# 拉取上游最新代码
git fetch upstream
```

> ⚠️ **注意事项**：每次开发新功能前，先从上流（upstream）拉取最新代码，然后**新建分支**进行开发。

## 4. 提交与 PR

在新分支上开发好功能后，先提交到自己的本地仓库，再在仓库页面创建 PR：

- 选择要提交的分支（自己的分支）
- 选择要合并到的源仓库分支

## 5. 等待评审

等待仓库审核者的测试和评审，**及时查看审核者的评论，对自己的 PR 负责**。

## 6. 踩坑：同一分支多次提交

如果在同一个分支上多次提交，第二次提交会带上前面的内容。解决方案：用新的提交（或 `git commit --amend` / `git push --force` 修正）保持 PR 分支干净，让审核者只看到本次改动。
