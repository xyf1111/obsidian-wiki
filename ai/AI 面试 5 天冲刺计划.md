# AI 应用工程师 · 5 天冲刺（面试可交付版）

> 定位：不是「学会 AI」，是**5 天后能用 AI 应用工程师的身份坐在面试桌前**。
> 你有 7 年后端底子（Go/PHP、MySQL/Redis/ES、MQ、WebSocket、直播/支付/游戏），这是最大优势——面试官对你的期待是「能把 LLM 接进真实业务」，不是「会推公式」。

---

## 〇、先做减法：这 5 天明确不学的东西

| 放弃 | 原因 |
|------|------|
| Transformer 数学推导、反向传播 | 应用岗不考，问到就答「注意力机制本质是加权求和 + QKV 三矩阵」 |
| 自己训练模型、分布式训练、CUDA | 12 周计划里才碰，5 天不碰 |
| 论文精读（除 RAG/ReAct 两篇） | 只读 2 篇，够撑面试 |
| Python 深度（装饰器/元类/asyncio 源码） | 你写过后端，语法 1 小时够；重点在 API 调用与工程结构 |
| 前端/多模态/语音 | 与目标岗位无关 |

**必学四块（面试 90% 的题都在这）**：
1. **Prompt 工程 + 结构化输出 + Function Calling**
2. **RAG 全链路**（最难也最常问，Day2 主攻）
3. **Agent / 工具调用 / 工作流**
4. **工程化 + 部署 + 微调概念**（只要概念 + 跑通一次）

## 一、5 天日程表（全职版：每天 9h）

### Day 1｜地基：API 工程 + Prompt 体系

| 时段 | 内容 | 产出 |
|------|------|------|
| 09:00-11:00 | LLM 应用全景：token/上下文窗口/温度/top_p/流式/计费；对比 DeepSeek、Qwen、豆包、OpenAI 的 API 差异 | 一份 provider 对比表（价格/上下文/能力） |
| 11:00-12:30 | 结构化输出（JSON Schema）+ **Function Calling 手写一遍**（不用框架，裸 HTTP） | 能跑通的 `tools` 调用 demo |
| 14:00-16:00 | Prompt 工程：CoT、Few-shot、角色设定、分隔符、注入防护；改写 5 个真实业务提示词 | 10 条业务提示词模板 |
| 16:00-18:00 | **项目1 起步**：文档解析（PDF/MD）→ 语义切分 → 向量化入库 | RAG v0：能问答（准确率不用管） |
| 19:30-21:00 | 读 llm-universe 第 1-3 章对答案 | 笔记 + 疑问清单 |

> 面试可用话术：*「我用裸 HTTP 手写过 Function Calling，所以知道框架帮我做了什么。」*

### Day 2｜RAG 深水区（面试第一战场）

| 时段 | 内容 | 产出 |
|------|------|------|
| 09:00-10:30 | 切分策略：固定长度/语义/父子文档/按标题层级；元数据设计（来源、时间、权限） | 三种切分方案对比实测 |
| 10:30-12:00 | Embedding 选型（bge-m3 / text-embedding-3 / Qwen-embedding）+ 向量库（pgvector/Qdrant/Milvus 选型理由） | 选型对比表（含成本） |
| 14:00-16:00 | **混合检索**：BM25 + 向量 + Rerank（bge-reranker）；查询改写（多轮/ HyDE） | 检索模块 v2 |
| 16:00-18:00 | 生成层：上下文压缩、**引用溯源**、幻觉抑制、拒答策略 | 带角标引用的问答 |
| 19:30-21:30 | **建 30 条评测集**，跑召回率/命中率，调参到 80%+ | 项目1 完成 + 评测报告 |

> 这一天决定面试成败。「召回率从 6x% 提到 8x%」的故事必须能讲。

## 四、项目包装模板（直接往里填）

```
项目：企业知识库智能问答（RAG）
背景：公司 X 类文档 Y 篇散落在多个系统，人工查找平均 15 分钟/次
方案：PDF/Word 解析 → 按标题层级切分（父块 800 字 + 子块 200 字）
      → bge-m3 向量化 → pgvector 存储 + BM25 混合检索 → bge-reranker 重排
      → LLM 生成 + 强制引用溯源 + 低置信度拒答
难点：① 表格/跨页内容切裂导致答非所问 → 父子块 + 表格专用解析
      ② 纯向量检索对编号/专有名词召回差 → 引入 BM25 混合，召回率 62%→85%
      ③ 幻觉 → 引用强制 + 无引用不答
结果：Top5 召回率 85%，答案采纳率 78%，查询耗时从 15 分钟降到 20 秒
```

> 面试官最想听的不是「我用了什么」，而是「**哪里坏了、你怎么查出来、怎么修好的**」。第 2 条难点就是你的杀手锏。

## 六、5 天后的面试预期

| 岗位层级 | 5 天冲刺后成功率 | 说明 |
|---------|----------------|------|
| AI 应用开发（16K） | **中高** | RAG + Agent + 后端工程，正好匹配 |
| 大模型算法（20K+） | 低 | 需要数学与训练经验，5 天补不出来 |
| AI 产品/解决方案 | 高 | 你的业务理解 + Demo 能力正好 |

> 结论：**5 天够拿下「AI 应用工程师」面试，不够拿算法岗。** 投递时把简历关键词对准应用侧。
