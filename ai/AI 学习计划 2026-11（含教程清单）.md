# AI 应用工程师 · 12 周学习计划

> 说明：昨晚口述版计划未落盘（会话记录丢了一部分），本版是**按你的 AI 版简历重搭**的可执行版本——目标岗位「AI 工程师 / 大模型应用开发」、期望 16K。
> 已有底子（不算零基础）：豆包大模型 API 接入、提示词工程做流程化开发、LangChain、RAG、向量库、7 年后端（Go/PHP）。所以计划**跳过 Python 基础和大模型原理科普**，直奔工程落地。

---

## 一、目标与策略

| 项目 | 设定 |
|------|------|
| 目标岗位 | AI 应用工程师 / 大模型应用开发（后端转岗） |
| 周期 | 12 周（约 3 个月），每天 1.5-2h + 周末各 4h ≈ 每周 15h |
| 总产出 | **3 个可写简历的项目** + 1 份技术博客系列 + 面试题库 |
| 核心策略 | 不追算法原理，主打「**后端工程能力 + LLM 应用落地**」——这是你相对算法岗的最大优势 |
| 差异化 | 用已有真实业务（商城/小游戏/小说平台）做 AI 改造，比人人都在做的「文档问答 demo」更有说服力 |

---

## 二、四阶段总览

| 阶段 | 周次 | 主题 | 核心产出 |
|------|------|------|---------|
| 一 | W1-W3 | LLM 应用基础 + Prompt 工程体系化 | 提示词模板库 + 一个带 Function Calling 的 CLI 工具 |
| 二 | W4-W7 | RAG 全链路（企业级） | **项目1**：多格式知识库问答（切分/混合检索/重排/评测） |
| 三 | W8-W10 | Agent 与工作流编排 | **项目2**：多工具 Agent（含 MCP/工具注册/沙箱执行） |
| 四 | W11-W12 | 微调 + 部署优化 + 面试冲刺 | **项目3**：LoRA 微调 + vLLM 部署；简历与题库 |

## 三、周计划（可直接照做）

| 周 | 学习内容 | 产出物 | 验收标准 |
|----|---------|--------|---------|
| W1 | LLM API 生态对比（OpenAI/Claude/DeepSeek/Qwen/豆包）、流式输出、token 计费、结构化输出（JSON Schema）、Function Calling | 统一 `llm-client` 封装（Go 或 Python 任选，重试/超时/降级/计费统计） | 能切换 3 家 provider，跑通流式 + 结构化输出 |
| W2 | Prompt 工程体系化：CoT、Few-shot、ReAct、自洽性、提示词评测；GPT-4 时代的提示词组织法 | 提示词模板库（20+ 场景）+ 提示词 A/B 评测脚本 | 同一任务两版提示词能跑出可量化对比 |
| W3 | 国内大模型生态：模型选型、上下文长度、价格、私有化部署（Ollama 本地跑 Qwen） | CLI 工具：自然语言 → 调用本地/云端模型 → 执行工具（查天气/读文件） | 工具调用成功率 > 90%，有错误兜底 |
| W4 | RAG 原理 + 文档处理：PDF/Markdown/HTML 解析、语义切分策略、元数据设计 | 文档摄入流水线（去重、分层切分、元数据标签） | 100 篇文档摄入 < 5 分钟，切分质量人工抽查 20 条 |
| W5 | 向量库选型（Milvus/Qdrant/pgvector/Chroma）+ 混合检索（BM25 + 向量）+ Rerank | 检索模块 v1（混合检索 + 重排） | 召回率对比纯向量提升 ≥ 20% |
| W6 | 生成层工程化：上下文压缩、引用溯源、幻觉抑制、多轮改写；工程侧：缓存、限流、异步 | **项目1 完成**：企业知识库问答（Web + API） | 有引用角标、有评测报告、能部署上线 |
| W7 | RAG 评测体系：RAGAS/自定义评测集、badcase 归因、迭代 | 评测报告 + 技术博客《我如何把 RAG 召回率从 62% 提到 85%》 | 有数据、有图表、可复现 |
| W8 | Agent 基础：ReAct、规划-执行、工具注册、状态管理；LangGraph / 原生实现二选一 | Agent 骨架（工具注册表 + 会话状态机） | 3 个工具串联任务跑通 |
| W9 | MCP 协议、多 Agent 协作、沙箱执行（代码解释器）、可观测（trace/日志） | **项目2 完成**：多工具 Agent（带 trace 面板） | 能完成「查数据→算指标→出报告」端到端任务 |
| W10 | 工作流编排平台对比（Dify/RAGFlow/n8n/FastGPT）+ 用它把项目2 重搭一遍 | 编排版 Demo + 对比博客 | 说清「自研 vs 平台」的取舍 |
| W11 | 微调入门：SFT/LoRA/QLoRA、数据构造、训练框架（LLaMA-Factory）、评测 | **项目3**：LoRA 微调小模型（如 Qwen2.5-1.5B 做领域任务） | 微调后任务准确率相对 base 提升 ≥ 10% |
| W12 | 部署与推理优化（vLLM/Ollama/量化）、压测、成本测算；简历重写 + 面试题库 | 简历 3.0 + 60 道 AI 面试题 + 3 个项目 README | 简历过 ATS 关键词检查；能白板讲清 RAG/Agent 全链路 |

## 六、每周节奏建议（在职版）

| 时间 | 安排 |
|------|------|
| 工作日早 30min | 读文档/论文（碎片时间，用手机也行） |
| 工作日晚上 1-1.5h | 写代码（跟周计划的产出物走） |
| 周六 4h | 整块攻坚（难点、调试、部署） |
| 周日 2h | 写技术博客 + 整理本周笔记进 Obsidian |

**三条铁律**：
1. **每周必须有产出物**，没有产出的一周等于没学（面试讲不出东西）
2. **先跑通再深挖**，别在原理上卡超过 2 天
3. **每周一篇博客**，12 周后就是 12 篇的技术沉淀，比简历更有说服力

## 七、面试高频关键词（背熟这 40 个）

**RAG**：切分策略、Embedding 选型、混合检索、Rerank、召回率/精确率、上下文压缩、幻觉抑制、引用溯源、RAGAS 评测
**Agent**：ReAct、Function Calling、MCP、工具注册、状态机、多 Agent 协作、沙箱执行、trace 可观测
**Prompt**：CoT、Few-shot、结构化输出、提示词注入防护、越狱与防御
**工程**：token 计费、流式输出、限流降级、缓存命中、向量库选型、并发与异步、成本测算
**微调**：SFT、LoRA/QLoRA、数据构造、灾难性遗忘、评测集设计
**部署**：vLLM、PagedAttention、量化（GPTQ/AWQ）、显存估算、QPS 压测
