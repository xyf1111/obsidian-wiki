# AI 大模型 - AI 生成 PPT 与思维导图实战（ChatGPT + MindShow）

> 用 ChatGPT 生成 Markdown 格式内容，再导入 MindShow 等工具一键转成 PPT 或思维导图：2 分钟搞定汇报演示文稿。

## 适用场景

被要求给团队做技术分享 PPT（如讲解 Nginx）、懒得选模板调格式时：**AI + PPT 生成工具**组合，2 分钟完成「写内容 → 做 PPT」全流程。

## 操作流程

### 1. 用 ChatGPT 生成内容

先让 ChatGPT 生成一篇图文教程/文章，**明确要求输出 Markdown 格式并区分小标题**——结构化输出是后续一键转 PPT 的前提。

### 2. 导入 PPT 生成工具（MindShow）

- 打开 PPT 生成工具（如 `MindShow`，免费）
- 点击导入，把生成的 Markdown 文章粘贴进去
- 点击「导入创建」，直接得到一份 PPT
- 支持免费下载 PDF 和 PPTX 格式

### 3. 调整布局

工具内置多种布局模板，可给每一页选择不同的布局，按需微调即可交付。

## 延伸：思维导图同理

生成思维导图是同样的原理：把 ChatGPT 生成的 Markdown 文章导入 XMind 等思维导图软件，自动生成结构化的导图。

## 要点

- **给 AI 提要求越具体，输出越可用**：指定 Markdown 格式、要求区分小标题，后续工具才能正确解析结构
- 同样的思路可迁移到其他内容形态（文档、导图、网页骨架），核心是「AI 产出结构化文本 → 工具消费」
