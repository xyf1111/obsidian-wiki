# 大数据 01 - 基础概念与特征

> 数据大 ≠ 大数据：大数据是以 4V 特征（体量大、多样性、高速性、价值）为核心的信息资产，需经收集、预处理、存储、分析、应用全流程并依赖完整技术生态。

## 什么是大数据？

大数据是高科技信息化时代的产物，本身是一个抽象的概念，通常指**数据量大、数据类型复杂、且无法在一定时间范围内用传统软件工具和方法进行收集、存储、管理和处理的数据集合**，是需要使用新的处理模式才能激发利用其价值的信息资产。

「数据大一点、多一点」不等于大数据——**体量大只是大数据最明显的特征之一**。

## 大数据的特征（4V → 8V）

公认的大数据特征可用 **4V** 概括：

| 特征 | 说明 |
|------|------|
| 体量大（Volume） | 数据采集、存储和计算量都很大，计量单位通常为 PB（1000 TB）、EB（1000 PB）甚至 ZB（1000 EB） |
| 多样性（Variety） | 数据种类和来源多样，包括结构化、半结构化和非结构化数据（网络日志、音视频、图片、地理位置等），需分类处理，对处理能力要求高 |
| 高速性（Velocity） | 数据增长速度快、时效性要求高，经常需要实时处理（如打开 App 浏览信息后系统实时推荐相似内容），是区别于传统数据的显著特征 |
| 价值（Value） | 数据量大但价值密度相对较低，如何用强大算法挖掘数据价值是大数据时代最需要解决的问题 |

随着技术发展不断有新特征被提出，从 4V 扩展到 5V、6V、7V、8V：

- **准确性（Veracity）**：数据质量影响分析结果，必须过滤无用、恶意信息，提高数据准确性
- **可视化（Visualization）**：将数据以图表等更易理解的方式展示，提升分析效率
- **合法性（Validity）**：数据采集和应用必须合法，如合理使用个人隐私数据
- **可变性（Variability）**：数据是可变化的，相同数据在不同上下文中可能含义不同，必须结合上下文分析

## 大数据处理流程

数据从诞生到被应用需经历漫长旅途：数据收集、数据预处理、数据存储、数据处理与分析、数据展示与数据应用，之后还有数据治理、持续改进等环节。

1. **数据收集**：利用软硬件技术将分散、多样、海量的数据采集起来，如无线和传感器采集、从数据库、网络 API、文件采集等
2. **数据预处理**：对原始数据进行清洗、填补、去噪、转换、合并、规格化、一致性检验等操作，提高数据质量
3. **数据存储**：持久化存储采集到的数据，通常存于分布式文件系统或数据仓库等易扩展的存储系统，并通过数据副本备份
4. **数据分析处理**：从杂乱无章的大量数据中找出有用信息和规律，可结合数据挖掘、人工智能算法；按实时性分为离线分析、实时分析和流式数据分析，需选用不同技术架构
5. **数据可视化或数据应用**：将分析结果可视化展示，或应用到其他系统中

## 大数据技术生态

大数据生态体系庞大，每个流程基本都有现成框架和系统，开箱即用。知名技术按环节分类：

| 环节 | 技术 |
|------|------|
| 数据同步 | Sqoop |
| 日志收集 | Flume、Scribe、Logstash、Kibana |
| 消息系统 | Kafka、StormMQ、ZeroMQ |
| 数据存储 | HDFS、HBase、Redis |
| 离线计算 | MapReduce、Spark |
| 流式计算 | Storm、Spark Streaming |
| 资源管理 | YARN、Mesos |
| 查询分析 | Hive、Impala、Pig、Presto、Phoenix、SparkSQL、Drill、Flink、Kylin、Druid |
| 集群管理与监控 | Ambari、Cloudera Manager |
| 任务调度 | Oozie |
| 数据挖掘、机器学习 | Mahout、Spark MLlib |

## 应用场景

大数据广泛应用于互联网、金融、电商、零售、医疗、生物、制造、智慧城市等各行各业，例如：浏览淘宝时的商品内容推荐、针对性广告投放、信贷风险分析、疾病预测、优化生产过程能耗、智能规划交通、为用户提供定制生活服务等。

近年来大数据技术生态不断完善，初步形成较完整的产业链，更多应用落地创造价值，持续赋能传统产业与产业互联网发展。
