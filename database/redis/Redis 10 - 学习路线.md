# Redis 10 - 学习路线

> Redis（Remote Dictionary Server）是开源的高性能内存键值（K/V）存储系统，读写速度极快（单机可达 10 万 QPS 以上），支持字符串、哈希、列表、集合、有序集合等多种数据结构。除了缓存外，还可用于配置存储、消息队列、分布式锁、分布式 Session 等场景，是后端开发必不可少的中间件；在 AI 时代还可用于数据缓存、向量存储、实时计算、AI 模型推理加速等场景。

> 学习前提：建议先学完一套开发框架（如 SSM、Spring Boot）再学习 Redis，便于理解实际项目中的应用场景；前端同学暂时不需要学习。

> 就业方向：掌握 Redis 可胜任 Java/Go/Python 后端开发工程师、架构师等岗位（Redis 只是所需技能之一，还需掌握更多技能）。

## 整体学习建议

1. **先会用再深入原理** — 先学会安装、基本命令、数据结构，在项目中实践，最后再深入底层原理；不要一上来就研究源码，容易打击学习积极性
2. **多敲命令多写代码** — 常用命令跟着教程敲一遍，忘了就查文档或问 AI；把 Redis 实际应用到项目中（加缓存、实现分布式锁），印象会更深刻
3. **重点学习缓存设计** — 缓存是 Redis 最核心的应用场景，重点学习缓存设计模式与缓存问题（穿透、击穿、雪崩）及解决方案，这是面试高频考点
4. **学完实战部分就够用** — 初学后端的同学学完阶段 2（实战应用）即可应对大部分项目需求；面试前再补高级知识和原理
5. **善用 AI 辅助学习** — 遇到不懂的概念（如 RDB、AOF、主从复制），可让 AI 工具用通俗语言解释，或帮你生成 Redis 命令
6. **整理最佳实践笔记** — 键值设计、客户端优化、服务端优化等最佳实践重点学习并整理笔记，养成好的设计和编码习惯

## 阶段 1：Redis 基础入门（3-7 天，仅供参考）

### 学习目标

理解 Redis 的基本概念和特点，掌握 Redis 的安装和基本操作，熟练使用五种基本数据结构，能够通过 Java/Python 等编程语言操作 Redis。

### 知识点

- **基础概念【必学】**：Redis 是什么；SQL 和 NoSQL 的区别；特点（高性能、多种数据结构、持久化、主从复制等）；应用场景（缓存、Session 存储、消息队列、分布式锁等）
- **安装和配置【必学】**：Windows/Linux/Mac/Docker 安装；启动和连接；redis.conf 配置文件；常用命令行操作
- **基本数据结构【必学，面试重点】**：
  - String（字符串）：存储字符串、数字、二进制数据 — SET、GET、INCR、DECR、APPEND
  - Hash（哈希）：类似 HashMap，适合存储对象 — HSET、HGET、HMSET、HMGET、HGETALL
  - List（列表）：有序字符串列表，两端插入弹出 — LPUSH、RPUSH、LPOP、RPOP、LRANGE
  - Set（集合）：无序不重复集合 — SADD、SMEMBERS、SISMEMBER、SINTER、SUNION
  - SortedSet（有序集合）：元素关联 score 分数 — ZADD、ZRANGE、ZRANGEBYSCORE、ZREM
- **通用命令【必学】**：键操作 KEYS、EXISTS、DEL、EXPIRE、TTL；数据库切换 SELECT；清空数据库 FLUSHDB、FLUSHALL
- **客户端【必学】**：Java（Jedis、Spring Data Redis/RedisTemplate【必学】、Lettuce、Redisson）；Python（redis-py）；Go（go-redis）
- **可视化工具【建议学】**：Redis Insight（官方推荐）、Quick Redis、RedisDesktopManager（RESP）

### 学习重点

1. 基础入门要动手实践，本地安装 Redis，把每个命令都敲一遍
2. 五种基本数据结构是核心，理解每种结构的特点和使用场景（面试常问"什么场景用什么数据结构"）
3. 客户端选择：Java 推荐 Spring Data Redis（RedisTemplate），Python 推荐 redis-py，Go 推荐 go-redis
4. 学完基础后立即在项目中使用 Redis，比如给查询结果加个缓存，效果立竿见影

## 阶段 2：Redis 实战应用（10-20 天，仅供参考）

### 学习目标

掌握 Redis 实战应用技巧，能够解决实际项目中的缓存、分布式锁、消息队列等问题，理解并解决常见缓存问题（穿透、击穿、雪崩）。

### 知识点

- **缓存设计【必学，面试重点】**：
  - 缓存更新策略：Cache Aside（旁路缓存）【必学】；Read Through / Write Through、Write Behind（异步缓存写入）【建议学】
  - 缓存穿透：查询不存在的数据导致请求直接打到数据库 — 布隆过滤器、缓存空对象、参数校验
  - 缓存击穿：热点数据过期，大量请求同时访问数据库 — 互斥锁、逻辑过期、热点数据永不过期
  - 缓存雪崩：大量缓存同时过期导致数据库压力剧增 — 过期时间加随机值、多级缓存、服务降级
  - 缓存预热、多级缓存架构【建议学】
- **分布式应用【必学】**：分布式 Session 存储；分布式全局唯一 ID 生成（雪花算法、Redis INCR）；分布式锁（SET NX EX 实现原理、Redisson 使用、死锁/锁超时等问题及解决方案、红锁 RedLock【可不学】）
- **高级数据结构【建议学】**：GEO（附近的人、附近店铺）；Bitmap（签到统计、在线用户统计）；HyperLogLog（UV 去重计数）；Bloom Filter 布隆过滤器（缓存穿透解决方案）
- **消息队列【建议学】**：Pub/Sub（发布订阅）、Stream（流）、List 实现简单消息队列
- **Lua 脚本【建议学】**：原子性操作；在 Redis 中使用 Lua；用 Lua 实现秒杀、限流
- **其他实战应用【建议学】**：Feed 流（关注推送）；事务（MULTI、EXEC）；点赞、收藏、关注功能实现

### 学习重点

1. 缓存设计是 Redis 最核心的应用，三大问题（穿透、击穿、雪崩）是面试必考，要理解问题的本质和解决方案
2. 分布式锁是重要应用场景，建议通过实战项目学习，从简单到复杂、从单机到集群系统掌握
3. Redisson 封装了分布式锁、分布式集合等分布式场景解决方案，建议重点学习
4. 多级缓存架构（Redis + Caffeine 本地缓存）是企业级应用标配，可大幅提升系统性能

### 学习资源

## 阶段 3：Redis 高级特性和原理（10-15 天，仅供参考）

> 这部分内容相对较深，初学者可在学完前 2 个阶段后先去学习其他后端技术（消息队列、微服务等），面试前再回头补这部分。

### 学习目标

理解 Redis 的持久化机制、主从复制原理、哨兵和集群的工作原理，了解底层数据结构和网络模型，能够设计高可用的 Redis 架构。

### 知识点

- **最佳实践【必学】**：键值设计规范（命名规范、避免大 Key、选择合适的数据结构）；客户端优化（连接池配置、批量操作、Pipeline）；服务端优化（内存优化、慢查询分析）
- **持久化【必学，面试重点】**：RDB（快照）定时将内存数据快照保存到磁盘；AOF（追加文件）记录每个写操作、重启时重新执行；RDB 和 AOF 对比及选择；混合持久化（RDB + AOF）【建议学】
- **主从复制【必学，面试重点】**：原理和作用；全量同步和增量同步；主从集群优化（复制积压缓冲区、复制偏移量）；主从切换【建议学】
- **哨兵 Sentinel【建议学，面试重点】**：作用（监控、自动故障转移）；哨兵集群工作原理；故障转移流程
- **分片集群 Cluster【建议学，面试重点】**：作用（数据分片、高可用）；散列插槽 Hash Slot；集群伸缩（添加/删除节点）；故障转移和数据迁移
- **底层数据结构【建议学】**：SDS 动态字符串、IntSet 整数集合、Dict 字典、ZipList 压缩列表、SkipList 跳表、RedisObject；五种基本数据结构的底层实现
- **网络模型【建议学】**：阻塞 I/O、非阻塞 I/O、I/O 多路复用（epoll）、单线程模型【面试重点】、Redis 6.0 多线程【建议学】
- **其他高级知识【可不学】**：RESP 通信协议；内存淘汰策略（LRU、LFU）【面试重点】；过期策略（定时删除、惰性删除、定期删除）【面试重点】

## 阶段 4：Redis 求职备战（面试前 1 个月突击）

> 不到面试前一个月不要急着背面试题，应先把前 3 个阶段知识学扎实、有了实际项目经验后再突击面试题，效果更好；提前看题巩固知识是 OK 的。

### 学习建议

1. 提前规划，建议至少提前 3 个月开始准备
2. 打磨简历：简历上要有能体现 Redis 能力的项目经历，比如用 Redis 做了什么功能、解决了什么性能问题、如何设计缓存方案
3. 面试题要理解而不是死记硬背：核心考点就那些（缓存设计、分布式锁、持久化、集群等），先理解原理再看题，遇到没见过的题也能答出大概
4. 多看真实面经，了解不同公司的面试风格和常考题目

### 经典面试题

**基础理论：**

1. Redis 是什么？有哪些特点？
2. Redis 为什么这么快？
3. Redis 和 Memcached 的区别？
4. Redis 的数据类型有哪些？分别有什么应用场景？
5. Redis 的单线程模型是什么？为什么单线程还这么快？

**缓存相关：**

1. 什么是缓存穿透、缓存击穿、缓存雪崩？如何解决？【高频】
2. Redis 的缓存更新策略有哪些？
3. 如何保证缓存和数据库的数据一致性？
4. 什么是热点 Key 问题？如何解决？
5. 什么是大 Key 问题？如何解决？

**分布式锁：**

1. 如何用 Redis 实现分布式锁？【高频】
2. Redis 分布式锁有哪些问题？如何解决？
3. Redisson 是如何实现分布式锁的？
4. 什么是红锁（RedLock）？

**持久化和高可用：**

1. Redis 的持久化方式有哪些？RDB 和 AOF 的区别？【高频】
2. Redis 的主从复制是如何实现的？
3. Redis 哨兵的作用是什么？故障转移流程是怎样的？
4. Redis 集群（Cluster）是如何实现的？
5. Redis 集群的数据分片策略是什么？

**底层原理：**

1. Redis 的过期策略有哪些？【高频】
2. Redis 的内存淘汰策略有哪些？【高频】
3. Redis 的底层数据结构是什么？（跳表、压缩列表等）
4. Redis 的 I/O 多路复用是什么？
