# 数据库 03 - Dolt（数据版本控制数据库）

> Dolt 是一个基于 Git 协议的开源 SQL 数据库（Golang 编写），把版本控制能力带到了数据上：既能像 MySQL 一样建表、建视图、增删改查，又能像操作 git 仓库一样对数据 `fork` / `clone` / `branch` / `merge` / `push` / `pull`；官方还提供类 GitHub 的远程托管平台 DoltHub。

## 核心要点

### 背景：数据也能做版本控制

Git 是开源的分布式版本控制系统，让项目代码支持同时存在多个版本和分支，是程序员开发中的必备工具。但除了代码文件，**数据其实也可以做版本控制**——Dolt 项目就曾登上 GitHub 趋势榜榜首，仓库自述为 “Git for Data”（面向数据的 Git）。

### 什么是 Dolt

- **本质**：一个基于 Git 协议的开源 SQL 数据库，使用 Golang 语言编写，由官方提供详细教程，上手比较简单。
- **数据库能力**：和 MySQL 这类关系型数据库一样用于存储和管理数据，具有表、视图等概念，支持数据的增删改查操作。
- **版本控制能力**：提供命令行工具，**完美支持所有 Git 命令且语法完全相同**，允许像使用一个 git 仓库那样对数据进行 `fork`、`clone`、`branch`、`merge`、`push`、`pull` 等操作。
- **提交与审计**：提交数据到存储库时，Dolt 会自动存储提交日志（本次修改的内容、作者、提交时间等），从而实现对数据单元的版本控制，便于多人对数据进行协作和优化。
- **差异与回滚**：可随时查看上次提交的数据与当前数据的区别；一旦有人不小心把公共数据改错，发现数据异常时可以轻松回滚和修复问题。

### DoltHub：数据的远程托管平台

- 正如 Git 有 GitHub 作为代码的开源远程托管平台，Dolt 官方也提供了 **DoltHub**，允许用户把 Dolt 数据库免费托管到官方云存储服务中，便于管理和协作。
- 可以像浏览 GitHub 一样浏览 DoltHub，在上面发现优秀的数据集（如 Coronavirus、Google Open Images 等），拿去实验和数据分析都极好。
- 官网：https://www.dolthub.com/
- 代码仓库：https://github.com/dolthub/dolt

### 典型适用场景

- **教学与实验**：一个班的同学用公共数据做实验时，可能需要针对不同实验提供不同数据，用 Dolt 做数据版本控制即可各取所需。
- **多人协作的数据集**：需要变更审计、随时回滚的公共数据维护场景。
