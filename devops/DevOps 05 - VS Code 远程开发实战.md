# DevOps 05 - VS Code 远程开发实战

> 装一个 Remote-SSH 插件，让 VS Code 像操作本地一样实时浏览、编辑、调试远程服务器上的代码，还支持端口转发和多人同时协作。

## 何为远程开发

远程是相对于本地的。传统开发是本地写好代码再放到服务器上运行；远程开发的特点是：

1. **代码不放在自己电脑上**，而是在远程连接的服务器上
2. **本地实时查看和修改**远程服务器上的代码

> 注意：远程开发 ≠ 远程办公。

实现远程开发的方式有多种，最古老的是远程控制软件；更推荐直接用开发工具自带的远程开发插件，如 JetBrains 全家桶和 VS Code。VS Code 相对轻量易用，本文以它为例实战。

## 环境准备

打开 VS Code，点击左侧扩展按钮，搜索 `remote`，即可看到远程开发相关插件，支持：

- SSH 远程连接
- 连接 Docker 容器
- 连接 Windows 上的 Linux 子系统（WSL）

选择 **Remote - SSH** 插件，点击安装即可。

## 连接远程服务器

1. 按 `ctrl` + `shift` + `p` 打开命令面板，输入 `remote`，找到 **Remote-SSH: Add New SSH Host**
2. 输入要连接的远程服务器的用户名、主机地址（没有服务器的话，在本地启动虚拟机也可以），记得带上 **`-A` 参数**（开启代理转发功能）：`ssh 用户名@主机地址 -A`
3. 选择将该连接信息保存到一个配置文件（SSH config）
4. 点击 **connect** 按钮连接，成功后左侧面板显示「已连接到远程」

## 远程开发体验

### 1. 安装插件

搜索 `remote`，安装 `Remote - SSH` 插件。

### 2. 远程连接

`ctrl` + `shift` + `p` → `Remote-SSH: Add New SSH Host` → 输入 `ssh 用户名@主机地址 -A` → 保存到 SSH config → 点击 connect，左侧面板显示「已连接到远程」。

### 3. 实时浏览远程文件

连接后像操作本地电脑一样浏览远程服务器上的文件，左侧资源管理器可直接查看目录下的文件。

### 4. 远程编辑

直接在编辑器中新建 / 修改远程文件。也可用 XShell 等其他 SSH 连接软件访问同一台服务器、进入同一目录，用 `ls` 查看目录，能看到 VS Code 中新建的文件（如 `test.java`）。

### 5. 实时协作

用 VS Code 和其他 SSH 连接软件（如 XShell）模拟两个用户同时协作编写同一个代码文件：VS Code 写下一行代码 → XShell 打开同一文件立即能看到，在下面再写一行并保存 → 回到 VS Code 能看到全部代码。

### 6. 端口转发

代码在远程、运行也在远程，要看运行效果怎么办？VS Code 提供端口转发功能，配置远程服务器和本地端口的映射，让本地直接访问远程应用：

`ctrl` + `shift` + `p` → 搜索 `forward` → 选择转发端口 → 输入要转发的端口号（应用占用的端口）→ 添加成功后即可在本地访问运行中的项目。

### 7. 远程调试

远程调试与本地调试几乎没有任何区别，可以直接利用 VS Code 本身的代码提示和调试能力。

## 远程开发的好处

1. **省本地电脑资源**：代码运行在远程服务器，多开几个项目也不会卡
2. **多人协同编辑**：提高协作效率
3. **免本地搭环境，快速上手**：不用在本地搭建环境，连上有现成环境和代码的开发机即可直接开发
4. **傻瓜式服务器管理**：不熟悉 Linux 服务器操作的话，可以把远程开发当服务器管理软件用
