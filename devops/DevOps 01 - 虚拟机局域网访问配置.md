# 虚拟机局域网访问配置

> 在宿主机上用虚拟机运行项目服务，配置 NAT 网络和端口转发，使局域网内其他机器可以通过宿主机 IP 访问虚拟机中的服务。

## 网络模式：NAT

NAT 模式是虚拟机共享宿主机 IP 上网的典型方案。宿主机充当路由器，虚拟机流量经 NAT 转发到外部网络；外部机器访问虚拟机服务时，需通过宿主机 IP + 端口转发进入。

**适用场景**：宿主机 IP 固定在同一局域网内，虚拟机不需要独立局域网 IP，外部通过端口转发访问。

## VMware 网络配置（VMnet8）

### 1. 虚拟网络编辑器

- 打开 VMware → **编辑** → **虚拟网络编辑器**
- 选择 **VMnet8**（NAT 模式）
- 点击 **更改设置**（以管理员权限编辑）

### 2. 子网与网关

| 参数 | 示例值 | 说明 |
|------|--------|------|
| 子网 IP | `192.168.95.0` | 虚拟机网段，不要与宿主机局域网冲突 |
| 子网掩码 | `255.255.255.0` | 默认 C 类地址 |
| NAT 网关 | `192.168.95.2` | 虚拟机的默认网关（在 NAT 设置中查看/修改） |

> 注意：子网 IP 避免与宿主机真实局域网段（如 192.168.1.x、192.168.3.x）重复，否则可能路由冲突。

### 3. DHCP 设置

- 查看 DHCP 的 **起始 IP 地址** 和 **结束 IP 地址**
- 虚拟机后续配置的静态 IP **必须落在这个范围内**
- 示例范围：`192.168.95.128` ~ `192.168.95.254`

### 4. 端口转发（NAT 设置）

端口转发使宿主机特定端口接收的流量自动转发到虚拟机指定端口。

| 宿主机端口 | 虚拟机 IP:端口 | 用途 |
|---|---|---|
| 22 | `192.168.95.200:22` | SSH 远程连接虚拟机 |
| 3306 | `192.168.95.200:3306` | MySQL 数据库客户端连接 |
| 8080 | `192.168.95.200:8080` | Web 项目访问（按需添加） |

> **原理**：局域网其他主机 → 宿主机 IP:宿主机端口 → VMware NAT → 虚拟机 IP:虚拟机端口

## CentOS 虚拟机网络配置

### 1. 配置静态 IP

编辑网络配置文件（网卡名称可能不同，用 `ip a` 确认）：

```bash
vi /etc/sysconfig/network-scripts/ifcfg-ens33
```

关键参数：

```ini
BOOTPROTO=static          # 静态 IP，非 dhcp
ONBOOT=yes                # 开机自启
IPADDR=192.168.95.200     # 固定 IP（必须在 DHCP 范围内）
NETMASK=255.255.255.0     # 子网掩码
GATEWAY=192.168.95.2      # 网关 = NAT 设置的网关地址
DNS1=8.8.8.8              # DNS（可选，用于外网访问）
DNS2=114.114.114.114      # 备用 DNS
```

### 2. 重启网络服务

```bash
service network restart
# 或 CentOS 7+
systemctl restart network
```

看到 `OK` 表示配置成功。

### 3. 检查 DNS 配置

```bash
cat /etc/resolv.conf
```

确保 DNS 地址正确（可选步骤，DHCP 通常自动写入）。

## 防火墙规则

**方式一：关闭防火墙（仅限局域网测试环境）**

```bash
systemctl stop firewalld
systemctl disable firewalld
```

**方式二：开放指定端口（推荐）**

```bash
# 开放 SSH
firewall-cmd --permanent --add-port=22/tcp
# 开放 MySQL
firewall-cmd --permanent --add-port=3306/tcp
# 重载使生效
firewall-cmd --reload
# 查看已开放端口
firewall-cmd --list-ports
```

> Windows 宿主机防火墙也需要开放对应的端口转发端口（如 22、3306 等）。

## 网络连通性验证

### 三步验证法

| 测试项 | 命令 | 预期结果 |
|--------|------|----------|
| 虚拟机访问外网 | `ping -c 4 www.baidu.com` | 有响应 |
| 虚拟机 ping 宿主机 | `ping -c 4 宿主机IP` | 有响应 |
| 宿主机 ping 虚拟机 | `ping 192.168.95.200` | 有响应 |

### 宿主机 IP 确认

```bash
# Windows
ipconfig
# 查看使用的网络适配器（以太网或无线）的 IPv4 地址
```

> 宿主机 IP 是局域网内其他机器访问虚拟机的入口地址。

## 局域网访问方式

| 访问目标 | 连接地址 | 说明 |
|----------|----------|------|
| SSH 连接虚拟机 | `ssh user@宿主机IP -p 22` | 经端口转发进入虚拟机 |
| MySQL 客户端 | `宿主IP:3306` | 经端口转发进入虚拟机 MySQL |
| Web 项目 | `http://宿主机IP:8080` | 经端口转发访问虚拟机中的 Web 服务 |

> 实际上访问的是宿主机 IP，VMware NAT 负责将流量转发到虚拟机内部的对应端口。

## 常见问题

- **子网 IP 冲突**：虚拟机网段不要与宿主机所在局域网网段相同，否则路由混乱
- **DHCP 范围越界**：虚拟机静态 IP 必须在 DHCP 起始/结束 IP 范围内
- **防火墙拦截**：虚拟机防火墙和宿主机防火墙均需放行对应端口
- **VMware 服务未启动**：检查 `VMware NAT Service` 和 `VMware DHCP Service` 是否在 Windows 服务中运行
- **网卡名不一致**：CentOS 7+ 的网卡名可能是 `ens33`、`ens192` 等，用 `ip a` 确认实际名称
