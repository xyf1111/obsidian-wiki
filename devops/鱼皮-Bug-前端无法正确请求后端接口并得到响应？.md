# Bug 解决：前端无法正确请求后端接口

> 前端请求后端接口响应不对，或 F12 看到响应但页面无法正常展示。

## 配置问题

1. **跨域问题** — 请求不正确，检查跨域配置
2. **SSL/HTTPS 配置问题** — HTTPS 配置不正确可能导致请求异常，确保 SSL 证书配置正确
3. **权限问题** — 确认当前账号是否有权限访问该接口

## 代码问题

1. **接口地址错误** — 确保请求的地址（主机名、端口、路径）正确
2. **前端未等待数据返回** — 页面渲染未等待异步请求完成

   示例：列表页按标签搜索后数据正常返回，但页面卡住处于加载状态：
   - 在组件上加 `:loading="loading"` 并定义 `const loading = ref(true)`
   - 数据返回后设置 `loading.value = false`

3. **前后端数据格式不匹配** — 确保约定的数据格式一致
4. **请求方法不正确** — 确认 GET/POST/PUT/DELETE 与后端接口匹配

## 网络问题

切换网络或检查是否有代理干扰。
