## Bug 案例分享

### 后端
- 数据误刷导致权限错误
- 端口被其他程序占用
- 字符不一致导致查询为空
- 大对象导致 JVM 内存溢出
- Docker 环境问题导致的数据查询错误
- 数据库连接池爆了
- 缓存导致的订单数据全量同步问题
- JDK 序列化错误
- Spring Cloud Gateway 500 错误
- 随机密码生成规则错误
- 用户登录不上零宽空格问题
- 消息中间件出错兜底方案

### 前端
- 前端长整数精度丢失
- 升级依赖版本导致的 Bug
- 缺少测试和上线规范导致的 Bug
