# Bug 解决：前端框架初始化错误

> 遇到报错时，先完整阅读报错信息，再去搜索或询问 AI。

## 常见原因

前端项目初始化报错或无法正常启动，常见原因：

1. **本地环境不一致** — Node.js 版本与教程不匹配（建议使用 v16）
2. **依赖版本过新** — 框架版本更新后可能与教程命令不一致
3. **文件权限问题** — 缺少文件读写权限

## 解决思路

### 1. 阅读官方文档

以 Ant Design Pro 为例，框架持续更新，应以官方文档最新命令为准。

> 官方文档：https://pro.ant.design/zh-CN/docs/getting-started

2024 年 2 月后，Ant Design Pro 脚手架不再提供 umi@3 选项，这是正常现象，不影响后续学习。

**核心原则：框架会变化，学习的重点是思路和方法。**

### 2. 自主搜索

将错误信息贴到百度查询，或去框架的 GitHub Issues 区搜索，99% 的问题别人已遇到过并有解决方案。

### 3. 使用老版本框架

如需与视频教程保持一致，安装老版本脚手架：

```shell
npm i @ant-design/pro-cli@3.1.0 -g
```

选择框架版本时选 **v3**（v4 不支持 umi ui 悬浮按钮）。

## 关键提醒

- 使用 `sudo`（Mac）或管理员权限解决权限问题
- 通过 NVM 管理多个 Node.js 版本
- 记录问题解决过程，长期积累后面对各种 Bug 都能从容应对
