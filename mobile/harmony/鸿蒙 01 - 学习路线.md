# 鸿蒙 01 - 学习路线

> HarmonyOS（鸿蒙）是华为 2019 年发布的面向全场景的分布式操作系统；2024 年鸿蒙 NEXT（纯血鸿蒙）不再兼容 Android 应用，原生应用需求爆发。本路线从零基础到精通，涵盖 ArkTS 语言、ArkUI 声明式 UI、鸿蒙特色能力（分布式/多设备协同）、项目实战与求职备战，建议 2-4 个月系统学习。

## 开篇介绍

### 鸿蒙是什么

- HarmonyOS 是华为开发的面向全场景的分布式操作系统，2019 年首次发布
- 不仅是手机操作系统，更是万物互联系统：可运行于手机、平板、智能手表、智能家居、车机等设备，实现多设备协同和分布式能力
- 2024 年是鸿蒙原生应用元年：鸿蒙 NEXT（纯血鸿蒙）不再兼容 Android 应用，所有应用需开发鸿蒙原生版本
- 开发技术栈：ArkTS 语言（基于 TypeScript 扩展，语法简洁）+ ArkUI 框架（声明式 UI，类似 React 和 SwiftUI），学习曲线相对平缓
- 官方 IDE：[DevEco Studio](https://developer.huawei.com/consumer/en/deveco-studio/)（华为官方，功能强大）
- AI 能力：华为推出盘古大模型、小艺助手等 AI 产品，鸿蒙系统内置 AI 能力，开发者可方便调用 AI 接口

### 为什么要学鸿蒙开发？

- **国产系统机遇**：鸿蒙是国产操作系统的希望，国家大力支持鸿蒙生态发展
- **需求量大**：随着华为手机和鸿蒙设备普及，鸿蒙原生应用需求量持续增长，正处于新技术红利期
- **薪资较高**：一线城市鸿蒙开发工程师平均薪资在 20-40K
- **AI 结合**：鸿蒙积极拥抱 AI 技术，学习鸿蒙 + AI 将打开新的职业空间

### 学习前提

1. 编程基础：至少会一门编程语言
2. TypeScript 基础【建议】：ArkTS 基于 TypeScript，有 TypeScript/JavaScript 经验学习会非常轻松
3. 移动端开发基础【建议】：了解移动端开发的基本概念
4. 有 Android 开发经验上手更快，很多概念相通

### 就业方向

| 岗位 | 说明 |
| --- | --- |
| 鸿蒙应用开发工程师 | 开发鸿蒙原生应用 |
| 移动端开发工程师 | 鸿蒙 + Android/iOS 全平台开发 |
| 全栈工程师 | 鸿蒙前端 + 后端开发 |
| IoT 开发工程师 | 开发智能家居、车机等鸿蒙设备应用 |

## 整体学习建议

1. **ArkTS 和 TypeScript 的关系**：ArkTS 基于 TypeScript 扩展，语法基本相同；会 TypeScript 或 JavaScript 会学得非常快
2. **ArkUI 和其他声明式 UI 的关系**：ArkUI 采用声明式编程，与 React、SwiftUI、Flutter 设计理念类似
3. **重点学习鸿蒙特色**：分布式能力和多设备协同是鸿蒙区别于其他平台的核心
4. **多看官方文档**：华为提供详细的[官方文档和视频教程](https://developer.huawei.com/consumer/cn/codelabsPortal/serviceTypes)，质量很高，遇到问题优先查阅
5. **善用 AI 工具**：可用 AI 工具辅助学习和开发

## 阶段 1：ArkTS 语言（5-15 天，仅供参考）

ArkTS 是鸿蒙应用开发的核心语言，基于 TypeScript 扩展而来，专为鸿蒙生态设计。

### 学习目标

掌握 ArkTS 编程语言，能够编写鸿蒙应用的脚本代码。

### 知识点

**ArkTS 基础语法【必学】：**

- 变量和常量（let、const）
- 数据类型（number、string、boolean、Array）
- 运算符和表达式
- 控制流（if、switch、for、while）
- 函数
- 装饰器（@Entry、@Component、@State 等）

**TypeScript 特性【必学】：**

- 类型注解
- 接口（interface）
- 类（class）
- 泛型
- 模块

### 学习建议

1. ArkTS 在 TypeScript 基础上增加了装饰器等特性；装饰器是 ArkUI 的核心，用于声明组件、状态等
2. 会 TypeScript 可以快速过一遍 ArkTS，重点学习装饰器等鸿蒙特有特性
3. 不会 TypeScript 建议先学习 TypeScript 基础

### 学习资源

- ⭐ [ArkTS 官方文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/arkts-get-started-V5)：官方文档

## 阶段 2：ArkUI 基础（5-10 天，仅供参考）

### 学习目标

掌握 [ArkUI 框架](https://developer.huawei.com/consumer/cn/arkui/)，能够开发鸿蒙应用的界面。

### 知识点

**开发环境【必学】：**

- DevEco Studio 的安装和配置
- 项目的创建和运行
- 模拟器和真机调试

**基础组件【必学】：**

- Text、Image、Button
- Column、Row、Stack
- List、Grid
- Scroll

**布局【必学】：**

- 线性布局（Column、Row）
- 层叠布局（Stack）
- 弹性布局（Flex）
- 相对布局（RelativeContainer）

**状态管理【必学】：**

- @State：组件内状态
- @Prop：父子组件单向传递
- @Link：父子组件双向同步
- @Provide 和 @Consume：跨组件传递

**路由导航【必学】：**

- 页面路由（router）
- 页面跳转和传参

### 代码示例

ArkTS 声明式 UI 最小示例（装饰器 + 状态管理）：

```typescript
@Entry
@Component
struct HelloPage {
  @State message: string = 'Hello HarmonyOS'

  build() {
    Column() {
      Text(this.message)
        .fontSize(30)
        .fontWeight(FontWeight.Bold)
      Button('点击修改')
        .onClick(() => {
          this.message = '你好，鸿蒙！'
        })
    }
    .width('100%')
    .padding(20)
  }
}
```

### 学习建议

1. ArkUI 采用声明式 UI，和传统的命令式 UI（如 Android XML）完全不同，要转变思维方式，理解声明式编程理念
2. 装饰器是 ArkUI 的核心，要理解各种装饰器的作用（@Entry、@Component、@State、@Prop 等）
3. DevEco Studio 是官方 IDE，功能强大，要熟练掌握其使用
4. 多动手，尝试用 ArkUI 开发简单界面，熟悉组件和布局的使用

## 阶段 3：鸿蒙特色能力（15-20 天，仅供参考）

鸿蒙特色能力包括分布式能力、原子化服务、一次开发多端部署等，是鸿蒙区别于其他平台的核心优势。

### 学习目标

掌握鸿蒙的特色能力，如分布式能力、多设备协同等。

### 知识点

**分布式能力【必学】：**

- 分布式数据管理
- 分布式任务调度
- 分布式文件系统

**多设备协同【建议学】：**

- 多设备发现和连接
- 跨设备迁移
- 跨设备协同

**系统能力【必学】：**

- 网络请求（http）
- 数据存储（Preferences、关系型数据库）
- 通知（Notification）
- 后台任务

**AI 能力【建议学】：**

- 调用盘古大模型 API
- AI 语音识别
- AI 图像识别

### 学习建议

1. 分布式能力是鸿蒙的核心特色，区别于 Android 和 iOS，要理解分布式的概念和应用场景
2. 鸿蒙的 AI 能力非常强大，内置华为 AI 服务，可方便调用 AI 接口为应用增加智能功能
3. 这部分内容相对高级，建议先掌握前面基础知识再学习

### 学习资源

- [HarmonyOS 分布式能力 - 同应用跨设备数据同步](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/distributed-data-sync)：官方文档

## 阶段 4：项目实战（20-45 天，仅供参考）

### 学习目标

通过实际项目巩固所学知识，积累项目经验。

### 学习建议

1. 从简单项目开始：先开发待办事项、天气查询、笔记应用等简单应用
2. 参考官方示例：华为提供了大量示例项目，可以学习和参考
3. 开发原生鸿蒙应用：2024 年后华为要求所有应用开发鸿蒙原生版本，可将现有 Android 应用改造成鸿蒙应用
4. 发布应用：完成后发布到华为应用市场，体验完整的应用发布流程
5. 利用鸿蒙特色：在项目中应用分布式、多设备协同等特色能力，增加项目亮点

### 项目推荐

**入门级项目：**

- 待办事项
- 天气查询
- 笔记应用
- 计算器

**进阶级项目：**

- 新闻资讯 App
- 健身 App
- 电商 App
- 社交 App

**官方示例：**

- [HarmonyOS 示例代码](https://gitee.com/harmonyos_codelabs)：官方示例项目

**优质开源项目：**

- ⭐ [OpenHarmony App Samples](https://github.com/openharmony/app_samples)：OpenHarmony 官方应用示例集合
- [HarmonyOS 100 Days](https://github.com/rubyhan1314/HarmonyOS-100-Days)：100 天从入门到精通鸿蒙开发
- [HarmonyOS Tutorial](https://github.com/waylau/harmonyos-tutorial)：跟老卫学 HarmonyOS 开发教程及示例项目
- [HarmonyUnit](https://github.com/toly1994328/HarmonyUnit)：《鸿蒙纪元》教程合集，包含大量原生鸿蒙学习资源

## 阶段 5：求职备战（面试前 1 个月突击）

### 学习目标

熟练掌握鸿蒙开发常见面试题，准备好简历和项目经历，顺利通过面试。

### 学习建议

1. 打磨简历和项目：简历上一定要有鸿蒙原生应用项目，最好能发布到华为应用市场
2. 多刷面试题：鸿蒙面试题主要包括 ArkTS 语言、ArkUI 框架、分布式能力、与 Android 的区别等
3. 了解鸿蒙生态：面试时要能说出鸿蒙的特点（如分布式、多设备协同）和发展前景
4. 对比鸿蒙和 Android：有 Android 经验者要能说出鸿蒙和 Android 的区别和优势

### 经典面试题

**基础概念：**

1. 鸿蒙系统有什么特点？
2. 鸿蒙和 Android 有什么区别？
3. ArkTS 和 TypeScript 有什么区别？
4. ArkUI 是什么？有什么特点？

**组件和布局：**

1. ArkUI 的常用组件有哪些？
2. ArkUI 的布局方式有哪些？
3. @State、@Prop、@Link 有什么区别？

**鸿蒙特色：**

1. 鸿蒙的分布式能力是什么？
2. 如何实现多设备协同？
3. 鸿蒙的 AI 能力如何使用？
