# BI 商业智能学习路线

> BI（Business Intelligence，商业智能）是将企业数据转化为商业洞察的技术和方法，涵盖数据收集、数据处理、数据分析、数据可视化等环节。

## 核心概念

- **BI ≠ 数据分析**：数据分析是方法论，BI 是工具；数据分析师用 BI 工具分析，BI 工程师开发和维护 BI 系统
- **BI 架构组件**：数据仓库、ETL 工具、OLAP 分析、报表系统、Dashboard
- **发展趋势**：从传统报表→自助式 BI（业务人员自拖拽分析）→ AI 驱动 BI（自然语言问答）
- **主流工具**：Tableau（可视化强）、Power BI（免费+微软生态）、FineBI（国产第一）

## 学习路径

| 阶段 | 内容 | 建议时长 |
|------|------|---------|
| 阶段 1 | BI 基础概念 + 数据可视化基础 | 7-15 天 |
| 阶段 2 | Power BI / FineBI 工具深入 | 20-30 天 |
| 阶段 3 | 项目实战 | 20-40 天 |
| 阶段 4 | 求职备战 | 面试前 1 个月 |

### 阶段 1：BI 基础

**必学知识点：**
- BI 的定义、价值、组成（数据仓库、ETL、OLAP、报表）
- 图表类型与选择：柱状图（对比）、折线图（趋势）、饼图（占比）、散点图（相关性）
- Dashboard 设计原则
- BI 工具对比选型

**学习建议：** 先理解数据分析的方法和流程，再学 BI 工具

### 阶段 2：BI 工具深入学习

选择 Power BI 或 FineBI 之一深入学习：

**Power BI：**
- 安装使用、数据导入和建模
- DAX 函数（Power BI 公式语言，类似 Excel 公式）
- 报表设计

**FineBI：**
- 自助分析、组件开发

**学习建议：** 多动手，尝试用 BI 工具开发各种报表和 Dashboard

### 阶段 3：项目实战

选择业务场景开发完整分析报告和 Dashboard：
- 销售数据分析 Dashboard
- 用户行为分析报表
- 财务分析报表
- 运营数据看板

**优质开源项目：** Apache Superset、Metabase

### 阶段 4：求职备战

**面试重点：**
- BI 基础：定义、价值、组成、工具对比
- 数据可视化：图表选择、Dashboard 设计原则
- 工具使用：DAX、数据源连接、性能优化
- 业务分析：用户流失分析、KPI 指标体系

**面试备考建议：**
- 简历上要有 BI 项目经历（报表、Dashboard、数据分析案例）
- 准备作品集，能够演示和讲解
- 理解业务：能说出如何通过数据分析发现业务问题
