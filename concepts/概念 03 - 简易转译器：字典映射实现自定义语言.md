# 概念 03 - 简易转译器：字典映射实现自定义语言

> 用字典把 Emoji 自定义语法（.yu 文件）转译成可运行的 JavaScript：5 个文件实现一门『新编程语言』。

## 核心思路

不必真正从 0 到 1 实现编程语言，而是编写一个『编译器』，将任何格式和语法的源文件转换成能在浏览器、Node 等环境直接运行的 JavaScript——类似 TypeScript 和 FreeMarker 等模板引擎的思路。

因此实现自定义语言被简化为两部分：

1. **核心包**：定义编译规则（字典）+ 开发编译器
2. **运行脚本**：一键编译并执行

## 定义编译规则

通过一本字典，将 Emoji 表情符号映射成 JavaScript 中的关键字。字典 map.js 中定义 Emoji 与关键字两个数组：

```js
const emojis = ['🐔', '🐖', '🐺', '🐑',
                '🦆', '🐧', '🐭', '🐂', 
                '🐯', '🐰', '🐉', '🐍'
               ];

const keyWords = ['abstract', 'arguments', 'boolean', 'break',
                  'byte', 'case', 'catch', 'char',
                  'continue', 'debugger', 'default', 'delete'
                 ];
```

用对象将两个数组关联为字典（"🐔" 对应 "abstract"，"🐖" 对应 "arguments"），并维护**双向映射**，供编译器与反编译器使用：

```js
// '🐔' => 'abstract'
const emojiWordMap = {};
// 'abstract' => '🐔'
const wordEmojiMap = {};

for (let i = 0; i < keyWords.length; i++) {
    emojiWordMap[emojis[i]] = keyWords[i];
    wordEmojiMap[keyWords[i]] = emojis[i];
}
```

自定义语法示例（.yu 源文件）：

```
🐘 getSum(val, N) 🦄
    🧸 (🐢 i 🐟 0; i < N; i++) 🦄
        val +🐟 i;
    🦁
    🦔 val;
🦁

🦌.log('result 🐟 ' + getSum(value, N))
```

## 开发编译器

定义好规则后，在编译器中编写应用规则的逻辑，将源文件（.yu）输出为目标文件（.js）。共 3 步：

**1. 通过 fs 读取源文件：**

```js
const fs = require('fs');

const basePath = './src';
const filepath = `${basePath}/${process.argv[2]}.yu`;

let fileData = fs.readFileSync(filepath, 'utf-8');
```

**2. 按字典用 RegExp 全局替换 Emoji 为关键字：**

```js
const {emojiWordMap} = require('./map');

for (const emoji in emojiWordMap) {
  fileData = fileData.replace(new RegExp(emoji,'g'), emojiWordMap[emoji]);
}
```

**3. 输出目标文件：**

```js
fs.writeFile(`${basePath}/${process.argv[2]}.js`, fileData, { 'flag': 'w' }, err => {
  if (err) {
    throw err;
  }
  console.log(`✅ compile succeed!`);
});
```

## 开发执行脚本

不能让开发者每次手动编译再运行（如同手动编译执行 C 语言）。编写 bash 脚本：接受源文件名参数 → node 编译 → node 执行 → 自动清理编译产物，实现一键运行：

```bash
#!/usr/bin/env bash
# 基本路径
basePath="./src"

# 参数校验
if [[ ! -n $1 ]]; then
    echo "❌ error: no filename!"
    exit 1
fi

# 编译
node ./core/compile.js $1

# 执行
node ${basePath}/$1

# 清理
rm -rf ${basePath}/$1.js
```
