# 概念 05 - 悲观编程：主动优化代码的编程习惯

> 写代码时保持「悲观」：把每一行代码都当作病人，坚持认为它们有问题，主动发现问题、主动优化，而不是等别人来提 Bug。

## 为什么发现不了自己代码的问题

- 很多人的编程态度是**「乐观」的**：相信视频教程、相信书本、相信编辑器，只要没报错，就认为代码是对的——因此被发现问题时往往是被动地被别人提 Bug、被迫修改，心态越来越差。
- 求人 review 代码不可行：老师不看代码只看运行效果，求学长帮忙看也难开口——没人免费帮你看「辣鸡代码」。求人不得，只能求己。
- 把作品上线给用户用、把代码开源到 GitHub 让别人指出问题，虽然有效但过于硬核，前期需要大量精力推广才有人看。

## 代码质量意识：写得少 + 看得少

初学者代码「粗糙」的典型表现：1 行能完成的功能写 10 行、20 行；同样的代码复制粘贴好几遍、变量名粘贴后忘了改；变量取名不规范甚至有中文名——很多人写完代码自己都没读过一遍。

- **三个自检问题**：① 你写完代码后自己会读一遍么？② 你想过能正常运行的代码哪里会有问题么？③ 你想过提升自己的代码质量么？
- **根源是写得少、看得更少**：入门只靠视频教程和书籍，而绝大多数教程只教你如何写出能跑起来的代码，于是很多同学以为「能写出来就是学会编程了」，放低了对自己的要求，缺失了「要努力写出高质量代码」的意识。
- **为什么要重视**：一个人写代码时无所谓，但进入团队开发后，又臭又长、难以理解和维护的代码不仅拖累自己的效率，还会拖垮整个团队。
- **面对批评的态度**：别人质疑你代码写得烂时，别急着反驳，先好好审视自己的代码，理性对待——保持提升代码质量的意识，审视代码中可能存在的问题，不被「金玉其外败絮其中」的表象迷惑。

## 悲观编程：主动挑自己的问题

- 把写过的每一行代码都看作病人，细致入微地检查，甚至从鸡蛋里挑骨头——**没问题也要挑挑问题**。
- 主动找问题、主动优化代码，通过思考、搜索和实践把复杂代码化繁为简，会收获成就感，形成正向循环；这与防御性编程不同，重点是主动精简与重构。

### 示例：JS 获取狗名的一步步精简

原始写法（先判空再取值，啰嗦）：

```javascript
// 默认狗名
let name = '无名狗';
// 狗、狗信息、狗名称都存在
if (dog && dog.info && dog.info.name) {
  name = dog.info.name;
}
```

第 1 步：**可选链操作符**（`?.`）——允许读取对象深处的属性值，不必验证链中每个引用是否有效，引用为空时自动短路，不报错：

```javascript
let name = '无名狗';
if (dog?.info?.name) {
  name = dog.info.name;
}
```

第 2 步：**三元运算符**一行搞定：

```javascript
let name = dog?.info?.name ? dog.info.name : '无名氏';
```

第 3 步：**空值合并操作符**（`??`）——左侧操作数为 `null` 或 `undefined` 时返回右侧操作数，否则返回左侧，去掉重复的 `dog.info.name`：

```javascript
let name = dog?.info?.name ?? '无名狗';
```

> 通过这一次挑问题，学到了两个 JavaScript 操作符的用法——这就是悲观编程的收获。

## 值得么？

- 短期看确实多花了时间，但从长远看这是学习的必经之路：通过自己思考发现问题、解决问题，知识会深深刻在脑海里，以后写类似代码更轻松、规范、高效，省下的时间是无限的。
- 抠细节也要分情况：开发很紧急时先以完成功能为主，但等有空了一定要记得优化，否则就是为代码「屎山」添砖加瓦。

## 找不到问题时怎么办（4 个方法）

1. **写起来很麻烦** → 多半有问题，搜索有没有现成的组件，或别人是怎么实现的。
2. **重复写某段代码** → 一定有问题，抽象成函数或组件，或用设计模式优化。
3. **大量 If Else** → 一定有问题，重新梳理逻辑，减少条件和分支。
4. **关注开发工具的报黄报红提示** → 通常能拿到很好的优化建议，尽早发现问题。

## 练习：Java 一行代码优化

获得所有狗的名字列表的原始写法（判空 + 循环 + 判 null）：

```java
List<Dog> dogList = new ArrayList<>();
List<String> dogNameList = new ArrayList<>();
if (dogList != null && dogList.size() > 0) {
  for (int i = 0; i < dogList.size(); i++) {
    Dog dog = dogList.get(i);
    if (dog != null) {
      dogNameList.add(dog.getName());
    }
  }
}
return dogNameList;
```

用 Stream 一行实现同样功能：

```java
return dogList.stream().filter(Objects::nonNull).map(Dog::getName).collect(Collectors.toList());
```
