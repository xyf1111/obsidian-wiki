# 概念 22 - 快速开发项目套路（代码生成工作流）

> 只要是把重复的代码，基本都可以自动生成。沉淀一套「前端脚手架 + 后端模板 + 数据访问生成 + 接口文档 + 联调代码生成」的开发套路，一天做一个基础项目完全可行，避免每天重复写增删改查。

## 一个项目的基本元素

**技术实现上**：

1. 前端界面，且要有通用布局
2. 后端接口，能保存登录态、对数据库增删改查
3. 前后端对接联调

**业务逻辑上**：

1. 用户登录、注册
2. 权限控制
3. 各类数据的管理（增删改查）

任何项目都少不了这些共性功能，没必要每次重复开发。「只要是重复的代码，肯定都是可以自动生成的」——核心是用好现成脚手架和代码生成工具。

## 核心工具 5 件套

| 工具 | 作用 |
|------|------|
| Ant Design Pro 前端脚手架 | 开箱即用生成前端项目（React），自带通用布局、路由、权限管理、登录注册、内容管理、全局状态管理 |
| Spring Boot 万用后端模板 | 封装 web 接口、数据访问、权限、会话、缓存、测试、日志、接口文档等通用能力，独立于具体业务 |
| IDEA MyBatisX 插件 | 根据数据表自动生成 service、mapper、entity 数据访问代码（免费） |
| Swagger / Knife4j | 自动生成遵循 openAPI 规范的接口文档 |
| openapi 插件 | 根据接口文档自动生成**前端调用代码、TypeScript 类型和模拟数据** |

### 前端代码生成

Ant Design Pro 是开箱即用的前端脚手架（基于 React），按官方文档输入几个命令即可生成完整页面，再自行修改。⚠️ 封装越成熟的框架隐藏的坑越多，且更新迭代快，**务必仔细阅读最新官方文档**再使用。

> 官方文档：https://pro.ant.design/zh-CN/docs/getting-started

### 后端代码生成

- 用通用后端项目模板（可自行沉淀）提供基础能力
- 根据业务编写数据表后，用 IDEA 的 **MyBatisX 插件**根据表结构一键生成 service、mapper、entity 代码

### 前后端联调（代码生成最爽的部分）

传统方式：后端提供接口文档 → 前端根据文档手写调用代码（如 axios）。更优做法：后端项目提供遵循 **openAPI 规范**的接口文档（Swagger/Knife4j 自动生成），Ant Design Pro 的 **openapi 插件**直接根据文档生成前端调用代码、TypeScript 类型和模拟数据。

> openapi 插件参考：https://pro.ant.design/zh-CN/docs/openapi/

## 全栈一键流程

全栈开发者可一把梭：**生成前端 → 使用后端模板 → 设计库表 → 生成数据访问代码 → 生成接口文档 → 生成前端调用代码和类型**。

技术学不完，但可以找到一套适合自己的开发套路，开发又快又灵活；日常学习和开发中要有意识地沉淀自己的模板和代码，而不是一直机械地工作。
