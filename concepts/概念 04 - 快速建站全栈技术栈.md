# 概念 04 - 快速建站全栈技术栈

> 一套「快速建站」的完整技术栈选型：前端 React 全家桶 + 组件库 + 脚手架一行生成项目；容器化发布 + CDN 加速；后端 Node.js + 云数据库 + Redis + Elasticsearch，微信云托管部署。

## 总览

以面试刷题网站为实战背景，沉淀出一套屡试不爽的「快速建站」技术栈，涵盖前端开发、前端发布、后端、部署四个环节。

## 前端开发

前端是给用户操作的界面，技术选型自底向上分 7 层。

### 1. HTML/CSS/JS 三件套

最基本的 `HTML、CSS、JavaScript` 三件套，可通过 FreeCodeCamp 免费学习：https://chinese.freecodecamp.org/

### 2. React 组件化开发

用主流开发框架 `React` 代替原生 JS DOM 操作，支持组件化开发，用习惯之后开发效率很高。

> React：https://zh-hans.reactjs.org/

### 3. Umi 搭建项目与路由

搭配 `Umi` 框架快速搭建项目、实现路由等功能。

> Umi：https://umijs.org/zh-CN

### 4. Dva 全局状态管理

使用 `Dva` 对用户信息、权限等数据进行全局状态管理。Dva 是基于 redux 和 redux-saga 的数据流方案（作用类似 Vuex），并额外内置了 react-router 和 fetch，可理解为轻量级应用框架。

> Dva：https://dvajs.com/

### 5. Less 样式复用

用 `Less` 代替原生 CSS，通过定义变量来复用代码，例如把经常用的宽高值单独提取出来。

> Less：https://less.bootcss.com/

### 6. 现成组件库

引入现成的组件库 `Ant Design`、`Ant Design Pro Components`，大大节约工作量，并保证网站风格统一。

> Ant Design：https://ant.design/index-cn
>
> Ant Design Pro Components：https://procomponents.ant.design/

### 7. 代码规范与打包

- `TypeScript`：约束变量类型
- `ESLint`：检查 JS 代码
- `StyleLint`：检查 CSS 代码
- `Prettier`：一键格式化代码
- `Webpack`：编译打包，把零散的代码文件组织成可运行的网站文件包

> TypeScript：https://www.tslang.cn/
>
> ESLint：https://eslint.bootcss.com/
>
> StyleLint：https://stylelint.docschina.org/
>
> Prettier：https://prettier.io/
>
> Webpack：https://webpack.docschina.org/

### 8. Ant Design Pro 脚手架

技术太多太复杂？使用 `Ant Design Pro` 提供的脚手架，开箱即用，一行命令生成初始项目代码，把上述所有技术整合好，还附带一套现成的后台管理界面，可通过点击方式快速创建页面。

> Ant Design Pro：https://preview.pro.ant.design/

## 前端发布

写好代码后，怎么发布给别人看？

### Docker + Nginx 部署到云托管

不使用传统服务器，而是用 `Docker 容器` 封装 `Nginx` Web 服务器，部署在 `云托管平台` 上：

- **弹性伸缩**：访问量大时容器数量自动增加、抗住更大并发；访问量小时容器数量减少、节约成本
- **负载均衡**：请求分配到不同容器上，降低单个容器的压力

### 静态资源上 CDN

网页文件等静态资源放到 `CDN`（内容分发网络）上，文件被分发到全国各地节点，用户就近访问，提高加载速度。

## 后端

后端的作用是为前端提供数据和服务。

### 云函数 Serverless 起步

增删改查等业务逻辑原本选用 `云函数`，用 `Node.js` 编写，每个功能一个函数、以 serverless 形式独立部署、互不影响。

### Express 重构为整体系统

随着系统庞大、函数数量太多、管理不便，改用 Node.js 后端框架 `Express` 对云函数重构，糅合成整体系统。Express 用起来非常简单，几行代码监听端口服务就跑起来了：

```js
const express = require('express');
const app = express();
app.get('/', (req, res) => res.send('Hello'));
app.listen(3000);
```

> Express：https://www.expressjs.com.cn/

### MongoDB 文档数据库

使用云开发提供的 `MongoDB` 文档数据库存储数据（而非 MySQL 之类的关系库），因为它的读写性能更高、字段更容易扩展，更适合初期项目。

### Redis 缓存与辅助能力

使用 `Redis` 这一高性能内存数据库实现缓存，同时利用 Redis 实现登录会话、限流、分布式锁等功能。

### Elasticsearch 搜索引擎

为提高题目搜索的准确性和灵活性，定期将题目数据同步到 `Elasticsearch` 集群，它不仅能存数据，还会自动对内容进行分词、实现高性能检索。

### Java SpringBoot 对接公众号登录

为实现点击公众号菜单登录的功能，单独开发了一个 `Java SpringBoot` 小服务与公众号对接，原因是现成的 `WxJava` 库实在是太香了。

> WxJava：https://github.com/Wechat-Group/WxJava

## 部署

### 微信云托管

所有后端服务与前端一样，使用 Docker 容器技术部署到 `微信云托管` 平台，天然支持负载均衡、打通微信，还自带自动发布、版本控制、灰度发布、日志检索、实时监控等能力。

### OSS 对象存储

使用容器技术后，用户图片等静态资源不能存到本地（其他容器可能缺失文件），改用 `OSS 对象存储服务` 存储，配合 CDN 实现访问加速。

### ECDN 全站加速（慎用）

在云托管上层套 `ECDN 全站加速网络`，通过智能分配网络链路，动态接口也能加速。效果明显，但要产生额外费用，**慎用**。

### Prerender 服务做 SEO

为了让网站更好地被搜索引擎收录，部署 `Prerender` 服务，原理类似 SSR（服务端渲染）：识别到访问者是搜索引擎蜘蛛时，将数据完整拼接到页面后再返回。使用现成镜像 `tvanro/prerender-alpine`，不用自己封装。

> 镜像：https://github.com/tvanro/prerender-alpine

## 小结

- 不是所有网站都得用这么多技术，也不是这些技术都要学习
- 有一套自己喜欢、用得顺手的技术栈就完全足够，后续再慢慢积累
