# 概念 - 遗传算法（GA）智能组题

> 使用 PyGad + Flask 的遗传算法实现智能题单生成，根据题单题目难度分布、题目类型分布、受众能力等参数得到最优组合方案

## 核心要点

### 遗传算法（GA）简介

**遗传算法（Genetic Algorithm）** 是受自然进化理论启发的一系列**随机全局搜索优化**算法。它模拟自然选择和遗传中发生的**复制、交叉（crossover）和变异（mutation）** 等现象，从初始种群（Population）出发，通过随机选择、交叉和变异操作，产生一群更适应环境的个体。经过多代繁衍进化，最终收敛到一群最适应环境的个体（Individual），从而求得问题的优质解。

GA 尤其擅长处理**具有大量参数和复杂数学表示形式**的问题，能够克服传统搜索和优化算法遇到的一些障碍。

### 应用场景：OJ 系统智能题单生成

在 OJ（Online Judge）系统中，传统题单生成依赖人工经验筛选和组合题目，存在**时间成本高、误差率大**的问题。利用 GA 遗传算法，将以下因素作为适应度函数的组成参数，经过多次遗传进化操作后得到**相对最优的题目组合方案**：

- **受众评分**（popScore）—— 题目与目标受众能力的匹配度
- **知识点分布**（needTags）—— 覆盖所需的标签（至多 5 个）
- **题目类型比例**（typeRate）—— 文字题与编程题的比例
- **题目难度比例**（difficultyRate）—— 简单:中等:困难的比例

### 输入数据结构

每条题目包含以下字段：

- `id`：题号（int）
- `tags`：知识点标签（list[str]）
- `questionDifficulty`：难度类型（0=简单，1=中等，2=困难）
- `questionType`：题目类型（0=编程题，1=文字题）

用户输入参数：

- `popScore`：受众评分（0~5，float）
- `questionNum`：选题数量
- `needTags`：所需知识点标签列表
- `typeRate`：题目类型比例数组 [文字题比例, 编程题比例]
- `difficultyRate`：题目难度比例数组 [简单, 中等, 困难]

### 适应度函数设计（核心算法）

适应度函数综合四项指标，加权计算后取**倒数**作为适应度值（值越大越优）：

```python
def max_fitness_function(solution, solution_idx):
    # 根据solution索引数组获取题目信息数组
    cur = [questionRange[e] for e in solution]

    # 计算题目类型分布并归一化
    type_distribution = calCurTypeRate(cur)

    # 计算题目难度分布并归一化
    difficulty_distribution = calCurDifficultyRate(cur)

    # 计算题目受众分数
    cur_popScore = calCurPopScore(difficulty_distribution)

    # 计算适应度函数值（公式）
    fitness = (
            weight_popScore * (abs(popScore - cur_popScore) / popScore) +
            weight_tags * calTagsLoss(cur) +
            weight_typeRate * (abs(typeRate[0] - type_distribution[0]) + abs(typeRate[1] - type_distribution[1])) / 2 +
            weight_difficultyRate * sum([abs(difficultyRate[i] - difficulty_distribution[i]) for i in range(3)]) / 3
    )

    return 1.0 / fitness
```

**适应度函数四项组成：**

| 分量 | 意义 | 计算方式 |
|------|------|----------|
| 受众评分差异 | 选题与目标受众的匹配度 | `weight_popScore * abs(popScore - cur_popScore) / popScore` |
| 知识点覆盖 | 选题覆盖所需标签的比例 | `calTagsLoss(cur)`，通过求交集除以 needTags 数量 |
| 类型比例偏差 | 实际类型分布与期望的差距 | 各类型比例差的绝对值取平均 |
| 难度比例偏差 | 实际难度分布与期望的差距 | 各难度比例差的绝对值取平均 |

四个 `weight_*` 系数用于调整不同参数的影响程度，可根据实际需求调整。

### GA 策略参数

使用 **PyGad 2.19.2** 库实现 GA 流程：

```python
ga_instance = pygad.GA(
    init_range_low=0,
    init_range_high=len(questionRange) - 1,
    num_generations=50,                  # 进化代数
    num_parents_mating=20,               # 每代选中的亲本数
    parent_selection_type="sss",         # 稳态选择（steady_state_selection），保证种群稳定性
    crossover_type="single_point",       # 单点交叉策略
    fitness_func=max_fitness_function,   # 适应度函数
    sol_per_pop=100,                     # 种群大小（每代 100 个个体）
    num_genes=questionNum,               # 染色体基因数（即选题数量）
    gene_type=int,                       # 基因类型为整数索引
    gene_space=range(0, len(questionRange)),
    allow_duplicate_genes=False,         # 不允许重复选题
    mutation_type="random",              # 随机变异
    mutation_percent_genes=5,            # 基因变异概率 5%
    random_mutation_min_val=0,
    random_mutation_max_val=len(questionRange) - 1
)
```

**关键参数总结：**

| 参数 | 值 | 说明 |
|------|-----|------|
| 种群大小 | 100 | 每代个体数量 |
| 进化代数 | 50 | 迭代总次数 |
| 亲本选择 | sss（稳态选择） | 保证种群稳定性 |
| 交叉策略 | single_point（单点交叉） | 适用于二进制和实数编码 |
| 变异策略 | random, 5% | 随机突变，5% 基因变异概率 |
| 是否允许重复 | 否 | 同一题单不出现重复题目 |

### 项目技术栈

- **PyGad** (2.19.2) —— Python 遗传算法库，封装了 GA 核心流程
- **Flask** —— 提供网络接口，将 GA 组题能力暴露为 API 服务

### 设计思路小结

1. **问题建模**：将题单生成转化为多目标优化问题，用适应度函数量化方案好坏
2. **GA 搜索**：通过 50 代进化，从 100 个个体的种群中逐步筛选出最优题单组合
3. **灵活可调**：四项权重系数可独立调整，适应不同场景（如更看重知识点覆盖或难度匹配）
4. **实用落地**：结合 Flask 提供 API，可集成到 OJ 系统中直接使用
