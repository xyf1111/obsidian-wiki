# 算法与数据结构学习路线

> 面向零基础的程序员数据结构与算法学习路线：先理解「程序 = 数据结构 + 算法」，再按「预热 → 依次学习 → 依次练习 → 大量刷题 → 面试冲刺」循序渐进，配套知识体系、整体学习建议与刷题资源。

## 为什么要学数据结构和算法

- **程序 = 数据结构 + 算法**。数据结构是数据的存储结构与组织方式，使数据便于访问、修改、存储；算法是操作数据、解决问题的一系列步骤。
- 平时「用不到」不代表不重要：很多时候是因为知识储备不足，根本想不到用算法来优化程序（提升性能、节省内存）。
- 框架和算法库虽然封装好了，但一旦底层出问题或某个算法效率低下需要优化，没学过数据结构与算法大概率搞不定。
- 学习算法能开拓思路、改变思考问题的方式、提升问题解决能力——这也是公司最看重的素质。

## 学习条件与时机

- **前提条件**：至少学过一门编程语言；预留至少 2 个月空余时间（急着找工作的同学可先跳过）。
- **学习时机**：建议学完一门编程语言后就开刷。算法本身重要，且用编程语言刷题能巩固语法基础，避免「纸上谈兵」、做项目时因语法不熟写不出代码。
- **现实预期**：零基础很难在面试前几周速成。作者从大二开始学习数据结构并刷题，一年多累计刷 1000+ 题；准备得早，学得扎实、面试答得出，日常压力也小。

## 整体学习建议

1. **坚持每天刷题**：算法不可追求速成（学得快忘得快），每天坚持刷 2 道以上保持手感。
2. **多写注释和总结**：写题时多写注释记录思考，做过的题按分类保存代码便于复习；写题解能检验是否真正理解，还能再次巩固。
3. **用任何编程语言都可以**：算法是一种思想，用正在学或熟悉的语言写代码即可，顺带复习语法细节。
4. **不用担心算法不够**：有基本开发技能就足够，算法可以持续强化，不必因担心而不敢面试。
5. **挑战自己**：入门时可刷简单题，但刷了几百题后不要满足于舒适圈，要适当挑战中等/困难题。
6. **善用 AI 辅助学习**：遇到不理解的算法或题目，可让 AI 工具（如 ChatGPT、DeepSeek）用通俗语言解释、画图演示算法过程，或帮忙分析时间/空间复杂度。
7. **参加竞赛和考证**：蓝桥杯、PAT 认证、LeetCode 周赛等门槛不高（难度低于 ACM），能帮你集中精力高效做题、提前适应面试节奏。

## 知识体系

### 数据结构

- **线性结构**
  - 数组（字符串）
  - 链表（单向链表、双向链表、循环链表）
  - 栈
  - 队列（普通队列、双端队列）
- **散列结构**
  - 集合
  - 映射
  - BitMap
- **树**
  - 二叉树
  - 二叉查找树
  - 多叉树
  - 前缀树
  - 堆（小顶堆、大顶堆）
- **图**
  - 最短路径
  - 并查集
  - 最小生成树
  - 拓扑排序

### 算法

- **排序算法**：冒泡排序、快速排序、插入排序、希尔排序、选择排序、堆排序、归并排序、计数排序、桶排序、基数排序
- **查找算法**：有序表查找（二分查找）、线性表查找、树结构查找、散列表查找
- **经典算法思想**：贪心算法、分治算法、动态规划、递归、回溯、枚举
- **搜索算法**：深度优先搜索（DFS）、广度优先搜索（BFS）
- **字符串匹配**：KMP 算法、前缀树
- **位运算**

### 复杂度分析

- 时间复杂度
- 空间复杂度

## 学习路线

> 本路线适用于所有从 0 开始学算法的同学；若目标是 ACM 算法竞赛，只学这些远远不够。

### 阶段 1：预热（可选）

**学习目标**：培养对算法的兴趣，简单入门，不要求真正理解。

**学习建议**：初学编程、刚开始学算法时，先通过阅读课外书、科普视频培养兴趣，简单入门即可，不要求真正理解。

**学习资源**：

- 《算法图解》：图文并茂的算法入门书（阿里云盘分享，提取码 73dl：https://www.aliyundrive.com/s/MFSC8TP7ANB ）
- 《大话数据结构》：通俗易懂的数据结构入门书（阿里云盘分享，提取码 73dl：https://www.aliyundrive.com/s/MFSC8TP7ANB ）

### 阶段 2：依次学习

**学习目标**：了解每个数据结构和算法的概念、特点、适用场景、时空复杂度，并能自己写代码从 0 到 1 实现一遍。

**学习建议**：

1. **按顺序学习**：不要一次性看完所有数据结构与算法后再回头写代码。
2. **边学边练**：学完某个数据结构/算法后，立刻趁热打铁做几道相关题目。
3. **重点突出**：链表、树是面试重点，多花时间；图论了解即可，优先级不高，面试考得不多。
4. **使用可视化工具**：通过动画演示（如 VisuAlgo、USFCA 数据结构可视化）理解算法的执行过程。
5. **多看题解**：自己做出的题目也建议看其他同学的题解，多积累一种方法。

**学习顺序**（推荐直接从 LeetCode 学习板块 LeetBook 开始，边学边写代码）：

### 阶段 3：依次练习

**学习目标**：通过练习巩固每个数据结构和算法的知识。

**学习建议**：

1. **限时做题**：每道题给自己设时间限制，超时后直接读题解（建议选带图片和动画演示的题解），有思路后再试着自己做，直到完成并真正理解每道题的解法。
2. **多看题解**：自己做出来的题也去看看其他同学的题解，多积累一种方法。
3. **配合可视化工具**：做题时观看算法的动画演示，加深理解。

### 阶段 4：大量刷题

**学习目标**：通过大量刷题提升解题能力和速度，为面试做准备。

**学习建议**：学完每个知识点后，去 LeetCode 题库按难易度、通过率、热门程度每天坚持刷几道；时间紧张（三个月内）可直接刷热门题目集合。有时间可参加 [蓝桥杯竞赛](https://www.lanqiao.cn/)、考 [PAT 认证](https://www.patest.cn/)，检验学习成果、丰富简历。

**刷题顺序**（仅供参考，可有自己的方法和习惯）：

1. **先按知识点逐个刷**：进入 [LeetCode 学习板块](https://leetcode-cn.com/leetbook/)，按知识点分类的教程和题目（初级算法、数组、字符串、队列、栈、树等）。每刷完一个知识点，再做几道相关题目举一反三，每道题都要做到 100% 通过。
2. **再按难度/通过率自由刷**：刷完知识点后，刷几十道简单题，再去做 [LeetCode 热题 100 道](https://leetcode-cn.com/problem-list/2cktkvj/)；时间紧迫可直接刷热题。
3. **建议刷题量**：算法最好刷 200 道以上，每天 2-3 道、坚持 2 个月以上，并整理好代码定期复习。尽量不刷冷门题，也别逞能刷太多 Hard 题（性价比不高），省下时间做项目。
4. **巩固强化**：刷完 LeetCode 经典题目后，可刷《剑指 Offer》或《剑指 Offer 面试精装版》巩固。

**刷题平台**：

- ⭐ [LeetCode](https://leetcode-cn.com/)：最主流的算法刷题平台
- [洛谷](https://www.luogu.com.cn/)：适合算法竞赛

**推荐题单**：

- ⭐ [LeetCode 精选 100 道](https://leetcode-cn.com/problem-list/2cktkvj/)
- [LeetCode 精选算法 200 题](https://leetcode-cn.com/problem-list/qg88wci/)
- [LeetCode 算法高频面试题汇总](https://leetcode-cn.com/leetbook/detail/top-interview-questions/)

### 阶段 5：面试前冲刺

**学习目标**：面试前集中复习，提高面试通过率。

**学习建议**：

1. **刷热门题目**：面试前刷一遍 LeetCode 热门题目，有时间可阅读《剑指 Offer》《剑指 Offer 专项突破版》《程序员代码面试指南》等书籍，争取面试遇到原题。
2. **刷公司真题**：有目标公司可刷 [牛客历年笔试题目](https://www.nowcoder.com/exam/company)（难度可能较大，不要因此丧失信心，多练习就习惯了）。
3. **复习算法知识**：面试前系统复习常见算法的时间复杂度、空间复杂度、适用场景等。
4. **准备手写代码**：面试可能要求现场手写代码，要能快速写出正确算法。提前练习几遍常见算法（快排、二分查找、DFS/BFS 等）。

**推荐资源**：

- ⭐ [图解算法数据结构](https://leetcode-cn.com/leetbook/detail/illustration-of-algorithm/)：图文并茂的算法题解
- [LeetCode 真题解析视频](https://www.bilibili.com/video/BV1a54y1b74k)：视频讲解 LeetCode 经典题目
- [LeetCode 101（C++）](https://github.com/changgyhub/leetcode_101)：C++ 题解汇总
- [LeetCode 题解（C++）](https://github.com/soulmachine/leetcode)：C++ 详细题解
- [LeetCode Cookbook（Go 语言）](https://github.com/halfrost/LeetCode-Go)：Go 语言题解

### 阶段 6：工作后（可选）

工作之后，如有兴趣可通过刷题巩固编程语言、提升思维能力。

## 面试考察形式

算法面试主要有以下几种形式：

1. **手写算法题**：给定题目，现场编写代码（最常见）
2. **口述思路**：描述如何用算法解决某个问题
3. **算法优化**：给一个低效的算法，要求优化
4. **复杂度分析**：分析算法的时间复杂度和空间复杂度
5. **数据结构设计**：设计一个数据结构来满足特定需求

## 更多学习建议

### 1、刷题顺序

最直接的方式：按知识点标签选题，从【简单】的题目、【通过率高】的题目刷起，循序渐进。

### 2、养成自己的刷题习惯

学算法是枯燥的，长期坚持很难（作者当年刷了 1000+ 题）。能坚持下来的关键，是把刷题当成像刷牙洗脸一样的日常任务：

1. **每天固定时间学习**：比如每天早上思考没解决的算法题，想到方案就敲代码。
2. **定每日学习目标**：如每天花 1.5 小时完成 3 道题，不多不少。没做完就等其他工作完成后静下心思考；超前完成可以奖励自己。
3. **分享学习记录**：每刷几十道题就与朋友分享，看着打卡表越来越满，成就感会支撑你走下去。

### 3、找到自己的灯塔

一个人学算法容易累，一定要找到能共同前行的伙伴或指路的灯塔：一起刷题的伙伴、算法交流圈子、专业的算法导师。一个问题自己想 30 分钟没解决，请教他人可能 5 分钟就解决，能大大节约时间。至于三天打鱼两天晒网、轻易摆烂的人，敬而远之。

### 4、学会总结

解决「学了就忘」的最好方法：多记录总结，把知识沉淀成电子文档，而不是全装在大脑里。写不清自己的思路，说明这道题还没理解——打回去重做。可通过云文档、GitHub 仓库、平台发帖总结分享题解和心得（费曼学习法），能给别人讲清楚，自己的印象就更深刻；即使刷了会忘，也能靠笔记快速捡起思路，大幅提高复习效率。

### 5、利用题解

读题解包括两部分：**读思路** 和 **读代码**。既要理解作者的解题思路和逻辑，也要学习他人代码中优秀的写法。即使自己做出来了（甚至击败 100%），也建议看看别人的题解，打开脑洞，做到**一题多解**。网上题解很多，刷题时读一两份即可，别给自己太大压力。

此外，**多写题解才是真正的法宝**：把自己的解题思路整理成文或讲给别人听，既能加深印象、巩固理解，也便于面试时复述，还能帮助其他同学。

### 6、精益求精

每次解题成功，LeetCode 会生成解题报告，显示时间/空间上击败了多少用户。答出题目已经很棒，但面试官喜欢出变种题或要求更优解，所以在完全理解解法的基础上，不断优化代码、寻找更多思路和更优解，直到击败 100% 的用户。

工作中未必直接和算法打交道，但学习算法帮助很大：解算法题要比较多种算法的复杂度选最优；工作中一个需求也有多种实现方式，需要设计方案并分析成本、性能差异后选最优。把每道算法题当成工程问题来解决，思维会逐渐打开，逐步掌握编写高性能程序的技巧。

### 7、多实践

#### 参加竞赛

多参加算法竞赛（不是 ACM 区域赛那种大神级别，目标只是找工作）：LeetCode 每周都有线上算法竞赛，限时解题，紧张的环境让精神高度集中、激发思维，帮助适应面试节奏，还有机会获得官方奖励；[蓝桥杯](https://www.lanqiao.cn/) 难度与求职算法题相当（作者参加过两届），能发现自身不足、激励进步。

#### 考取证书

[PAT 计算机程序设计能力考试](https://www.patest.cn/) 近年逐渐升温，分顶级、甲级、乙级三个级别。作者亲身参加过甲级和乙级，难度适中；证书含金量目前虽不高，但备考过程有明确目标、更有动力坚持。过程大于结果。
