# 工具 03 - 剪切助手

> 剪切助手是一款界面精美的跨平台剪贴板管理工具，支持历史记录搜索、内容分组、云同步和快捷粘贴。

- 官网下载：[https://jianqiezhushou.com](https://jianqiezhushou.com/)
- 支持 Windows / Mac 双系统，核心功能免费

## 核心功能

### 1. 历史剪贴板管理

- 自动记录所有复制内容（文本、图片、文件）
- 支持搜索历史内容，按快捷键（默认 `Ctrl + O`）唤起面板
- 内容分组筛选，可作为备忘录使用

### 2. 高效粘贴

- 键盘操作即可搜索并选择内容粘贴，无需鼠标
- `Ctrl + 数字键` 快速粘贴最新复制的几个内容
- 支持粘贴图片和文件到文件夹

### 3. 自定义快捷键

- 切换分组、粘贴最近复制内容均可绑定快捷键
- 可为指定内容设置快捷键，一键粘贴常用内容（如运营话术）

### 4. 极速分享

- 右键单击复制内容即可生成分享链接
- 其他设备可查看分享的内容，实现跨设备信息同步

### 5. 跨设备云同步

- 支持多台设备共享复制内容
- 按需开启同步，默认不上传，保障隐私

### 6. 智能识别

- 自动识别复制内容的类别：链接展示网页标题，图片/文件显示大小，文本显示字数

### UI 特性

- 横向/纵向布局切换
- 深色/浅色模式
