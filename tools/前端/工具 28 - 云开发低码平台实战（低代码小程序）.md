# 工具 - 云开发低码平台实战（低代码小程序）

> 用腾讯云开发低码拖拽式平台从零搭建备忘录小程序：7 步实战 + 五方面评测。

## 概念：云开发低码是什么

### 云开发（CloudBase）

- 云端一体化的**后端**云服务，采用 Serverless 架构，无需自己搭建服务器、免运维。
- 提供云数据库、云存储、云函数、静态托管、命令行工具、Flutter SDK 等能力，前端同学也能开发完整的小程序、小游戏、H5、Web、移动 App。
- 开发者只需专注业务逻辑，无需关心后端架构与服务运维。
- 腾讯云开发（CloudBase）由腾讯云与微信团队联合打造，是一站式后端云服务；开发者只需关注**业务逻辑**（实现功能），业务之外的负载均衡、容器服务、弹性伸缩、监控告警、安全加固、异地容灾、高可用高并发等统统交给统一服务。
- **核心能力一览**：

| 能力 | 作用 | 说明 |
| :--- | :--- | :--- |
| 云函数 | 无需自建服务器 | 在云端运行的代码，微信私有协议天然鉴权，只需编写自身业务逻辑 |
| 数据库 | 无需自建数据库 | 既能在小程序前端操作、也能在云函数中读写的 JSON 数据库 |
| 存储 | 无需自建存储和 CDN | 小程序前端直接上传/下载云端文件，控制台可视化管理 |
| 云调用 | 原生微信服务集成 | 基于云函数免鉴权使用小程序开放接口（服务端调用、获取开放数据等） |
| HTTP API | 小程序外访问云资源 | 在已有服务器上通过 HTTP 访问云开发资源，实现与云开发互通 |

- **传统开发 vs 云开发**：传统开发需自行搭建后端、数据库、服务器并处理负载均衡、监控告警、安全防护、异地容灾等；云开发把这些业务之外的问题统一解决——以「文件上传」为例，传统开发（前端 + 后台 + 运维）约 120 分钟，云开发仅前端 5 分钟；「插入数据」传统约 90 分钟，云开发仅 2 分钟。集成 SDK 还可直接操作数据库、上传下载文件，一行代码调用微信开发者接口，并提供音视频、内容安全审核、图像识别、AI、智能对话、短信等开放能力。
- **开通方式**：小程序里创建后打开微信开发者工具点「云开发」申请即可，10 秒得到一套环境，**小型产品免费版完全够用**；做网站 / 移动应用可在腾讯云开发官网开通环境。

### 云开发在真实项目中的应用（编程导航实战全景）

> 以下是作者用云开发搭建「编程导航」网站（获腾讯云·云开发技术竞赛一等奖、几乎用遍云开发所有主流功能）时用到的能力全景，可作为技术选型与落地参考。项目已开源：https://github.com/liyupi/code-nav

**基础能力**

- **云数据库**：存储业务数据（用户、资源等），在网页控制台配置**索引**加速查询。
- **登录鉴权**：未登录时用**匿名登录**访问云开发资源；登录后用**自定义登录**实现 token 的前后端存储与交互。
- **云函数**：业务后台采用 serverless 架构，把后端打碎、**每个接口一个云函数、独立部署**，实现数据库增删改查与登录；用**定时触发器**实现用户排行周榜 / 月榜。
- **云存储**：存用户头像、资源图片等文件。
- **静态网站托管**：一键部署静态网站，用云开发提供的 CDN 加速访问。
- **HTTP 访问服务**：暴露云函数供其他服务器调用，并可通过配置多个域名实现网站重定向。
- **云托管**：以 Docker 容器集群方式部署前端、微信公众号后台等服务。
- **安全规则**：控制云开发资源的默认访问权限，保护数据安全。
- **日志管理**：默认提供日志记录，在云函数中用日志 SDK 实现**自定义分级日志**，用于定位故障、分析异常流量来源。
- **监控告警**：在控制台为云函数等资源配置监控告警规则，即时发现问题。

**API 能力**

- **服务端 SDK 访问云函数**：让零散的云函数互相调用（类似微服务架构的公共服务），如发送系统消息、增加用户积分。
- **数据库事务**：支持提交与回滚，保证一致性（如用户发布资源后必增加积分）。
- **聚合查询**：支持随机查询（资源的随机推荐）、流水线、关联查询（查评论列表时一并关联用户头像、昵称）。
- **数据库实时推送**：透明化底层 socket 长连接，实时监听数据库字段变化，实现实时公告、实时聊天室。

**扩展能力**

- **云 CMS 内容管理系统**：集中式可视化数据管理，便于管理员定义数据模型、全局管理数据。
- **云 Redis**：支持内网安全访问 Redis 中间件，如用 `setnx` 对接口限流、保证接口安全。

**工具插件**

- **CloudBase CLI**：一行命令即可发布静态网站、部署云函数 / 触发器。
- **CloudBase Framework**：一键部署云开发完整应用，如静态网站、云托管容器等。

**其他能力**

- **云环境共享**：网站与小程序可复用同一套接口与数据资源，无需为小程序再单独开发一套接口和数据。

### 低代码的本质

- 低代码（LowCode）指开发中少写代码甚至不写代码（零代码），"Low" 不是低端，而是少写。
- 演进路径：复制粘贴代码 → 代码生成器（生成包含特定字符串的文件）→ 可视化界面拖拽动态生成代码，即低代码应用。
- **本质 = 应用场景的极致抽象 + 模板化**。随云计算发展，这类平台逐渐上云，无需下载软件即可开发系统。

### 云开发低码平台

- 腾讯 2020-11-29 推出的**拖拽式**低代码开发平台，以云开发为底层支撑，将底层架构与基础设施抽象为图形界面。
- 通过行业模板、拖放式组件、可视化配置快速构建**多端应用**（小程序、H5、Web，未来支持 App），一次开发、自动部署多端。
- 意义：降低开发门槛（产品/运营等无技术背景的人也能做应用），提升生产效率、避免重复劳动。
- 官方案例：粤省事小程序「贫困认证」功能，代码行数 2000+ → 61 行，文件数 42 个 → 1 个，交付效率提升至少 5 倍。

## 实战：7 步开发备忘录小程序

目标：一个记录/查看待办事项的 todoList 小程序，含「主页」列表与「添加待办」两个页面。

### 1. 创建应用

进入云开发低码控制台，新建**空白应用**。一个应用对应一个小程序或网站。

### 2. 创建数据源

- 数据源对应云数据库的一张表，控制台「数据源管理」→ 新建数据源。
- 填写数据表名、字段，并配置对该表的增删改查操作权限。

### 3. 开发界面（可视化拖拽）

- 编辑界面分组件树、预览区、编辑区，点选组件即可实时看到页面变化。
- 新建「主页」和「添加待办」两个页面；每个组件有默认文字，点击编辑区对应组件即可修改内容。
- 拖拽搭建整个主页结构不超过两分钟。

### 4. 美化样式

- 无需写代码，在「样式」面板中点选输入值即可（导航条颜色、文字间距/字号/对齐等）。
- 也支持自由编写 CSS 样式代码。
- ⚠️ **表单输入项的 key 必须与最初定义的数据表字段名保持一致**，否则会增加大量额外工作。

### 5. 前后端连接

- 传统方式需写 Ajax 异步请求；低码平台只需点选配置自动关联。
- 顶部操作栏「数据源变量」→ 创建 `todos` 全局变量（整个应用有效），关联 `todo` 数据源，动作选「查询列表」，变量即保存表中全部数据。
- 外层 `View` 组件配置 **for 循环表达式** 实现列表重复渲染。
- 内层 `Cell` 组件动态绑定标题、描述，绑定方式选「For 循环」（只需考虑单条数据）。
- 「暂无待办」空状态：配置 **if 条件表达式**，当待办数据为空时才展示。

### 6. 实现交互逻辑

- 平台内置**素材库**，提供大量常用事件与执行动作：为主页按钮配置点击事件 → 跳转「添加待办」页面。
- 插入数据等复杂动作素材库没有：在**低代码编辑器**中新增事件处理器、编写代码、保存后指定执行动作。这是全文唯一写代码的地方。
- 平台提供示例应用，直接复制代码、替换数据源名称即可（Ctrl C + Ctrl V）。

### 7. 预览发布

点击「预览发布」，等待几分钟生成可访问链接，打开即见作品，支持 H5 浏览与手机扫码。

## 评测：五个方面

### 易用性

编辑界面简明清晰，可轻松调整组件顺序、内容、样式、交互；提供现成应用模板直接套用。除定制业务逻辑外几乎不用写代码，写代码处也有友好提示，**没读文档也能直接完成开发**。

### 丰富度

公测期已提供表单、媒体、数据展示、画布、微信开放能力等常用组件，基本满足开发需求；另有面向企业级应用的页面模板，开箱即用。

### 灵活性

应用/页面信息、每个组件的 CSS 样式与 JavaScript 代码均可自由定制，还能控制页面生命周期；目前暂不支持自定义组件和页面模板。

### 成熟度

云开发技术和跨端框架已较成熟，但低码作为融合新生产品，能否经受大项目考验待验证。

### 生态

打通云数据库、云函数、云存储、云托管、内容管理 CMS 的完整生态，1 + 1 > 2。内置**数据管理后台**（腾讯云 CMS），可直接管理数据源，省去自建管理后台的成本。

## 评价

- 低代码 + 云开发一条龙：前后端都不用自己写代码，无需关心服务器购置与部署。
- 天然支持跨端：做一个应用同时支持小程序和 H5，甚至其他端。
- 微信小程序属腾讯自家产品，与微信生态连接紧密，可直用微信开放平台能力。
