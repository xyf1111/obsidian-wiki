# 工具 41 - Semi Design 设计系统与组件库（字节跳动）

> Semi Design 是字节跳动抖音前端团队与 MED 产品设计团队设计、开发并维护的企业级设计系统，同时是一套开箱即用的 React 组件库：设计风格简洁现代、支持主题自定义与国际化，文档还提供「版本对比」和「代码实时编辑」能力，对 React 开发者尤其友好。

## 核心要点

### 什么是 Semi Design

- **官方定位**：由抖音前端团队、MED 产品设计团队设计、开发并维护的设计系统，作为全面、易用、优质的现代企业级应用 UI 解决方案，从字节跳动各业务线复杂场景提炼而来，支撑近千计平台产品，服务内外部 10 万+ 用户。
- **用人话描述**：一套精美的设计系统 + 一套开箱即用的 React 组件库，喜欢用 React 写前端的开发者可以直接拿来用；这也是该团队在 GitHub 上首次公开的项目，发布短短几天就收获 3.6k 个 star。
- 官网：https://semi.design/
- 代码仓库：https://github.com/DouyinFE/semi-design

### 主要特点

- 遵循简洁轻量、现代化的设计风格，开放自定义，让设计「活」起来。
- 提供**主题编辑器**和**主题商店**，可轻松切换视觉风格。
- 完备的**国际化**，默认支持十几种语言（国际化如今已像不成文标准：有它不新鲜，没有反而显得欠缺）。
- 采用**跨前端框架技术方案**、F/A 分层设计：通过重构，可以快速支持除 React 外的通用组件库，比如 Vue、Svelte 等。
- 还计划上线**物料市场**（可理解为组件社区），持续提供更多开箱即用的组件，帮助更快开发精美前端界面。

### 文档的易用性亮点

- 每个组件上方多了一个 **`版本对比`** 按钮：可以快速了解组件随版本的更新和变化，从而减少一些版本不一致导致的 Bug。
- 提供 **`代码实时编辑`** 能力：使用哪个组件都可直接实时修改代码并查看效果，调试出想要的界面后再把代码复制到自己的项目中，大大提高开发效率。

### 与 Ant Design 的关系

- 文档结构、语法风格和属性名称都与蚂蚁的 **Ant Design** 很类似，网上一度有「抄袭」的争议。
- 作者观点：**借鉴和抄袭是两码事**——Ant Design 本身已开源，开源理念之一就是让大家更好地参与建设、共同促进技术发展；如果 AntD 做得不好，大团队也没必要借鉴它。
- 换个角度看，不同组件库语法一致，用户使用时不需重新区分语法、可保持原有习惯，反而便于平滑迁移（就像很多语言的取子串函数都叫 `substring`，已成不成文标准），做新产品时让用户自然迁移是很机智的策略。
- 字节开源 Semi Design 既让开发者多了一套选择，也间接给 Ant Design 施加了压力，促进其更好地完善。
