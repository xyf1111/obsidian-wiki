# 工具 39 - 富文本编辑器选型（开源免费）

> 开发写作类网站时最容易被低估的一环就是富文本编辑器：既要好看、流畅，又要和所用框架/版本、目标浏览器兼容。本文对比 6 款开源免费的富文本编辑器组件，给出各自的定位、能力与短板。

## 一、为什么要提前选型

自己开发写作网站（或论坛、笔记、后台内容管理）时，富文本编辑器往往是最耗时间的一块。常见的坑：

- **样式不可控** — 默认界面难看，改造成本高
- **性能差** — 内容一多就卡顿
- **框架 / 版本不兼容** — 例如用 React 时找不到匹配封装，或新版框架下报错
- **浏览器兼容性差** — 部分浏览器下直接不能用

> 选型建议：先明确「外观 / 性能 / 框架匹配 / 浏览器兼容」四项硬约束，再对照下表挑组件；付费编辑器虽然开箱效果好，但**不方便修改和定制**，写作类产品通常优先选开源可改的方案。

## 二、6 款开源富文本编辑器对比

| 编辑器 | Star | 语言栈 / 集成方式 | 特点 | 局限 |
| --- | --- | --- | --- | --- |
| **editor.md** | 12k | 纯 HTML / CSS / JS | 只学过三件套也能用；支持 Markdown、代码块、科学公式、流程图；自定义配置多；兼容 IE 8+ | 不支持把 HTML 解析回 Markdown |
| **quill** | 32.2k | 原生 JS + Vue / React 封装 | 轻量、兼容性强、插件扩展丰富，按需引入功能 | — |
| **bytemd** | 2k | Svelte 开发，支持原生 / Vue / React / Svelte | 字节跳动（掘金）出品；内置多套掘金主题，写作体验好；问题修复响应快 | Star 数相对少 |
| **monaco-editor** | 28.6k | 原生 JS（VS Code 同源） | 微软开源；支持 Visual Studio 主题，接近本地编辑器体验；**支持代码 Diff** | 面向代码编辑，非通用图文写作 |
| **tui.editor** | 14.4k | 原生 JS + Vue / React 封装 | NHN 出品；界面舒适；支持所见即所得（类似 Typora） | — |
| **slate** | 23.8k | 完全可定制框架 | 「用于更好地造轮子的轮子」，灵活性极高 | 易用性相对不高，需自行组装 |

### 2.1 editor.md

- 仓库：https://github.com/pandao/editor.md
- 国内上手成本最低的一款，只需了解 HTML / CSS / JS 即可使用
- 支持 Markdown 语法、代码块、科学公式、流程图等，配置项丰富
- 兼容 IE 8+，基本能满足写作网站需求
- **注意**：目前不支持将 HTML 解析为 Markdown，有该需求需另寻方案

### 2.2 quill

- 仓库：https://github.com/quilljs/quill/
- Star 数在富文本编辑器中名列前茅，轻量 + 兼容性强 + 插件丰富，缺什么功能再单独引入
- 原生 JS 即可使用，界面精简
- 生态完善，主流框架都有封装：
  - Vue 版：https://github.com/surmon-china/vue-quill-editor
  - React 版：https://github.com/zenoamaro/react-quill

### 2.3 bytemd

- 仓库：https://github.com/bytedance/bytemd
- 字节跳动（掘金）出品，功能强大，内置多套掘金主题
- 使用 **Svelte** 框架开发，支持原生、Vue、React、Svelte 集成，几乎适用于所有前端开发者
- 曾有火狐浏览器崩溃问题，已快速修复，维护响应速度较好

### 2.4 monaco-editor

- 仓库：https://github.com/microsoft/monaco-editor
- 微软开源的代码编辑器（VS Code 编辑器内核），支持 Visual Studio 主题，给用户接近本地编辑器的敲代码体验
- **支持代码 Diff 功能**：想自研一个类似 GitHub 的代码差异展示界面，用它即可低成本实现

### 2.5 tui.editor

- 仓库：https://github.com/nhn/tui.editor
- 界面观感舒适；支持**所见即所得**编辑，体验类似 Typora
- 同时提供原生 JS 以及 Vue、React 的封装版本

### 2.6 slate

- 仓库：https://github.com/ianstormtaylor/slate
- 定位特殊：面向「专注于构建富文本编辑器的完全可定制框架」，可以理解为**用于造轮子的轮子**
- 易用性不算高，但灵活性很强——想从零做一个自己的富文本编辑器时，slate 是很好的底座

## 三、选型小结

- **通用图文写作 / 论坛发帖** → quill（轻量、生态全、跨框架）或 editor.md（上手最快、兼容老浏览器）
- **想要现成好看的主题与 Markdown 体验** → bytemd
- **以代码内容为主、需要高亮与 Diff** → monaco-editor
- **偏所见即所得、重视界面观感** → tui.editor
- **要深度定制、自成一套编辑器** → slate
