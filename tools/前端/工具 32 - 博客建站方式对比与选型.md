# 工具 32 - 博客建站方式对比与选型

> 搭建个人博客网站主要有 5 种方式：自己开发、站点生成器、建站程序、建站平台、直接购买，各有优劣。按「省事 / 省钱 / 简易 / 灵活」四个维度对比选型，追求扩展性选开源建站程序，追求省心省钱选静态站点生成器。

## 五种建站方式

### 1. 自己开发

自己写代码（前台 + 后台管理）、自己发布上线、自己维护，啥都自己干。

- 优点：代码掌握在自己手里很安全；想加什么功能不受限制、很灵活
- 缺点：最麻烦，开发 + 上线 + 维护全包
- 适合：自学编程的同学练手（博客功能丰富且典型：登录、评论、标签），也可基于 GitHub 开源项目二次开发；只想快速写文章则没必要

### 2. 站点生成器

大佬将博客的通用功能（如文章管理）抽象成**站点生成器**，用极少的命令 + 配置文件即可自动生成精美网站：

- 博客站：Hexo、Hugo
- 文档站：Docsify、VuePress、Dumi

绝大多数站点生成器只能生成**静态网站**（内容固定、无需从数据库动态获取），因此优点突出：

- **省钱**：文件扔 GitHub Pages、Gitee Pages 等即可免费部署
- **速度快**：省去数据动态获取过程，配合 CDN 加载飞快
- **SEO 好**：静态页面更容易被搜索引擎蜘蛛抓取、稳定排名
- **易维护**：功能纯粹，比动态网站好维护

缺点：内容需提前确定、不能动态添加；功能纯粹导致交互性弱，可配合插件实现评论、全文检索等功能。对博客来说静态网站基本够用。

具体搭建教程见 [[工具 13 - Hexo 博客搭建教程]]、[[工具 27 - VuePress 文档网站搭建]]。

### 3. 建站程序

快速做**动态博客**的现成程序，主流推荐 WordPress，轻量可选 Typecho：

- 按官方文档一键安装 → 引导式初始化配置 → 挑选主题美化
- 后台直接发布和管理文章，用户管理、分类、标签、评论等功能开箱即用
- 可装插件扩展（发邮件、表单收集等），必要时自己改源码

### 4. 建站平台

线上拖拽式建站平台，不用安装任何东西，套模板 + 界面拖拽即可出网站，平台提供域名、一键上线，维护也全包。适合完全不想碰技术、专注内容的场景（如凡科建站）。

### 5. 购买

花钱找工作室/个人开发者做网站，常见渠道：

- 云服务提供商（如 BAT 云官网）：大厂相对专业靠谱，更推荐
- 建站主题官网（收费模板 + 专业建站服务）
- 某宝（价格一般较贵）

## 对比表格

从四个维度对比（星星越多越优秀）：

| 方式 | 省事 | 省钱 | 简易 | 灵活 |
| :--- | :--- | :--- | :--- | :--- |
| 自主开发 | ⭐ | ⭐⭐⭐ | ⭐ | ⭐⭐⭐⭐⭐ |
| 站点生成器 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐ |
| 建站程序 | ⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐ |
| 建站平台 | ⭐⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐ |
| 购买 | ⭐⭐⭐⭐⭐ | ⭐ | ⭐⭐⭐⭐⭐ | ⭐ |

## 选型建议

- 自主开发**最灵活但最麻烦**；站点生成器**最省钱**（大量免费静态托管服务）；直接购买**最省事但最费钱**、后续修改难；开源建站程序 / 建站平台**相对均衡**，方便易用且功能齐全
- 后续计划深度定制（自己写代码扩展）→ 选**开源建站程序**（如 WordPress）
- 只想低成本快速写文章 → 选**站点生成器** + 免费静态托管（部署方式见 [[DevOps 06 - 免费上线网站的几种方法]]）
