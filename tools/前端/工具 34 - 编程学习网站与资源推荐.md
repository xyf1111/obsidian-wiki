# 工具 34 - 编程学习网站与资源推荐

> 从入门教学、开源资源检索、技术文章社区到刷题求职的网站清单，外加 9 个值得长期收藏的开源教程仓库（Java / 前端 / Python / SQL / Docker / AI / Go）——自学编程时按「学 → 查 → 读 → 练」四个环节各取所需。

## 核心要点

### 一、学习类网站（入门教学）

| 网站 | 地址 | 特点 |
| --- | --- | --- |
| freeCodeCamp | https://chinese.freecodecamp.org/ | 免费实战学编程，课程丰富，尤其适合想学前端 web 开发的同学；每小节有教学 + 代码示例 + 在线写代码完成任务，像玩游戏闯关 |
| 菜鸟教程 | https://www.runoob.com/ | 简洁却不简单：前端、Java、Python、C++、PHP 等主流语言的文档教程全免费，附大量可直接在线练习的代码示例 |
| W3CSchool | https://www.w3cschool.cn/ | 多元化教学网站，免费在线文档教程多，支持手机端学习；实战训练为闯关模式，适合新手（同名的 W3School 年久失修，相对一般） |
| 慕课网 | https://www.imooc.com/ | 各编程方向的免费入门/进阶视频教程，学习过程中可记录笔记、阅读他人笔记，帮助养成记录习惯 |
| 蓝桥云课 | https://www.lanqiao.cn | 通过做实验学编程：使用真实的云服务器环境写代码、开发项目，比看书印象更深 |
| B 站 | https://www.bilibili.com/ | 大量免费视频教程与优质知识分享博主，入门、项目、考研、大厂求职指南都有 |
| 知乎 | https://www.zhihu.com/topic/19554298 | 没有系统教学，但有大量编程学习心得、经验分享与程序员相关讨论，适合了解行业全貌 |

另见 [[自学编程的入门方法]] 的「推荐学习网站」小节。

### 二、资源类平台（查资料 / 找项目）

| 平台 | 地址 | 特点 |
| --- | --- | --- |
| GitHub | https://github.com/ | 世界一流代码开源平台，数亿公开仓库；可搜索代码参考学习、上传代码共享、协作开发，也能搜到学习笔记、趣味项目甚至「不加班公司名单」 |
| Gitee | https://gitee.com/ | 软件开发协作平台，可理解为国内版 GitHub；同样支持搜索、共享、协作，项目数不及 GitHub 但访问速度更快 |
| 菜鸟工具 | https://c.runoob.com/ | 汇总程序员常用开发工具：各语言在线代码编辑器、代码转换、格式化工具等，随用随取（类似的还有 BeJSON，收藏一个即可） |
| 开发者搜索 | https://kaifa.baidu.com/ | 厌倦搜索广告时的替代品：纯净无广告、专为开发者定制搜索结果，让技术搜索更简单高效 |
| HelloGitHub | https://hellogithub.com/ | 人工维护的编程项目推荐网站，可分类浏览有趣、入门、优质的开源项目；每月发布一期「项目全家桶」推荐各语言好项目 |

在线编写/运行代码的平台见 [[工具 33 - 在线编程网站与在线 IDE]]。

### 三、技术文章与社区

| 网站 | 地址 | 特点 |
| --- | --- | --- |
| CSDN | https://www.csdn.net/ | 搜索编程问题时命中率最高的中文站；看技术博客、下载资料、提问题、看教程，也可开通自己的博客 |
| 掘金 | https://juejin.cn/ | 专注分享编程技术文章，覆盖前端、后端、架构、AI 等上百个分类，前端优秀作者尤其多 |
| 博客园 | https://www.cnblogs.com/ | 经典程序员博客网站，界面陈旧但文章丰富，可轻松打造自己的专属博客记录学习心得与代码笔记 |
| InfoQ | https://www.infoq.cn/ | 国内相对高端的软件开发文章与资讯站点，偏前沿技术、企业技术与工程思考；另有免费电子书、大咖直播回放 |
| 开源中国 | https://www.oschina.net/ | 国内开源技术交流社区：最新软件发展/更新资讯、前沿技术文章、各类优质开源项目搜索 |

### 四、刷题与求职

| 网站 | 地址 | 特点 |
| --- | --- | --- |
| LeetCode | https://leetcode-cn.com/ | 一流的在线刷题、学算法网站，每个知识点都有专题教程；建议看完教程即时练习、举一反三 |
| 牛客网 | https://www.nowcoder.com/ | 求职找工作平台：学编程、做习题、刷算法，还能看各公司各方向的面试题与面试经验，并参与内推、在线笔试、模拟面试 |

算法学习路线见 [[算法与数据结构 01 - 学习路线]]，求职相关内容见 [[编程学习与求职架构]]。

### 五、优质开源教程仓库（可直接在线阅读）

| 项目 | 地址 | 说明 |
| --- | --- | --- |
| JavaGuide | https://javaguide.cn/ | 全面的 Java 指南：帮初学者了解完整知识体系、帮求职者准备面试；作者准备面试时开源，如今已成为 GitHub 超 10 万 star 的顶流项目 |
| LeetBook | https://leetcode-cn.com/leetbook/ | 轻松学算法的在线小书：分阶段、按知识点的入门教程，有图解、视频与他人题解，可选任意语言随时在线练习；另附《图解算法数据结构》等免费小书 |
| 被删的前端游乐场 | http://www.godbasin.com/ | 同事小姐姐的前端文章合集，几百篇：新手入门教程、前端深入理解、领域解决方案与技术分享 |
| Python 100 days | https://github.com/jackfrued/Python-100-Days | 分阶段 Python 入门教程：基础、进阶、开发框架、爬虫、数据分析、人工智能、项目管理；每天内容小而精，适合时间不多、想持续学习或巩固复习的同学 |
| GitHub 漫游指南 | https://github.com/phodal/github | 在线小书，不是枯燥的 GitHub 教程，而是结合作者使用 GitHub 一万多小时的亲身经历，讲使用技巧、打造自己的项目、探索编程可能性 |
| SQL 自学网 | http://xuesql.cn/ | 边学边练、实时查看运行结果，用最快速度学会数据库与 SQL 基本使用（对应路线见 [[MySQL 15 - 学习路线]]） |
| Docker 从入门到实践 | https://vuepress.mirror.docker-practice.com/ | 可在线阅读的 Docker 教程，含常见问题总结、热门开源镜像、工作中积累的最佳实践 |
| 《动手学深度学习》 | https://github.com/d2l-ai/d2l-zh | 完全开源的人工智能零基础入门教程，全中文、可在线阅读，已被全球近 200 所大学用于教学；附大量练习与源码，边学边练 |
| 地鼠文档 | https://www.topgoer.cn | Go 语言学习资源合集网站：入门教程、代码示例、框架、类库、中文文档、算法、面试题、电子书，可在线阅读与免费下载 |

Java 方向的文档教程与实战项目另有单独汇总，见 [[Java 47 - Java 学习资源与项目汇总]]。
