# 工具 34 - 编程学习网站与资源推荐

> 从入门教学、开源资源检索、技术文章社区到刷题求职的网站清单，外加 9 个值得长期收藏的开源教程仓库（Java / 前端 / Python / SQL / Docker / AI / Go）和 4 个面向程序员的英语学习项目，以及 3 个值得关注的前端团队开源项目与 10 余个创意练手开源项目——自学编程时按「学 → 查 → 读 → 练」四个环节各取所需。

## 核心要点

### 一、学习类网站（入门教学）

| 网站 | 地址 | 特点 |
| --- | --- | --- |
| freeCodeCamp | https://chinese.freecodecamp.org/ | 免费实战学编程，课程丰富，尤其适合想学前端 web 开发的同学；每小节有教学 + 代码示例 + 在线写代码完成任务，像玩游戏闯关 |
| 菜鸟教程 | https://www.runoob.com/ | 简洁却不简单：前端、Java、Python、C++、PHP 等主流语言的文档教程全免费，附大量可直接在线练习的代码示例 |
| W3CSchool | https://www.w3cschool.cn/ | 多元化教学网站，免费在线文档教程多，支持手机端学习；实战训练为闯关模式，适合新手（同名的 W3School 年久失修，相对一般） |
| 慕课网 | https://www.imooc.com/ | 各编程方向的免费入门/进阶视频教程，学习过程中可记录笔记、阅读他人笔记，帮助养成记录习惯 |
| 蓝桥云课 | https://www.lanqiao.cn | 通过做实验学编程：使用真实的云服务器环境写代码、开发项目，比看书印象更深 |
| programming-idioms | https://programming-idioms.org/ | 收录 30 多种语言、250+ 个常用代码片段（idiom = 惯用法）的对照网站：同一功能可横向比较各语言实现（如复制文件用 Python 一行搞定）；既能查看某门语言的全部常用代码片段（学新语言时巩固基础、学优秀写法），也能一键对比两种语言的语法差异（如 Java vs C++ 的打乱列表、随机取元素、判断列表是否包含某个值） |
| B 站 | https://www.bilibili.com/ | 大量免费视频教程与优质知识分享博主，入门、项目、考研、大厂求职指南都有 |
| 知乎 | https://www.zhihu.com/topic/19554298 | 没有系统教学，但有大量编程学习心得、经验分享与程序员相关讨论，适合了解行业全貌 |

另见 [[自学编程的入门方法]] 的「推荐学习网站」小节。

### 二、资源类平台（查资料 / 找项目）

| 平台 | 地址 | 特点 |
| --- | --- | --- |
| GitHub | https://github.com/ | 世界一流代码开源平台，数亿公开仓库；可搜索代码参考学习、上传代码共享、协作开发，也能搜到学习笔记、趣味项目甚至「不加班公司名单」 |
| Gitee | https://gitee.com/ | 软件开发协作平台，可理解为国内版 GitHub；同样支持搜索、共享、协作，项目数不及 GitHub 但访问速度更快 |
| 菜鸟工具 | https://c.runoob.com/ | 汇总程序员常用开发工具：各语言在线代码编辑器、代码转换、格式化工具等，随用随取（类似的还有 BeJSON，收藏一个即可） |
| 开发者搜索 | https://kaifa.baidu.com/ | 厌倦搜索广告时的替代品：纯净无广告、专为开发者定制搜索结果，让技术搜索更简单高效 |
| HelloGitHub | https://hellogithub.com/ | 人工维护的编程项目推荐网站，可分类浏览有趣、入门、优质的开源项目；每月发布一期「项目全家桶」推荐各语言好项目 |

在线编写/运行代码的平台见 [[工具 33 - 在线编程网站与在线 IDE]]。

### 六、程序员英语学习资源（GitHub 开源项目）

英语能力直接影响日常交流、变量命名、读英文文档与晋升答辩的表达；下面 4 个项目覆盖「兴趣启发 → 系统提升 → 方法训练 → 词汇手册」四个层次，均可在 GitHub 免费在线阅读。

| 项目 | 地址 | 说明 |
| --- | --- | --- |
| 人人都能用英语 | https://github.com/xiaolai/everyone-can-use-english | 近 5k star 的在线小书，不是单词书也不是练习册，而是从口语、语音、朗读、词典、语法、精读等方面给你启发，带你重新认识和理解英语；在啃厚厚的单词书之前不妨先读它 |
| 英语提升诀窍 | https://github.com/byoungd/English-level-up-tips-for-Chinese | GitHub 上最受欢迎的英语学习项目（近 20k star）：从认知、单词、听力、阅读、口语五方面重识英语，并给出高效学习建议与配套资源（英文脱口秀、电影、YouTube 频道、英文原版书等），20 分钟即可读完 |
| 程序员英语学习指南 | https://github.com/yujiangshui/A-Programmers-Guide-to-English | 近 10k star，专为程序员编写的英语学习指南：深挖语言学习本质（多用中文举例、以程序员易理解的方式思考），给出可自行推演的训练方法；核心观点是「语言学习没有技巧」，关键是按本质设计适合自己的方法并用以甄别网上的资料 |
| 程序员工作中常见的英语词汇 | https://github.com/Wei-Xia/most-frequent-technology-english-words | 面向程序员的英语词汇手册：收集计算机书籍、文档、文章中的高频技术词汇，目标是掌握后无障碍阅读英文技术文章与文档；不要死记硬背，工作中遇到时对照着读几遍即可 |

### 七、值得关注的前端团队开源项目（知识渠道）

腾讯新闻中台前端团队（TNTWeb，GitHub 组织 [tnfe](https://github.com/tnfe)）在 GitHub 上公开了几个可持续阅读的前端项目，适合用来感知前沿动态、拓宽技术名词量：

| 项目 | 地址 | 说明 |
| --- | --- | --- |
| TNT-Weekly | https://github.com/tnfe/TNT-Weekly | 持续更新的前端周刊：官方精选 web 前端领域（含 H5、小程序等）的国内外技术文章、开源项目与前端技巧，帮读者过滤无意义信息；进仓库可直接挑往期读，如「React 运行时优化方案的演进」「从零到一实现企业级微前端框架」 |
| FEDiagram | https://github.com/tnfe/FEDiagram | 「图说前端」：用图画的方式讲清前端开发中晦涩难懂的知识细节，共 15 期、每期一个主题配几张知识图（如第 4 期讲 ES3 / ES5 / ES6 的区别）；已停更，但已整理的 15 期仍值得读 |
| awesome-blackmagic | https://github.com/tnfe/awesome-blackmagic | 前端「奇技淫巧」合集：作者把开发中常用的技巧称为「魔法」，按语言、框架分类（黑魔法 = js / ts 相关，蓝魔法 = 框架相关），收录实用 JavaScript 小技巧与有趣的技术实践；也已停更 |

**为什么值得读技术周刊**：除了具体知识，最大的好处是**多接触名词**——有些技术你没用上，可能只是不知道它的存在；看到新词之后，用「搜索 → 阅读 → 实践」一套组合拳就能把它拿下。

### 八、开源创意项目推荐（练手思路启发）

自学时不知道该做什么项目？网上 Java 项目多是商城、博客、管理系统，同质化严重、功能基础还 Bug 层出不穷。下面这些非业务型开源项目脑洞大、结构规整、代码规范，适合作为练手素材与思路启发（按项目名在 GitHub 搜索即可）。评级为源作者的参考值：难度 · 创意 · 实用。

| 项目 | 方向 | 技术栈 | 评级 | 说明 |
| --- | --- | --- | --- | --- |
| windows11 | 前端 | React + CSS Modules | ⭐️⭐️ · ⭐️⭐️⭐️⭐️ · ⭐️ | 能直接在浏览器里运行的 Windows 11，界面与体验高度还原，还能浏览网页、打开 VS Code 写代码；技术并不复杂（主流前端技术 + iframe 内嵌实现高级功能），胜在项目结构规范清晰，适合学前端 |
| air-conditioner | 前端 | React + TypeScript + Sass + Redux + Material UI | ⭐️⭐️⭐️ · ⭐️⭐️⭐️⭐️⭐️ · ⭐️ | 曾刷屏朋友圈的「云空调」，只有一个页面却用上不少前端主流技术；打开小空调还会触发真实的吹风音效 |
| codelf | 前端 | React + Gulp + Animate.css + SearchCode | ⭐️⭐️ · ⭐️⭐️⭐️ · ⭐️⭐️ | 变量命名神器：输入中英文词汇，自动推荐合适的英文变量名；原理是先用翻译插件把中文翻成英文，再拿英文单词请求 SearchCode 代码搜索服务 |
| bytemd | 前端 | Vue / React / Svelte + TypeScript + Rollup | ⭐️⭐️⭐️⭐️ · ⭐️⭐️ · ⭐️⭐️⭐️⭐️ | 字节跳动开源的富文本编辑器组件：与掘金写作风格一致、同时支持 Markdown 与傻瓜式操作、支持多主题、插件式设计可按需定制，且适配原生与主流框架（含 Svelte）；编辑器选型对比见 [[工具 39 - 富文本编辑器选型（开源免费）]] |
