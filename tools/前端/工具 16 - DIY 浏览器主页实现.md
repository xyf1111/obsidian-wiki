## 项目背景

> 鱼皮从 0 到 1 做了一个『编程主页』（程序员浏览器主页），并完整开源，登上 GitHub 趋势榜。项目本身不需要复杂技术，仅需一点点前端基础即可完成。本文分享完整制作过程与实现原理，最后教你怎么**一键上线自己的项目**，动手 DIY 自己的浏览器主页。

## 一、项目流程方法论

做任何项目都应遵循：**需求分析 → 产品设计 → 技术选型 → 跑通 Demo → 开发 → 部署上线**。

### 1. 需求分析

开发前先明确目标。要做的是一个精简的浏览器主页，弥补默认标签页和插件主页的局限（如不支持切换壁纸、无法自定义快捷链接）。

- 参考痛点：KIM 主页的默认链接几乎用不到，更希望主页是自己的创作平台（CSDN、牛客、GitHub 等）
- 虽然可登录 KIM 主页改链接，但自己定制更灵活，且工作量不大
- 功能优先级：**搜索（最重要）→ 快捷链接 → 其他锦上添花**

### 2. 产品设计

- 审美不足就参考现有优秀产品：整个设计参考 KIM 主页
- 做项目/在企业做项目同理：先参考现有项目，学习优秀之处，以此为基础改进

### 3. 技术选型

根据功能与设计稿选型（语言、框架、脚手架、类库），好的选型能极大提升开发效率。浏览器主页是很小的前端项目，不需要重型框架：

- **原生方案**：HTML + CSS + JavaScript 三件套 + jQuery 库，节省代码量
- **框架方案**：轻量 Vue / React + 优雅组件库，灵活实现交互、省去自研组件

本文选型：

- **React**（熟练）+ **React Static** 静态站点开发框架
- **Ant Design** 组件库：流行，组件支持多端自适应，移动端体验好；导航菜单、抽屉、按钮等组件满足需求
- 部署方式：网站几乎没有动态加载的数据 → 选用静态网站托管服务

### 4. 先跑通 Demo 再开发

- 本地运行一个最简单的 Demo，试着加一个按钮组件，验证组件库是否引入成功
- 执行一次打包构建，确认环境和依赖没有问题后再正式开发

## 二、基础界面

- 开发任何前端项目都先做基础界面：**从整体到局部，将页面由上至下进行结构拆解**
- 除按钮组用固定定位放右下角外，其余区块从上至下排列，加间距即可

## 三、万能搜索

万能搜索：用户仅输入一次，即可从多个搜索引擎获取信息。

实现原理：用 HTML `<iframe>` 标签将整个百度/Bing 等搜索引擎嵌入页面；`current` 变量决定当前使用哪个搜索引擎，`searchText` 变量确定搜索内容，拼接 iframe 地址即可：

```jsx
{
  current === "baidu" &&
  <iframe src={`https://www.baidu.com/s?wd=${searchText}`}
          style={{border: 'none', height: '100vh', position: 'fixed', zIndex: 1}}
        />
}
{
  current === "bing" &&
  <iframe src={`https://cn.bing.com/search?q=${searchText}`}
          style={{border: 'none', height: '100vh', position: 'fixed', zIndex: 1}}
        />
}
```

## 四、壁纸切换

针对不同类型的壁纸选择不同的实现方式：

### 1. 静态壁纸

静态壁纸即一张图片，直接用 `<img>` 标签，设置**绝对定位 + 全屏显示**即可。

### 2. 动态壁纸

- 不是 GIF 动图，而是用 **HTML5 Canvas 画布等技术实现的交互式网页**
- 每个动态壁纸都是一个独立小项目（含 HTML、CSS、JS 文件），可直接在浏览器中运行
- 直接采用 `<iframe>` 标签引入这些动态壁纸页面

### 3. 随机壁纸

- 使用免费的**搏天 API 随机壁纸接口**，完全不用自己爬取图片再做随机
- 为解决浏览器跨域限制，使用 **JsonBird 免费请求代理**：把请求随机图片的地址作为参数拼接在 JsonBird 地址后即可

```js
await axios.get(`https://bird.ioliu.cn/v1/?url=${cover.api}`)
```

## 五、主题切换

支持白底 / 透明两种主题动态切换。定义两个 CSS 文件分别作为白底和透明主题的样式，切换为透明主题时，只需给最外层的 HTML 标签增加一个 `ghost` 类名（另一种实现思路见《工具 06 - CSS变量与主题切换》，两套 CSS 文件方案更简单直接）：

```css
/* 白底 CSS 文件 */
.search-wrapper {
 background: white; /* 白色背景 */
}
  
/* 透明模式 CSS 文件 */
.ghost .search-wrapper {
  background: transparent; /* 透明背景 */
}
```

最外层标签根据透明模式是否开启来确定类名：

```jsx
{/* 如果透明模式开启，则添加 ghost 类名 */}
<div className={ghostClose ? '' : ' ghost'}>
</div>
```

多主题有很多实现方式和插件，这并非最优雅的方案，但比较简单易懂。

## 六、部署上线

1. **构建**：项目做完后，用框架自带命令将所有文件构建成一个目录包
2. **本地预览**：直接双击 `index.html` 文件，或使用 `serve` 在本地运行网页浏览效果
3. **发布上线**：
   - **Vercel**：一行命令即可发布，供他人输入网址在线访问
   - **腾讯云静态网站托管 / 云托管**：一行命令甚至点击"一键部署按钮"即可上线，访问速度更快，**提供免费空间，完全足够学习和小项目使用**

## 小结

- 技术栈不重：React + React Static + Ant Design + iframe + axios
- 关键实现思路：
  - 万能搜索 = iframe 嵌入搜索引擎 + `current` / `searchText` 变量拼接 URL
  - 静态壁纸 = img 绝对定位全屏；动态壁纸 = iframe 引入 Canvas 交互网页；随机壁纸 = 免费 API + 免费代理解决跨域
  - 主题切换 = 两套 CSS 文件 + 最外层 `ghost` 类名
- 项目已开源，所有代码均可一键部署，适合作为前端小项目练手与学习
