# 工具 23 - 免登录资源导航小程序实战（Taro + 云开发）

> 用 Taro + Taro UI 开发一个所有用户都能查看和推荐资源的微信小程序，后端采用腾讯小程序云开发，无需自建服务器，并通过云开发未登录模式实现免登录访问，帮助快速了解小程序开发流程与云开发技术。

## 技术选型

- **前端：Taro 框架 + Taro UI**。Taro 是基于 React 的跨端开发框架，写一套代码可自动生成微信小程序、H5、APP 等应用，且为很多复杂功能提供了函数封装，提升开发效率；Taro UI 是基于 Taro 的 UI 库，提供图片上传、选择器等现成组件，满足常见开发需求。
- **后端：腾讯小程序云开发**。传统方式用 SpringBoot、Laravel、Django 等框架需要自己搭建服务器、数据库、日志、监控、运维，对只懂前端或想快速开发的同学门槛太高；云开发免去这些负担，专注实现功能本身。

## 云开发优势

小程序云开发是微信团队联合腾讯云推出的专业小程序开发服务，原生打通微信开放能力，优势：

1. **免后端服务器**：直接使用平台提供的云数据库、云存储、音视频、AI 等能力快速开发业务。
2. **安全易接入**：无需管理证书、签名、密钥，直接调用微信 API，复用微信私有协议及链路保证安全性。
3. **多端复用**：支持环境共享，一个后端环境可开发多个小程序、公众号、网页，便捷复用业务代码与数据。
4. **不限语言框架**：可用任意语言和框架开发，构建为容器后快速托管至云开发。
5. **按量计费**：成本更低，支持自动扩缩容。
6. **扩展能力**：支持一键部署静态网站，并能用云 CMS 管理数据内容。

例如查询数据，直接用云开发 SDK 几行代码即可完成。

## 项目搭建

参照 Taro 框架官方文档的快速开始部分，安装 Taro 命令行工具并初始化小程序应用。

初始化时选择模板为**云开发**，Taro 会自动生成包含云开发示例代码的项目。

## 页面开发

共创建两个页面：**资源列表页**和**推荐资源页**，需要用到的组件有列表、表单、输入框、按钮、图像上传等。

Taro UI 支持以上所有组件，按官方文档接入，复制组件代码到页面中修改即可快速完成。资源列表页示例代码（精简版）：

```jsx
<View className='list'>
  {/* 列表组件 */}
  <AtList>
    {resourcesView}
  </AtList>
  {/* 固钉组件，点击跳转至推荐页 */}
  <AtFab className="fab-btn"
         onClick={() => navTo(xx)}>
    <AtIcon value='add'/>
  </AtFab>
</View>
```

## 接入云开发

### 开通云环境

在微信开发者工具中点击云开发、开通环境即可，每位用户可享有一定数量的免费环境。云开发界面中可对云数据库、云存储、云函数等资源进行监控和管理。

### 云数据库

在云数据库中创建一张 **资源表**（resource）用于读写资源数据。控制台支持可视化数据库管理（记录、索引、数据权限等）。

每个环境都有唯一的 id，前端引入云开发 SDK 并传入环境 id 初始化（Taro 封装好的 `init` 方法）：

```js
Taro.cloud.init({
  // 环境 id
  env: 'xx',
})
```

之后即可在前端直接调用操作数据库的接口，例如插入数据：

```js
const db = Taro.cloud.database();
// 添加数据到 resource 表
db.collection('resource').add({
  data
}).then(res => {
  // 成功
  return res;
}).catch(err => {
  // 失败
  console.error(err);
});
```

### 云存储

推荐资源时需要用户上传图片，可直接在前端调用云存储，几行代码搞定：

```js
// 上传文件
const res = await Taro.cloud.uploadFile({
  cloudPath: '上传到云存储的位置',
  // 要上传图片的本地路径
  filePath: pictureUrl,
})
// 获取图片 id，可下载或直接展示
picture = res.fileID;
```

可在云开发控制台管理云存储中的文件、配置权限、缓存等。

### 云函数

若默认接口不满足需求，可自己写后台接口作为**云函数**部署到腾讯云，前端请求即可，与自建后端类似。例如部署登录函数获取用户在小程序中的唯一 id，控制台可查看函数调用日志、管理权限。

## 免登录模式

按上述流程开发完成后，开发者工具中可正常推荐和展示资源；但上线分享给其他用户后会出现权限问题、功能全部失效——因为云开发制定了安全规则，**默认不允许未登录用户访问**。若小程序分享到朋友圈，要求朋友登录才能看资源列表，体验太差，因此需要实现无登录调用。

云开发为此提供了 **未登录模式**，该模式下不存在用户登录态，应用场景：

1. **单页模式**：小程序/小游戏分享到朋友圈被打开时。
2. **Web 未登录模式**：没有登录的 Web 环境中。

该模式默认关闭，需在「云控制台 - 设置 - 权限设置」中手动为云环境开启**允许未登录访问**。

### 安全规则

开启未登录模式后，客户端（前端）的权限控制**必须使用安全规则**：云函数、数据库和文件存储的访问都必须通过安全规则。因此除了控制台开启允许未登录访问外，还需在云数据库、云存储和云函数的权限设置中分别选择安全规则并配置。

安全规则语法（以云数据库为例，选择自定义安全规则）：

- `read` / `write`：分别代表读写权限。
- `doc`：表示当前的一条数据。
- `auth`：表示当前登录的用户。
- 表达式为 `true` 时允许访问。

默认规则下，当前登录用户必须是该条数据的创建者才能读写。**未登录用户访问时 auth 字段为空**，若要允许所有用户读写所有资源，直接将表达式值设置为 `true`。

各资源规则配置：

- **云数据库**：将规则表达式改为 `true`，允许所有用户读写。
- **云存储**：`resource` 表示一个资源，将表达式改为 `true`，允许所有用户读写存储的所有文件。
- **云函数**：可为不同函数设置不同规则，例如 `login` 函数允许所有用户访问，其他函数仅允许已登录用户访问。

安全规则非常灵活，合理运用可在满足资源调用需求的同时增加资源安全性。
