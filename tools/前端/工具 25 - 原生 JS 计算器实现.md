# 工具 25 - 原生 JS 计算器实现

> 用 HTML + CSS + JavaScript 三件套五分钟实现一个计算器网站：核心是利用 JS 内置 eval 函数直接计算表达式字符串，无需自己解析公式。前端学习要多写小项目练手，熟能生巧。

## 1. 开发基本结构（HTML）

写出显示框和按钮的基本结构，`id="result"` 的 div 用于展示计算式和结果：

```html
<body>
  <div id="wrapper">
    <div id="result"></div>
    <div class="row">
      <button>+</button>
      <button>-</button>
      <button id="ac">AC</button>
    </div>
    <div class="row">
      <button>/</button>
      <button>*</button>
      <button id="getResult">=</button>
    </div>
    <div class="row">
      <button>7</button>
      <button>8</button>
      <button>9</button>
    </div>
    <!-- 其余数字按钮同理 -->
  </div>
</body>
```

## 2. 美化样式（CSS）

- `#wrapper` 指定整个计算器的宽度
- `display: flex` 配合 `flex: 1` 控制每行三列布局
- 按钮添加边框、背景色、控制字体大小和内边距
- `body` 加 `user-select: none` 防止用户选中按钮文字，影响体验

```css
body { padding: 20px; user-select: none; }
#wrapper { width: 320px; }
#result { height: 100px; border: 1px solid #ddd; padding: 20px; box-sizing: border-box; }
.row { display: flex; }
.row button { padding: 20px; flex: 1; font-size: 16px; border: 1px solid #ddd; background: #eee; }
```

## 3. 实现功能（JavaScript）

先用内置函数获取所有按钮 DOM 对象：

```js
let buttonObjs = document.getElementsByTagName("button");
let resultObj = document.getElementById("result");
let acObj = document.getElementById("ac");
let getResultObj = document.getElementById("getResult");
```

### 输入：点击数字/运算符 → 拼接算式

对非 AC、= 的按钮绑定点击事件，本质是对算式做字符串拼接：

```js
for (const buttonObj of buttonObjs) {
  if (!['AC', '='].includes(buttonObj.innerHTML)) {
    buttonObj.addEventListener('click', () => {
      resultObj.innerHTML += buttonObj.innerHTML;
    })
  }
}
```

### 计算：eval 函数一步求值

JavaScript 提供了强大的 **eval 函数**：传入公式字符串，直接计算表达式的值，无需自己解析复杂公式：

```js
getResultObj.addEventListener('click', () => {
  resultObj.innerHTML = eval(resultObj.innerHTML);
})
```

### 清空：AC 按钮

```js
acObj.addEventListener('click', () => {
  resultObj.innerHTML = '';
})
```

## 核心要点

- 计算器看似难在「解析复杂公式并求值」，但利用 JS 的 `eval()` 函数只需一行代码
- 开发流程遵循前端三件套基本套路：先结构（HTML）→ 再样式（CSS）→ 最后交互（JS）
- 小项目练手是前端入门最有效的方式之一，五分钟就能做出一个实用又「看起来很牛」的作品
