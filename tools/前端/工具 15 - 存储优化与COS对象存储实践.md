## 存储优化概述

存储是一个广泛的概念，涵盖数据库存储、内存存储、对象存储、块存储、文件存储等多种技术。存储优化可以从多个维度展开：

- 存储空间优化
- 存储成本优化
- 存储安全性优化
- 存储可用性优化
- 存储可靠性优化
- 存储性能优化

以下分享一些通用的存储优化手段，并重点以腾讯云 COS 对象存储为例，进行实践层面的讲解。

### 其他优化角度

- **存储可用性优化**：保证存储系统在任何时候都能正常提供服务，常用方法有容错、冗余备份、故障转移、快速故障检测恢复等。
- **存储可靠性优化**：保证数据的完整性和系统的稳定性，可通过选用高可靠硬件设备实现。
- **存储性能优化**：提高存储系统的读写速度、降低响应延迟。
- **存储管理优化**：通过自动化管理工具提高操作、配置和监控存储资源的有效性。
- **存储可观测性优化**：通过可视化监控看板、日志和告警系统，更好地检测存储系统的运行状态、资源占用和行为。

实际开发中，一般选用第三方云服务提供的存储（如腾讯云 COS），这些服务已内置了可用性、可靠性、性能、管理和可观测性的保障。因此在项目中，重点从 **存储空间优化**、**存储成本优化**、**存储安全性优化** 三个角度进行优化。

## 存储空间优化

### 1. 文件压缩

可以将多个文件打包为压缩包，也可以对单个文件进行压缩（如用户头像、帖子封面）。COS 官方强烈推荐此方式，并自带了图像自动压缩处理功能（数据万象），通过配置即可启用。

### 2. 文件瘦身

除压缩文件外，还可以精简文件本身的体积。

### 3. 数据去重

通过文件的 MD5 值判断是否已存在相同文件，若重复则不再上传，而是将新文件的路径指向已有文件。类似网盘秒传的实现原理，但实现成本较高。

### 4. 文件清理

定期清理项目中不需要的文件，是业务开发中最常用的方式。

## 存储成本优化

对于大部分企业来说，**存储容量费用** 和 **流量费用** 是云存储成本的主要组成部分。成本优化可从以下角度进行。

### 选择合适的存储类型

腾讯云 COS 提供了多种存储类型：

| 存储类型 | 说明 |
|---------|------|
| 标准存储 | 频繁读写场景（UGC、电商图片等读多写少业务），可选用标准存储（多 AZ）以提升可用性和数据持久性 |
| 低频存储 | 少量读场景（约一个月读一次），如日志数据分析、网盘数据，读取频率低但对性能有要求 |
| 归档存储 | 极少量读场景（约三个月读一次），如视频监控、日志数据归档 |
| 深度归档存储 | 基本不读取场景（约半年读一次），如医疗影像、档案资料的长期备份，相较标准存储可节省约90%存储费用 |

**注意**：存储总费用最低的存储类型未必最合适。若业务数据需要频繁下载，低频/归档/深度归档存储的取回费用可能导致整体费用反而更高。

### 数据沉降

数据的访问热度一般随存储时间延长而降低。数据沉降分为两个阶段：

1. **分析**：通过对象存储提供的清单/访问日志分析，或在业务代码中自行统计分析。
2. **沉降**：通过对象存储的 **生命周期** 功能自动将不常访问的数据沉降到更低成本的存储类型。此外也可通过数据库记录资源使用时间，自行调用 API 批量沉降。

### 减少访问

目的是降低流量费，例如使用本地文件缓存，减少对对象存储的访问。CDN 本质上也是一种缓存，能减少回源，但会产生额外的 CDN 流量费用。

## 存储安全性优化

### 官方建议的安全方案

#### KMS 白盒密钥

与设备绑定，安全性极高，但成本较高。

#### 权限隔离

授权 CAM 用户可以在哪种条件下、通过哪种方式、对哪些资源进行哪种操作。（腾讯云访问管理控制台截图）

#### 对象锁定

对核心敏感数据（如金融交易数据、医疗影像数据）通过对象锁定功能防止文件被删除或篡改。配置后在有效期内，存储桶内的所有数据处于只读状态，不可覆盖写或删除。（对象锁定配置界面截图）

#### 数据灾备

- **版本控制**：每次操作创建新版本文件，通过"删除标记"区分文件是否被删除（逻辑删除），可通过指定版本号访问历史数据或进行数据回滚。（版本控制配置界面截图）
- **存储桶复制**：主存储桶数据被删除时，可从备份存储桶通过批量拷贝恢复数据。（存储桶复制配置界面截图）
- **冷备份**：通过生命周期功能将备份数据沉降到低频或归档存储，实现低成本冷备。（冷备方案流程图截图）

此外，可通过事中监控（操作对象存储时触发事件通知）和事后追溯（查看日志）辅助安全性分析。

### COS 安全管理

COS 控制台提供以下安全管理功能：

#### 1. 跨域访问设置

跨域访问是通过 HTTP 请求从一个域去请求另一个域的资源。只要协议、域名、端口有任何一个不同，即视为不同域。跨域是浏览器的限制，一般用于前端直传对象存储的场景。

可在控制台中添加规则，根据域名、请求方法、请求头信息进行配置。配置完成后，对象存储会允许该域名的跨域请求。

#### 2. 防盗链设置

**盗链**：指网站或应用程序在未经资源拥有者许可的情况下，直接引用并展示其他网站的资源（如图片、音频、视频）。盗链会消耗被引用方的流量，是一种成本极低但危害巨大的攻击方式。

**防盗链方法**：通过请求头中的 `Referer`（网站请求来源）进行校验，若请求头中没有该字段或来源不符合预期，则禁止请求。

实践建议：配置 Referer 白名单，仅允许特定范围的域名访问，并拒绝空 Referer。（防盗链配置界面截图）

配置防盗链后，白名单之外的域名访问资源会返回 403 错误，防盗链生效。

#### 3. 服务端加密

分为两种模式：

- **加密存储**：数据写入磁盘前进行加密，访问时自动解密，整个过程在服务端完成。
- **加密传输**：通过 HTTPS 部署 SSL 证书，在传输链路层建立加密层，确保数据在传输过程中不被窃取或篡改。

注意：文件加密会有一定的性能损耗，主要体现在访问延迟增加，对小文件读写影响较为明显。

#### 4. 盗刷风险检测

COS 提供盗刷风险检测功能，可帮助发现潜在的安全风险。（盗刷风险检测界面截图）

### 权限管理机制

COS 对象存储提供三种权限管理方法，用户的总权限为三种方法的组合：

1. **存储桶访问权限**：控制已有账号、子账号操作存储桶的权限，粒度较粗。
2. **自定义 Policy 权限**：更灵活地控制某个用户、在某个条件下、对某个资源的某种操作权限，粒度更细。

**实际使用时，建议两者结合。**

#### 实践：创建子账户

不建议使用主账户操作（权限过大、存在风险）。进入访问管理控制台，快速创建子用户：

- 开启**编程访问**（方便通过 API 访问）
- 选择策略时取消所有默认权限，按需逐条添加
- 新建用户后保存密码和 SecretKey，用于腾讯云 API 访问

#### 实践：修改存储桶访问权限

遵循最小权限原则，将公共权限设置为**私有读写**，保证只有授权用户才能访问。然后为新建的子用户增加访问存储桶的权限。

#### 实践：配置 Policy 权限

在 Policy 中添加策略，指定允许访问的资源路径（如用户头像目录和封面目录），开放公开读权限。

配置后，允许的路径资源可正常加载，但其他资源文件无法通过客户端直接下载。

### 其他安全方法

还可通过生成临时操作密钥，在前端直传对象存储等方式进一步保证安全性。
