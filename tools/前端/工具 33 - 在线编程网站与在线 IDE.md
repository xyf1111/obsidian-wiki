# 工具 33 - 在线编程网站与在线 IDE

> 几类可替代本地环境的在线编程平台：前端代码搜索与在线编辑用 CodePen / CodeSandbox / JSFiddle，多语言在线运行用 JSRUN，一键在线构建运行任意 GitHub 项目用 Gitpod——核心思路是「不想本地搭环境时，直接在浏览器里跑代码」。

## 核心要点

### 在线前端编辑与效果预览：CodePen

国外的在线前端编程网站，可发现大量国外大神编写的前端代码，除常见网页布局外，更多是各式各样好玩的、炫酷的、新颖的前端动画和特效。

- **搜索即得效果**：输入关键词（如 `Christmas Tree`）就能搜到各种风格的现成网页，直接拿来看效果
- **在线编辑**：点击看中的网页即进入代码编辑页，可任意修改 HTML、CSS、JavaScript，底部区域实时浏览运行效果
- **分享导出**：编辑完成后，网页右下角菜单支持全屏浏览、收藏、克隆、分享，还能将网页内嵌到自己的项目中，或下载完整代码包到本地

得益于前端技术的发展，这类网站提供了「搜索项目 → 在线编辑 → 分享导出」一条龙服务，可以自主练习的方式轻松学习别人优秀的代码。

演示视频：https://www.bilibili.com/video/BV1im4y1X7zb/

### 基于模板的隔离沙箱：CodeSandbox

代码沙箱，顾名思义，可以在隔离的环境中运行前端项目。

- 基于丰富的模板创建自己的沙箱（项目），覆盖 React、Vue、Angular、VuePress、Svelte 等常见前端框架
- 创建后可在线编辑代码、实时查看效果，也能把沙箱分享给其他小伙伴

### 快速验证代码片段：JSFiddle

前端开发的练习场，同样是在线编写代码、实时浏览效果。

- 相对 CodePen，编辑体验更好
- **典型用法**：在网上看到一段不错的 JS 代码或插件，不必下载到本地，直接粘贴到 JSFiddle 就能以最快方式查看运行效果
- 现在很多前端组件库也用这类平台做演示，给开发者所见即所得的体验

### 多语言在线调试：JSRUN

国内的在线编程网站，除前端外，甚至支持多达 30 多种编程语言的在线调试和运行。

- 可浏览别人编写的代码片段并直接下载
- 可保存和分享自己的代码，建立个人的小代码合集
- 国内访问速度和功能体验都相当不错

### 在线 IDE 与 GitHub 项目一键运行：Gitpod

比在线编辑器更高级，是一个强大的在线 IDE（集成开发环境），提供 VSCode 风格的编辑器，允许在线编写代码完成开发。

- 基于容器技术，可一键编译、构建、运行**任意 GitHub 项目**，不止前端
- 每个项目运行环境互相隔离，随用随创建、用完可随时回收，非常灵活
- **典型用法**：看中某个 GitHub 项目又不想在本地搭建各种环境查看运行效果时，用 Gitpod 在线构建和执行；越来越多 GitHub 项目接入了 Gitpod，仓库页出现一键部署按钮即可直接运行
