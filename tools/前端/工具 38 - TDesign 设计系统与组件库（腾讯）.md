# 工具 38 - TDesign 设计系统与组件库（腾讯）

> TDesign 是腾讯开源的一套拥有完整设计价值观与视觉风格指南的企业级设计体系，同时提供基于 Vue、React、小程序等业界主流技术栈的多端组件库，主要用于构建**设计统一、多端覆盖、跨技术栈**的企业级前端应用，尤其适合开发中后台系统。

## 核心要点

### 什么是 TDesign

- **官方定位**：一套拥有完整的 **设计价值观** 和 **视觉风格指南** 的企业级设计体系，并在此基础上提供基于 Vue、React、小程序等业界主流技术栈的**组件库**解决方案。
- **用人话描述**：定了一套设计风格（字体大小、颜色、动效等），并提供不同框架（Vue、React）、各终端（PC、移动端、小程序）的**组件库**，帮助开发者轻松完成风格一致的前端项目，尤其适合开发中后台系统。
- 官网：https://tdesign.tencent.com/
- 代码仓库：https://github.com/Tencent/tdesign

### 怎么用

- 前端开发者进入 [TDesign 官方文档](https://tdesign.tencent.com/)，按「快速开始」引入 TDesign 即可直接使用组件库。
- 每个组件除**示例代码、效果演示和 API 介绍**外，还包含**使用指南**，帮助正确高效地使用组件。
- 提供开箱即用的脚手架 **TDesign Starter**：只需输入几行命令，就能快速搭建出一个多端适配的中后台管理系统。

### 与 Ant Design 的对比

- TDesign 与蚂蚁金服的 **Ant Design** 模式几乎一致（设计体系 + 组件库 + 中后台脚手架）——Ant Design 做得很好，有很多值得参考的地方；Ant Design 生态与脚手架见 [[工具 05 - Ant Design Pro 入门与初始化]]。
- 区别在于：TDesign 并非照搬，而是由**整个腾讯各大 BG 的同学内部共建**，整合了过去腾讯各种设计体系和组件库的优点，经过 **5000 多次代码提交**才推出一套有腾讯产品风格的设计体系。
- 例如 **Tencent Blue** 蓝色调，在腾讯官网、腾讯文档、腾讯会议等产品中都能见到。

### 组件库选型参考

- 前端主流组件库盘点（Element Plus / Vant / Ant Design 等）见 [[工具 12 - 前端学习路线]] 的「组件库」条目。
- 同类开源设计系统：字节跳动的 **Arco Design**、抖音的 **Semi Design**。
- 结论：对开发者来说，多一个组件库的选择不是坏事；多一个大厂的开源项目，也多一份学习空间。
