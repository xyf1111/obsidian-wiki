# 前端面试 01 - 26 届春招前端热题

> 26 届春招前端高频面试题汇总，每题为「回答重点 + 扩展知识」结构，逐批追加。本篇覆盖 CSS 基础：`display` 取值与布局模型、属性继承规则。

## 一、CSS 中 display 属性的值及其作用

**回答重点**：`display` 决定元素的**内部显示类型**——元素自身按什么盒子参与父级布局，以及它的子元素按什么规则排列。可以理解为两段式：外部（`block` / `inline`）决定自己占不占一整行，内部（`flow` / `flex` / `grid`）决定子元素的排列方式，现代 CSS 中两者可分开写（`display: block flex` 等价于 `flex`，外部盒级、内部弹性）。

| 属性值 | 作用 |
|---|---|
| `none` | 元素不显示，且**不占据任何空间**（脱离渲染树） |
| `block` | 块级元素，独占一行，可设宽高 |
| `inline` | 行内元素，前后不换行，宽高由内容决定 |
| `inline-block` | 行内块级，不换行但**可以设置宽高** |
| `flex` | 块级弹性容器，子元素按一维弹性布局排列 |
| `inline-flex` | 行内弹性容器，子元素弹性布局 |
| `grid` | 块级网格容器，子元素按二维网格布局 |
| `inline-grid` | 行内网格容器，子元素网格布局 |
| `table` / `table-row` / `table-cell` / `table-row-group` / `table-header-group` / `table-footer-group` / `table-column` / `table-column-group` / `table-caption` | 让普通元素模拟表格各部分的显示行为（表格语义化标签默认值即这些） |
| `list-item` | 显示为列表项，带列表标记（`<li>` 的默认值） |
| `initial` | 恢复为属性默认值（`display` 的初始值是 `inline`） |
| `inherit` | 继承父元素的 `display` 值（注意 `display` 本身**不可继承**，只能显式声明） |

**其中 `flex` 和 `grid` 是前端必须熟练掌握的两种布局**：`flex` 是一维（行或列）布局，适合导航、卡片横向排列；`grid` 是二维（行 + 列同时）布局，适合整体页面骨架、宫格列表。

### 1、Flex 一维布局

关键属性只有四个：容器上 `display: flex` + `flex-direction`（主轴方向）+ `justify-content`（主轴对齐）+ `align-items`（交叉轴对齐）；子项再用 `flex: 1` 做剩余空间分配。

```css
.container {
    display: flex;
    flex-direction: row;        /* row | column | row-reverse | column-reverse */
    justify-content: center;    /* flex-start | flex-end | center | space-between | space-around */
    align-items: center;        /* flex-start | flex-end | center | baseline | stretch */
    height: 100vh;
}
.box { flex: 1; margin: 10px; }
```

- **主轴 vs 交叉轴**：`flex-direction` 一改，`justify-content` 和 `align-items` 作用的方向也随之互换，这是面试最常见的追问点。
- **垂直水平居中**：容器 `display: flex; justify-content: center; align-items: center;` 即可，是「如何实现垂直水平居中」的标准答案之一（另有 `position + transform`、`grid + place-items: center`）。

### 2、Grid 二维布局

```css
.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);  /* 3 列等宽 */
    gap: 10px;                              /* 网格间隙，旧写法 grid-gap 仍可用 */
    padding: 10px;
}
```

- `fr` 是网格专用弹性单位，按剩余空间比例分配；`repeat(3, 1fr)` 比手写三遍 `1fr` 更易维护。
- 需要「列数随宽度自动变化」时用 `repeat(auto-fill, minmax(200px, 1fr))`，可替代部分媒体查询。
- `grid` 与 `flex` 不互斥：常见做法是页面骨架用 `grid`，内部组件排列用 `flex`。

### 3、易混点

| 对比 | 区别 |
|---|---|
| `display: none` vs `visibility: hidden` | 前者不渲染、不占位（触发重排）；后者仍占位，只是不可见（只触发重绘），且 `visibility` 可继承、子元素可单独改回 `visible` |
| `inline` vs `inline-block` | 两者都不换行；`inline` 的 `width/height/margin-top/margin-bottom` 无效，`inline-block` 生效；`inline-block` 元素之间会因 HTML 空白符产生空隙，可用 `font-size: 0` 或父级 `display: flex` 消除 |
| `block` vs `flex` | `flex` 容器自身仍是块级（占满一行），区别在于**子元素**的排列规则被替换为弹性布局 |

## 二、CSS 中可继承与不可继承属性有哪些？

**回答重点**：CSS 属性分**可继承**与**不可继承**两类。可继承属性会把父元素的计算值传递给后代，不可继承属性只作用于声明它的元素本身。**判断规律：与「文本内容呈现」相关的属性大多可继承，与「盒子模型、布局、定位」相关的属性大多不可继承。**

### 1、可继承属性（文本 / 字体 / 列表 / 可见性）

`color`、`font-family`、`font-size`、`font-style`、`font-variant`、`font-weight`、`letter-spacing`、`line-height`、`text-align`、`text-indent`、`text-transform`、`visibility`、`white-space`、`word-spacing`，以及 `list-style`（部分，见下）、`cursor`、`direction`。

### 2、不可继承属性（盒子 / 布局 / 定位 / 背景）

`background`（含 `background-color` 等）、`border`、`display`、`width`、`height`、`margin`、`padding`、`position`、`top/right/bottom/left`、`z-index`、`float`、`clear`、`overflow`、`vertical-align`。

| 类别 | 代表属性 | 是否继承 |
|---|---|---|
| 文本 / 字体 | `color`、`font-*`、`line-height`、`text-align` | ✅ |
| 列表标记 | `list-style-type`、`list-style-position` | ✅ |
| 列表图片 | `list-style-image` | ❌ |
| 盒子模型 | `width`、`height`、`margin`、`padding`、`border` | ❌ |
| 布局 / 定位 | `display`、`position`、`float`、`z-index` | ❌ |
| 可见性 | `visibility` | ✅（可被子元素用 `visible` 覆盖） |

### 3、全局关键字：inherit / initial / unset / revert

| 关键字 | 行为 |
|---|---|
| `inherit` | 强制取父元素的计算值——**不可继承属性也能借此「变成」继承**，常用于表单控件（`input`、`button` 默认不继承字体，用 `font: inherit` 统一） |
| `initial` | 取属性在规范中的初始值（`color` → `canvastext`，`display` → `inline`），**不是**「浏览器默认样式」 |
| `unset` | 可继承属性等同 `inherit`，不可继承属性等同 `initial` |
| `revert` | 回滚到浏览器默认样式（用户代理样式表），重置组件样式时比 `initial` 更符合直觉 |

```css
.child {
    color: inherit;   /* 强制继承父元素的文字颜色 */
    all: unset;       /* 一次性清空所有属性，常用于组件库样式隔离 */
}
```

### 4、两个坑

- **`line-height` 的百分比 / 无单位值差异**：写 `line-height: 1.5`（无单位）时，1.5 会继承下去、后代按**自身字号**重算；写 `line-height: 150%` 或 `1.5em` 时，继承的是**已计算出的像素值**，后代字号变化不再跟随。想让行高随字号自适应，用无单位值。
- **`a` 标签颜色不继承父级**：链接有用户代理样式（`color: -webkit-link`），优先级高于继承值——继承值永远是最低优先级，「继承来的样式盖不过任何直接声明」。这也是「为什么设了 body 颜色链接还是蓝的」的原因。
