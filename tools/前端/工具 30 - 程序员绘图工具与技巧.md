# 工具 30 - 程序员绘图工具与技巧

> 程序员常用画图软件与技巧：流程图/架构图用 Draw.io，ER 图与 UML 类图交给工具自动生成，数据图表用 Flourish，思维导图用 Markdown 导入 XMind 自动生成——核心思路是「能自动生成就不手画」。

## 核心要点

### 流程图 / 交互图 / 架构图：Draw.io

免费在线网页绘图工具，选它的 4 个理由：

1. **使用方便**：无需登录直接进网页，可用海量模板新建项目；左侧拖拽图形到绘图区编辑、右侧修改样式；可直接搜索需要的图形（如服务器），也能粘贴本地或网络图片
2. **样式美观**：内置多种默认主题和预设图形风格（如手绘风格）；图形可高度灵活定制，熟悉界面开发甚至可以直接编辑图形的属性值
3. **丰富导出**：一键导出图片、矢量图、PDF、HTML 文档等；可直接生成在线网页分享给别人浏览（带缩放、截图、打印工具栏），还能导出为嵌入式网页，无缝集成到自己开发的网页中
4. **便于存储和导入**：随时保存为本地文件或存储到 GitHub 等在线空间，再次编辑时从原处导入——习惯用 GitHub 存放代码的同学可以用它协作绘图

本地绘图软件可参考 EdrawMax（亿图图示），功能同样强大。

### ER 图：数据库工具自动生成

ER 图常用于数据库设计，表示数据的属性和关系——**不用手画**，直接用数据库管理软件（Navicat、JetBrains DataGrip 等）根据已有的库表自动生成。

### UML 类图：IDE 自动生成

UML 类图表示类与类之间的关系，帮助快速了解整个系统的设计结构——同样**不用手画**，直接用集成开发环境（如 JetBrains IDEA）根据代码自动生成，比自己画更美观。

### 可视化图表：Flourish

在线生成可视化图表的网站，图表在 PPT 汇报中能直观展示数据和趋势：

- 内置丰富的图表类型模板（条形图、柱状图、饼图、折线图等）
- 选择图表类型 → 配置数据和样式即可出图（比 Excel/PPT 自带图表美观）
- 特色功能：**动态图表**（动态变化数值的实时排行榜）+ **URL 分享**（一键分享网页地址，也可嵌入到自己的网页）

### 思维导图：Markdown 导入 XMind

- 常用软件 XMind：使用方便、主题丰富
- 技巧：**先编写 Markdown 文档，再导入 XMind 自动生成思维导图**（按标题、列表等元素自动转换）——学习路线类思维导图都可以用这个方法批量生成，不用一个个手动编辑

### 画图没思路怎么办

- 画图可以模仿：**多看多画、熟能生巧**——画不出来时直接上网搜索别人画的同类图，照猫画虎
- Process On 提供大量绘图模板可参考
