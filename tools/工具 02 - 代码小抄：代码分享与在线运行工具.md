# 工具 02 - 代码小抄

> 代码小抄（CodeCopy）是一个简洁的代码分享与在线运行工具，旨在替代截图/拍照分享代码的糟糕体验。

- 官网：[https://codecopy.cn](https://codecopy.cn/)
- 微信小程序：代码小抄

## 核心功能

### 1. 快速创建与分享代码片段

- 类似编辑器的界面，可新增、删除多个代码片段
- 支持切换主题、设置过期时间、用 Markdown 补充描述（如报错信息）
- 多种分享方式：复制链接、QQ、扫码、微信小程序、嵌入代码
- 分享范围：公开、加密、仅个人可见

### 2. 代码库

- 浏览其他用户分享的优质代码片段
- 支持按标签、语言、关键词搜索，多种排序方式

### 3. 代码管理

- 集中管理自己的代码片段
- 收藏他人代码便于学习

### 4. 在线运行

- 支持多种主流编程语言代码在线运行，直接查看运行结果

### 5. AI 智能分析

- **代码分析**：解释代码逻辑，辅助学习
- **代码纠错**：自动发现代码中的 Bug
