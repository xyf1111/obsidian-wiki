# 工具 06 - autojump 命令行目录快速跳转工具

> autojump 是一款开源十余年、GitHub 近 1.5 万 star 的命令行目录跳转工具：自动记录访问过的目录并按访问频次排序，用 `j 关键词` 就能跳到目标目录，不必再手打长路径。

## 背景：目录切换的痛点

命令行里频繁在多个项目目录间跳转，例如从主目录 `~` 切到 `~/code/projects/my-project/src/main/java`，每次都要手打一长串路径；同时开发多个项目时，在各项目目录间来回跳还容易跳晕。

## 安装

同时支持 Linux、macOS 和 Windows，跟随官方文档安装即可（macOS 上通过包管理器一行命令完成）：

> 仓库：https://github.com/wting/autojump

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `j 关键词` | 跳转到**已访问过**的、包含该关键词的目录（如 `j t` 跳到 `java-test`）；`j` 是 autojump 的简写，可简化输入 |
| `jc 关键词` | 只跳转到**当前目录下**包含该关键词的子目录（如 `jc s` 跳到 `src`） |
| `jo 关键词` | 不在终端跳转，而是用文件管理器打开包含该关键词的目录 |
| `j -s` | 查看它记录的内容（访问过的目录及访问次数） |

其余命令可查官方文档，一分钟即可上手。

## 实现原理

本质很简单：在本地文件中记录你访问过的所有目录，并按访问次数排序；跳转时若有多个目录都匹配输入的关键词，优先选择访问次数最多、最常用的那个。源码没有几行，自己实现一个也不难。
