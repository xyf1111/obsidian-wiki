# Java 学习路线（零基础到精通）

## 开篇介绍

Java 是拥有 20 多年历史的老牌编程语言，以"一次编写，到处运行"为特性，是企业级应用开发的首选语言之一。

### 应用场景

企业管理系统、电商平台、社交应用、游戏后台、大数据处理系统、AI 应用（智能客服、AI 助手等）。

### 就业方向

1. **Java 后端开发工程师**：负责服务端业务逻辑开发，最主流的就业方向
2. **Java 全栈开发工程师**：后端 + 前端，能独立完成完整项目
3. **安卓开发工程师**：使用 Java/Kotlin 开发安卓应用
4. **大数据开发工程师**：使用 Java 进行大数据处理（Hadoop、Spark、Flink）
5. **架构师**：负责系统整体设计和技术选型
6. **AI 应用开发工程师**：Java + AI 框架（LangChain4j 等）开发 AI 应用

## 阶段 1：编程语言基础

**目标**：培养兴趣、快速上手，能运行和编写简单的 Java 程序。

### Java 编程基础（45 天）

#### 知识点

- Java 特点与环境搭建
- IDEA 开发工具（新建项目、运行调试、界面配置、插件管理）
- **Java 基础语法**：数据类型、流程控制
- 数组
- **面向对象**：方法、重载、封装、继承、多态
- 抽象类、接口、枚举
- 常用类：String、日期时间
- 集合类、泛型、注解
- 异常处理、多线程、IO 流、反射

#### 学习建议

1. 坚持每天学习 2-3 小时，保持连贯性
2. 多敲代码，不要只看视频不动手
3. 学会使用 Debug 调试，学会看报错信息
4. 善用 AI 工具辅助学习，但不要完全依赖
5. 不要死记硬背语法和 API，理解为主，多用自然记住

#### 经典面试题

1. 为什么重写 equals 还要重写 hashcode？
2. == 和 equals 比较的区别
3. 为什么有时会出现 4.0 - 3.6 = 0.40000001 的现象？
4. final 关键字的作用
5. 介绍 Java 的集合类
6. ArrayList 和 LinkedList 的区别

### Java 8 及新版本特性（3 天）

#### 知识点

**Java 8 核心特性（必学）：**
- Stream API
- Lambda 表达式
- 新日期时间 API
- 接口默认方法
- Optional 类

**Java 新版本特性（了解）：**
- Java 17：Record 类、Sealed Classes、模式匹配增强
- Java 21（LTS）：虚拟线程（Virtual Threads）、序列集合
- Java 21 之后：更多语法糖和性能优化

#### 学习建议

Java 8 是企业开发中最主流的稳定版本，Lambda 和 Stream API 能让代码更简洁优雅。新版本特性可在掌握 Java 8 核心后按需了解，特别是虚拟线程对 I/O 密集型应用的提升显著。

#### 经典面试题

1. Java 8 有哪些新特性？
2. Lambda 表达式的原理是什么？
3. Stream API 和传统循环有什么区别？
4. HashMap 在 JDK 1.7 和 1.8 的区别？
5. Optional 类的作用和使用方法

#### 学习资源

- 宋红康 — 全网最全 Java 零基础入门教程（看 Java 8 部分）
- 《Java 8 实战》
- 在线编写运行 Java 8（Tutorialspoint）

### MySQL 数据库（7 天）

企业中大部分业务数据使用关系型数据库存储，MySQL 是主流也是面试重点。

#### 知识点

- **索引（必学）**：索引类型、原理、优化
- **事务（必学）**：ACID 特性、隔离级别
- **锁机制**：行锁/表锁、乐观锁/悲观锁
- **设计数据库表（必学）**：三大范式、表关联设计
- 性能优化

#### 经典面试题

3. 有哪些优化数据库性能的方法？
