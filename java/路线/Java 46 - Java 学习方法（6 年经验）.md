# Java 学习方法（6 年经验）

> 6 年 Java 使用经验的过来人总结：如何快速入门、如何巩固基础、进阶学什么怎么学，附推荐资源与书籍。

## 第一阶段：入门

- 推荐 B 站韩顺平老师的免费 Java 课（讲解细、内容全）；想看书入门可看《21 天学通 Java》这类轻量入门书
- 一边看书/看课一边跟着敲代码（入门阶段用 Eclipse 编辑器即可），顺手做些小玩意增加乐趣（如写个无限弹窗的坑人程序发给同学）
- 入门 2 点建议：
  1. **一定要多写代码**：时间允许的话尽量把书中的每行代码都敲一遍；尤其是面向对象编程，要写代码去理解，不要背知识点背代码
  2. **合理分配时间**：以快速写出代码为目标，不要过度纠结源码；急着找工作的话，Java 界面开发可跳过

## 第二阶段：巩固基础

> 巩固基础是一个过程，要注重日常积累、养成每日阅读/做题的习惯，而不是停掉新技术学习、光刷题复习（会很枯燥，也低效）。

5 种行之有效的方法（可按需组合）：

1. **精读一本基础书**：《Java 核心技术卷 1》适合巩固基础——可跳过界面开发章节，重点复习面向对象三大特性、接口、泛型、异常处理、集合类、内置类等；卷 2 可以不用看
2. **考证倒逼学习**：Oracle 官方 Java 8 认证考察内容正好是 Java 基础，可借考试系统巩固一遍；但证书本身认可度低，纯粹为了激励学习性价比不高，不太推荐
3. **刷基础面试题**：背常见面试题（如 String 为什么不可变、equals 和 == 的区别）查漏补缺，也顺便为实习/秋招做准备
4. **刷选择题**：利用零碎时间（如通勤路上）在手机上刷 Java 基础选择题——约 1000 道完整刷两遍，第一遍正确率只有 30% 多，第二遍能到 90%，进步明显可见
5. **每天写 Java**：每天用 Java 刷 2-3 道算法题、做项目、实现设计模式——只要几天不写 Java，很多语法就会忘；坚持写才能把集合类、各种内置类方法、Java 8、类库用得熟练

> 面试观察：除了阿里比较喜欢考 Java 基础和底层（毕竟 Java 主场），其他公司基本没怎么考察 Java 基础知识，更多是问数据库、中间件、计算机基础、业务场景设计等独立于编程语言的问题。

### 巩固基础的两个建议

- 急着找工作：先把开发框架、常用技术学了，能做出一个完整的项目，再用上述方法巩固基础，性价比更高
- 注重日常积累：巩固基础是长期过程，养成每日阅读/做题的习惯，坚持比突击重要

## 第三阶段：Java 进阶（5 个方向）

1. **Java 类库和生态**：工具库 Guava、Apache Commons，缓存库 Jedis、Caffeine 等——需要多做项目、多看别人的视频、不断积累
2. **并发编程**：了解并发编程思想，能熟练运用 Java 并发包写代码；资源：《并发编程的艺术》+ 网上视频教程
3. **JVM（Java 虚拟机）**：了解 JVM 内存模型、Java 运行原理、垃圾回收等概念，能分析和调优 Java 程序；《深入理解 JAVA 虚拟机》很厚、读起来有压力且很多东西记不住，硬啃性价比不高——建议先看视频学 JVM 分析工具的用法、自己多调试，更容易理解；面试前背题目，工作后再深入学习也可以
4. **源码阅读**：如 HashMap、ArrayList 源码——网上读文章 + 自己多 Debug 调试即可
5. **Java 特性**：反射、探针、动态代理、UnSafe 等——在学框架设计原理和源码的过程中会接触到，也可以专门到网上搜文章学习

> Java 进阶知识非常多，「编程一辈子都学不完」，量力而为就好。

## 工作后

- 工作后 Java 功力容易退步（公司更多是开发需求，没时间天天自学；不用再背面试题），但此前积累的能力已能满足实际开发需要
- 学习重心可以转向系统设计、其他后端技术
- 入门阶段觉得枯燥时，多做小玩意和项目增加乐趣，在实践中学习
