# Java 工具 17 - HTML 解析与网页抓取（jsoup）

> jsoup 本质是一款 Java 的 HTML 解析器，支持用类似前端 CSS 选择器的语法从网页源码中提取想要的片段，几行代码即可完成网页请求与内容抓取。

## 一、先说清楚：爬虫的边界

爬虫是从网站上抓取数据（比如从表情包网站抓取图片），虽然不像黑客攻击那样直接，但同样会对网站和企业造成威胁：

- 爬虫频率过高，可能影响网站的正常运营
- 爬虫范围太大，可能侵犯原网站的权益
- 非法爬取数据，可能侵犯用户的隐私

即便如此，程序员仍然值得学习爬虫：一方面它的应用场景非常多，是获取数据必备的神技；另一方面**只有了解一项技术，才能更好地防范它**。

> 适度爬虫益脑，过度爬虫伤身，请将技术用到正道。

## 二、jsoup 是什么

Java 爬虫库有很多（比如 crawler4j），jsoup 的优势是**用起来简单方便**，基本可以满足大部分简单的爬虫需求。

- 项目地址（官网）：https://jsoup.org/
- 本质：不是完整的爬虫框架，而是 **Java 的 HTML 解析器** —— 而解析正是爬虫中不可或缺的一步

**为什么不直接用正则？** 假设要从一篇文章中取出作者姓名：

```html
<title>文章页</title>
<body>
  <h1>文章标题</h1>
  <div>作者姓名</div>
  <p>文章内容。。。</p>
</body>
```

最直接的方式是用正则表达式匹配被 `<div>` 包裹的内容，但网页内容灵活多变，写出符合要求的正则并不容易。因此一般都用网页解析库，像 jsoup 支持用 CSS 选择器语法来解析和提取网页内容。

## 三、快速上手

从官网引入 jsoup 后，只需一行代码就能向网站发送请求并获取页面内容：

```java
Document doc = Jsoup
    .connect("https://example.com")
    .get();
```

jsoup 会自动把网页内容封装到 `Document` 对象中，之后取任何内容都很方便：

```java
// 取网页标题
String title = doc.title();

// 用选择器语法取多个网页链接
Elements lines = doc.select("#box a");
for (Element line : lines) {
    // 获取链接标题
    line.attr("title");
    // 获取链接 url
    line.absUrl("href");
}
```

此外 jsoup 还有**处理网页数据**的功能，照着官方文档的示例代码很容易上手。

## 四、进阶方向
