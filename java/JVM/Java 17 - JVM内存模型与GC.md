# Java 17 - JVM内存模型与GC

## JVM 运行时数据区（JDK 8+）

```
┌─────────────────────────────────────────────┐
│                  堆 (Heap)                    │
│  ┌─────────┬──────────┬──────────────────┐  │
│  │ 新生代   │  老年代   │  字符串常量池     │  │
│  │ Eden    │ Old Gen  │  (移入堆)         │  │
│  │ S0  S1  │          │                  │  │
│  └─────────┴──────────┴──────────────────┘  │
├─────────────────────────────────────────────┤
│             元空间 (Metaspace)                │
│  取代永久代 (PermGen)，使用本地内存            │
├──────────────────┬──────────────────────────┤
│  虚拟机栈 (Stack)  │  本地方法栈              │
│  每线程一个        │  native 方法调用栈       │
├──────────────────┴──────────────────────────┤
│           程序计数器 (PC Register)            │
│  记录当前线程执行的字节码地址                  │
└─────────────────────────────────────────────┘
```

### JDK 8 重要变化
- **永久代 (PermGen)** → **元空间 (Metaspace)**，使用本地内存
- **字符串常量池**从方法区移入堆

## 垃圾回收机制

### 判断对象存活

1. **引用计数法**（主流 JVM 不用，循环引用问题）
2. **可达性分析**（GC Roots 搜索，主流方案）

GC Roots 包括：
- 虚拟机栈引用的对象
- 静态属性引用的对象
- 常量引用的对象
- JNI 引用的对象

### 引用类型

| 类型 | 回收时机 | 用途 |
|------|----------|------|
| **强引用** | 永不回收 | new Object() |
| **软引用** | 内存不足时 | 缓存 (SoftReference) |
| **弱引用** | 下次 GC | WeakHashMap (WeakReference) |
| **虚引用** | 任何时候 | 追踪对象回收 (PhantomReference) |

## 垃圾回收算法

| 算法 | 原理 | 适用区域 |
|------|------|----------|
| **标记-清除** | 标记存活→清除死亡 | 老年代（CMS） |
| **标记-复制** | 分为两块，轮流使用 | 新生代 |
| **标记-整理** | 标记存活→压缩整理 | 老年代 |
| **分代收集** | 新生代复制，老年代整理 | 整堆 |

### 常用 GC 收集器

| 收集器 | 区域 | 算法 | 特点 |
|--------|------|------|------|
| **Serial** | 新生代 | 复制 | 单线程，暂停所有应用线程 |
| **ParNew** | 新生代 | 复制 | Serial 多线程版 |
| **Parallel Scavenge** | 新生代 | 复制 | 关注吞吐量 |
| **CMS** | 老年代 | 标记-清除 | 低延迟，并发 |
| **G1** | 整堆 | 分区+复制 | 可预测停顿，JDK 9+ 默认 |
