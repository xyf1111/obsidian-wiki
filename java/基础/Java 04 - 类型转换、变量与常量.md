# Java 04 - 类型转换、变量与常量

## 类型转换

低 → 高：`byte,short,char → int → long → float → double`

### 自动类型转换（隐式）

低精度 → 高精度，自动完成：
```java
int i = 100;
long l = i;    // 自动转
float f = l;   // 自动转
```

### 强制类型转换（显式）

高精度 → 低精度，需强制转换，可能丢失精度：
```java
double d = 3.14;
int i = (int) d;  // 结果为 3，精度丢失
```

### 注意点

1. 不能对 `boolean` 进行类型转换
2. 不能把对象类型转换成不相关的类型
3. 高容量→低容量需强制转换
4. 转换时可能出现内存溢出或精度问题

## 变量

变量是程序中最基本的存储单元，三要素：**变量名 + 变量类型 + 作用域**

```java
type identifier = value;
```

### 变量作用域

| 类型 | 位置 | 生命周期 |
|------|------|----------|
| **类变量** (static) | 类中，方法外 | 随类加载而存在 |
| **实例变量** | 类中，方法外 | 随对象创建而存在 |
| **局部变量** | 方法或代码块内 | 方法执行期间 |

## 命名规范

| 目标 | 规范 | 示例 |
|------|------|------|
| 类成员变量 | 首字母小写 + 驼峰 | `monthSalary` |
| 局部变量 | 首字母小写 + 驼峰 | `userName` |
| 常量 | 全大写 + 下划线 | `MAX_VALUE` |
| 类名 | 首字母大写 + 驼峰 | `GoodMan` |
| 方法名 | 首字母小写 + 驼峰 | `runRun()` |

## 常量

常量用 `final` 关键字定义，初始化后不可改变：
```java
final 类型 常量名 = 值;
final double PI = 3.14159;
final int MAX_LOGIN_ATTEMPTS = 5;
```
