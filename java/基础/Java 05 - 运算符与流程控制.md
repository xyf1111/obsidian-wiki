# Java 05 - 运算符与流程控制

## 运算符分类

### 算术运算符
| 运算符 | 含义 | 示例 |
|--------|------|------|
| `+ - * /` | 加减乘除 | `a + b` |
| `%` | 取模（取余） | `a % b` |
| `++` | 自增 | `a++` / `++a` |
| `--` | 自减 | `a--` / `--a` |

### 关系运算符
`==` `!=` `>` `<` `>=` `<=` — 返回 boolean

### 逻辑运算符
| 运算符 | 含义 | 说明 |
|--------|------|------|
| `&&` | 短路与 | 前 false 则后不执行 |
| `\|\|` | 短路或 | 前 true 则后不执行 |
| `!` | 非 | 取反 |
| `&` | 与 | 两边都执行 |
| `\|` | 或 | 两边都执行 |

### 位运算符
`&` `|` `^` `~` `<<` `>>` `>>>` — 直接操作二进制位

### 三元运算符
```java
条件 ? 表达式1 : 表达式2
int max = a > b ? a : b;
```

## 流程控制

### if-else
```java
if (条件) {
    // 条件成立
} else if (其他条件) {
    // 其他条件成立
} else {
    // 所有条件不成立
}
```

### switch
```java
switch (表达式) {
    case 值1: 语句; break;
    case 值2: 语句; break;
    default: 语句;
}
```

### 循环

```java
// for 循环
for (初始化; 条件; 迭代) { 循环体 }

// while 循环
while (条件) { 循环体 }

// do-while 循环（至少执行一次）
do { 循环体 } while (条件);
```

### break vs continue
- `break` — 跳出当前循环
- `continue` — 跳过本次循环剩余语句，进入下一次迭代
